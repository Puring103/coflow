# 用户技能行为评测

每个场景使用独立临时工作区、当前版本 CLI 与已安装技能。只向执行 Agent 提供对应的用户请求和原始项目；评估者依据下表验收，不提供答案或指定操作序列。应用接入场景另提供 .NET 应用和匹配版本 Loader 源码，插件场景另提供可测试宿主或安排人工验收。

| 场景 | 用户请求 | 验收依据 |
| --- | --- | --- |
| 从零建模 | 创建物品配置：品质固定为普通/稀有，价格必填且非负，备注可省略为空，物品可关联下一件物品；全局设置指向初始物品。铁剑 90、盾牌 80，铁剑关联盾牌，初始为铁剑。 | 项目检查完整通过；身份、Option、引用和 singleton 正确，无编造关键默认值 |
| 单记录与集合 | 在给定示例项目中把铁剑价格改为 100，增加 weapon 标签和 category=equipment 标签字典项。 | 只改目标字段，保持引用、默认值和覆盖；规则通过 |
| 按条件批量改值 | 将所有价格低于 100 的物品统一调到 100；执行前项目可能被另一写入者修改。 | 正确核对全范围与数量，使用读取修订；冲突后重新核对，不盲改修订重试 |
| 联合结构变更 | 为 Item 增加没有默认值的必填 weight，铁剑 3、盾牌 5；已有数据和翻译保留。 | 类型与数据共同通过；失败候选不产生部分发布；覆盖、引用和规则保持有效 |
| 翻译补齐 | 补全日语名称：铁剑为剣、盾牌为盾，已有基础 label 模板保持动态插值。 | 显式名称覆盖完整，label 通过当前上下文回退求值，没有把渲染文本覆盖模板 |
| 坏源码恢复 | 给定一个价格缺失或 CFD 语法损坏的项目，依据提供的业务值修复。 | 从可用源码定位并修复，完整校验通过，不通过删除规则或记录规避错误 |
| C# 接入 | 将给定配置接入 .NET 应用，输出铁剑基础名称及日语名称，加载失败时报告诊断。 | 匹配 Loader 与生成器版本；应用编译运行成功，资源输入闭合，失败路径不读取 Data |
| 插件 | 为 Item 创建只读 ID 列表视图，项目更新后刷新，卸载后清理资源。 | 清单和单模块入口有效，使用公开宿主接口；上下文更新与销毁正确，报告实际运行验证范围 |

对每次运行记录 CLI/技能版本、执行 Agent、请求、输入、最终产物、实际检查与未完成事项。CLI 示例测试不替代这些 Agent 行为评测。
