# CFD Editor Integration Project

This repository fixture is the manual and automated integration project for the CFD editor. It is
not a user-facing example. The project stays valid so every record can be inspected, edited, saved,
reloaded, shown in tables, and arranged in graph views.

It covers scalar values, enums, flags, defaults, nested collections, inline objects, inheritance,
polymorphism, cross-file references, options, results, functions, checks, dimensions, custom views,
record groups, and workspace restoration.

From the repository root, validate it with:

```bash
cargo run -- check tests/editor-project
```
