# Coflow 视觉语言提案

这是一套独立概念方案，不修改也不依赖现有官网。可直接打开 `index.html` 查看演示。

## 1. 核心概念：Laminar Confluence

中文概念名为「层流汇聚」。视觉不把 Coflow 画成一条僵硬的生产线，而是把它理解为一组低阻力的流场：策划、程序和 AI 从各自熟悉的入口进入，在统一数据模型中平滑收束，再稳定抵达运行时。

三个感受对应三套设计手段：

| 感受 | 视觉表达 | 交互表达 |
| --- | --- | --- |
| 流动 | 连续长线、沿路径移动的信号点、横向构图 | 等速位移、无突然跳变 |
| 汇聚 | 三股路径在同一切线上合流 | 鼠标只轻微影响流向，系统会自然回正 |
| 无摩擦 / 低阻力 | 大留白、少边框、扁平层级、短文案 | 反馈轻、快、可预测，避免弹性过冲 |

这套语言刻意避开水滴、旋涡、箭头和传统 ETL 管线图。Coflow 的价值不是「搬运」，而是让不同数据共享同一种语义，因此汇聚点比终点更重要。

## 2. Logo

Logo 由三条岗位轨迹和一条统一输出轨迹组成。珊瑚红代表策划，清水青代表程序，黄绿色代表 AI；三条轨迹用连续曲率汇入中线，汇聚后统一为深青绿色，表示共享语义和可信结果。

- `assets/coflow-logo.svg`：标准横版 Logo。
- `assets/coflow-mark.svg`：独立图形标。
- `assets/coflow-mark-mono.svg`：单色版本，适合印刷、压印和小尺寸场景。
- 最小显示高度建议为 `20px`；图形标四周至少保留一个线宽的安全空间。
- 不旋转、不增加外框、不把三条输入线改成箭头，也不在汇聚点增加圆形节点。

## 3. 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| Flow Ink | `#172A29` | 主文字、深色背景、结构线 |
| Soft Paper | `#F5F7F2` | 主背景，避免纯白的屏幕眩光 |
| Deep Paper | `#E6ECE7` | 区段分隔和工具背景 |
| Planner Coral | `#F06B5D` | 策划与内容创作入口 |
| Engineer Cyan | `#2AAFBF` | 程序、schema 与运行时入口 |
| Agent Lime | `#B9E63A` | AI agent 与自动化入口 |
| Confluence Teal | `#147C75` | 汇聚后的共享语义、可信结果与主品牌面 |
| Diagnostic Rose | `#FF4D7A` | 仅用于错误、阻塞与需要注意的诊断 |

主题色不是一个孤立的品牌色，而是一套「汇流光谱」。三种岗位色只在来源、过程和局部状态中出现；一旦进入统一模型，就收束为 Confluence Teal。Diagnostic Rose 独立于岗位色，并始终配合图形和文字，不能只靠颜色传达错误。

## 4. 字体与版式

- 品牌与正文：`Inter / Aptos / Segoe UI / PingFang SC`。使用中性、开放的无衬线体，不塑造过度科技感。
- 代码与系统状态：`Cascadia Code / Consolas`。
- 大标题短而直接，正文行长控制在约 32 个中文字符。
- 网格以横向流动为主，关键模块使用左对齐；不把每段内容都放进卡片。
- 圆角不是视觉语言。按钮、工具面板和数据节点保持直角，表达精确与低阻力。

## 5. 动效语言

- 主动画是匀速信号沿贝塞尔曲线移动，避免弹跳、液态形变和大幅缩放。
- 交互只改变流线控制点的小范围偏移，指针离开后平滑回到默认流向。
- 按钮反馈使用 `2px` 垂直位移和硬阴影，不使用发光。
- 完整支持 `prefers-reduced-motion`：关闭持续动画，保留静态流场。

## 6. 首页叙事

首页顺序从感受到证据，避免在首屏塞满功能：

1. 首屏先建立「Coflow = 配置自然流向运行时」的直觉。
2. 数据源汇聚图解释 Excel、CSV、CFD 如何进入统一模型。
3. 三条原则解释 schema、diagnostics 和 artifact lifecycle。
4. 终端工具展示实际 `check` / `build` 工作流。
5. 结尾给出唯一的安装入口。
