# 项目组成与协作

Coflow 项目由 CFT 声明、CFD 基础记录与维度覆盖、代码生成目标组成。

CLI 读取项目配置，提供查询、候选修改、检查、差异与代码生成。编辑器提供表格、记录、源码、图谱、维度与 Git Diff 视图，修改后更新数据与诊断。LSP 为文本编辑提供诊断、补全、导航和格式化。

C# 应用使用生成源码和 Coflow.Loader，将自行选择的 CFD 文件加载为业务对象。加载时完成默认值、引用连接、维度合成及字段路径插值。记录引用共享对象身份，维度可在同一份数据中选择多个变体。

CFT 决定数据契约和业务规则；CFD 保存应用要加载的记录。运行 `coflow check --rules` 独立验证项目，或使用 `coflow build` 在全部检查通过后生成 C# 代码。应用检查加载结果的成功状态与来源诊断，再读取生成的业务类型。
