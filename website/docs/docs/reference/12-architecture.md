# 项目组成

Coflow 项目由 CFT 声明、CFD 数据和 `coflow.yaml` 配置组成。
命令行、编辑器和语言服务使用同一份项目配置。

1. 用 CFT 定义记录、内联数据、默认值和维度。
2. 用 CFD 填写记录并关联其他记录。
3. 检查声明与静态数据，生成宿主接口。
4. 应用提交 CFD 来源并构建只读运行时，通过生成接口读取数据。

Unity 2022+ 宿主使用 Coflow.Runtime 和目标平台原生插件，支持 IL2CPP。
数据更新通过新建运行时完成；旧实例在释放前保持原有数据。

当前版本提供声明编译、数据加载、宿主数据访问、函数与模板执行、语言内部函数、
Host 调用及显式 check。构建阶段不执行程序；应用通过生成的强类型接口发起调用。

配置见 [项目配置](./01-project-config.md)，语法见 [CFT](./03-language/01-cft.md)、
[CFD](./03-language/02-cfd.md)，宿主集成见 [C# 代码生成](./07-codegen/01-csharp.md)。
