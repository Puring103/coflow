# 编辑器上手

安装[全量安装包](./install.md)后启动 Coflow 编辑器，创建项目或打开已有项目的 `coflow.yaml`。项目应包含 CFT 类型定义与 CFD 数据；完整示例见[快速开始](./install.md)。

## 编辑与检查

在文件树选择 CFT 以编辑类型源码，选择 CFD 以查看记录。表格适合比较同类型的字段，图谱适合查看引用关系，源码视图适合直接编辑 CFT/CFD。字段编辑应符合类型；缺失字段、无效引用和规则错误可从诊断定位到源码。

保存源码后检查诊断，再继续其他修改。数据编辑支持撤销和重做；外部 CLI 或 AI 修改文件后，编辑器会刷新项目。未通过检查的内容需依据诊断修复，不能仅凭视图中存在记录判断项目完整。

## 维度、比较与扩展

通过维度选择查看基础数据和覆盖结果，按需修改对应维度的显式值；未覆盖字段继续回退到基础值。参见[本地化与维度](../reference/10-localization.md)。

Git 比较用于核对当前数据与仓库版本的差异。自定义视图可通过[编辑器插件](../reference/13-plugins.md)接入。

## VS Code

从发布页下载 VSIX，在 VS Code 扩展菜单选择“从 VSIX 安装”，打开包含 `coflow.yaml` 的工作区并确认 `coflow --version` 可用。扩展提供 CFT/CFD 语言支持；语言服务失败时，在“输出”面板选择 `Coflow Language Server` 查看信息。

## 问题反馈

使用“日志与反馈”查看最近问题并生成诊断预览，确认内容后下载并提交问题。该入口在未打开项目时也可使用。参见[诊断与问题定位](../reference/09-diagnostics/01-diagnostics.md)。
