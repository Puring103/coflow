# Overview

Coflow connects configuration structure, data and application integration: define types and validation rules in CFT, store records in CFD, and load and read data through generated C# types. Project configuration organizes input files and generated directories. Dimensions express localization and platform differences.

- [Getting started](./guide/install.md): install Coflow, configure a project, write data, generate code and load it in C# using an item example.
- [Project configuration](./reference/01-project-config.md): inputs, dimension directories and code generation targets.
- [CFT](./reference/03-language/01-cft.md): types, declarations, defaults and business validation.
- [CFD](./reference/03-language/02-cfd.md): records, field values, references and overrides.
- [C# code generation](./reference/07-codegen/01-csharp.md): generated types, loading and querying records.
- [CLI commands](./reference/08-cli.md): commands and parameters for queries, editing, validation and generation.
- [Localization and dimensions](./reference/10-localization.md): organize variants, check coverage and read values on demand.
- [Diagnostics](./reference/09-diagnostics/01-diagnostics.md): interpret diagnostics and locate problems with the [error code index](./reference/09-diagnostics/02-codes.md).
- [Editor plugins](./reference/13-plugins.md): install project plugins and extend views, presentations, pages and commands.
