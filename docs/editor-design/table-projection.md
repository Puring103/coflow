# 表格投影、尺寸测量与共享传输

本文定义文件快照、表格行列模型、复杂字段摘要、引用显示、筛选及 IPC 归一化。

## 摘要宽度

`features/table/components/summaryMeasurement.ts` 统一管理摘要的 ResizeObserver、正文 MutationObserver 和字体失效事件。每帧先读取容器样式和逻辑宽度，再准备未测量片段与计数探针，集中读取精确尺寸，最后提交可见前缀和余项计数。相同样式及内容共享测量结果，计数探针在同一批次内去重。字体加载、主题样式、引用名称和容器尺寸变化触发相应重算。

尺寸统一为 CSS 逻辑像素。视觉矩形宽度根据容器的实际 zoom 换算，gap 与可用宽度使用同一单位。0.8、1、1.25、1.5 倍缩放由浏览器回归覆盖。

片段前缀和用于计算可显示项数；余项计数使用各候选 `+n` 的精确宽度。计数位数和比例数字会改变宽度，因此候选校验使用纯数值递减。所有候选计数的 DOM 写入与尺寸读取在计算前完成。

摘要按 8 项批次准备前缀，全部可容纳时继续补充。集合总数直接读取长度。宽度缓存上限为 4,096 项，旧文本按插入顺序淘汰。缓存保存尺寸，React 节点由当前值与注解生成。

## 数据投影与查询

- 对象字段投影按不可变值与注解身份保存在 WeakMap 中，声明顺序、额外字段排序和缺失字段行共用一次结果。
- 全文搜索按不可变记录身份缓存规范化后的 ID、字段名和递归值文本。记录替换后重新建立该记录的投影，字段边界保持独立。
- 引用候选按 lookup 结果数组身份共享 ID 索引、标签和下拉选项。数据代际刷新取得新数组，旧投影随 WeakMap 键释放。
- 下拉当前值通过共享索引查找，关闭时复用候选列表。首次搜索建立规范化文本，后续查询复用；空查询直接返回原列表。超过 100 项的菜单按固定 28px 行高挂载窗口，并保留完整候选序号、键盘循环与 ARIA 身份。
- 插件上下文在解析到实际展示贡献时创建；折叠摘要插件只在摘要可见时克隆值。

## 挂载与交互

内置复杂列与标量列共用横向窗口。列宽前缀按布局身份缓存；滚动通过二分定位边界，边界未变时不更新挂载范围。连续屏外列合并为总宽度占位。

内置字段树使用 28px 最小行高契约。屏外几何按预览高度预算估算，达到上限后停止访问其余字段。列分段由所有记录共用，屏外区间宽度从列前缀作差取得。完整展开高度仅在双击适配行高时计算，包含横向屏外的可见列。插件和差异展开内容使用自身布局，保留真实挂载与测量。

未选中的复杂预览通过 `previewWindow` 为所有展开层级分配同一个可见行预算；折叠子树不访问，省略尾部只创建 28px 溢出标记，不模拟完整内容高度。对象首次字段投影仍建立 schema 顺序和额外字段排序，后续按不可变身份复用。选中后恢复完整已展开内容，由浏览器自然扩展单元格表面，整行高度不变；超过表面上限时内部滚动。放大编辑保持完整字段树。用户调整行高后，可见行预算随高度更新。

展开路径保存在文件/实际类型视图的 `TableExpansionStore` 中，按记录定向通知。窗口卸载释放 DOM，重新挂载恢复展开状态。活动列保持挂载，输入草稿和键盘导航保留。单元格 memo 的失效输入包含值、列定义、诊断、搜索、语法编辑、差异展示和编辑回调；上下文继续响应选择、引用与插件代际变化。

## 后端与传输

Rust 构建文件快照时，在同一次字段遍历中按实际类型聚合列宽提示、复杂值标记、声明类型、标签、说明和下拉种类。前端列准备直接读取列描述；本地差异投影和演示夹具使用等价的 TypeScript 聚合。

`WireContext` 根据 schema 形状身份及影响注解的值结构缓存 `Arc<FieldAnnotation>`。结构键包含 Option 包装、枚举整数、多态实际类型、对象成员、数组形状及字典键；普通业务文本和数字不参与注解结构键。缓存限于一次查询上下文，跨代际共享由不可变 schema 形状缓存承担。

`FileRecordsTransfer` 在接收边界传输快照、共享注解描述表和逐行字段描述索引。每个描述只保存本节点元数据，子项、字典键与子字段通过索引引用先前描述。编码先复用 Arc 身份，再按内容合并独立但相同的描述。编码期间保留 Arc，确保分配地址不被复用。

前端 `decodeFileRecords` 一次恢复有向无环描述表，让引用相同描述的字段共享注解对象。字段值、坐标、容器位置、摘要和诊断保持完整。整数归一化仅复制发生转换的分支，保留未变元数据身份；i64 从字符串转换，拒绝已丢失精度的 JavaScript 数字。

单行写入继续返回变化行，前端保留其他行对象。完整刷新仍按 revision 接收完整值快照；注解共享属于响应内部共享，不承担撤销历史或跨 revision 的值等价判断。大数据搜索由现有后端搜索接口承担，文件视图中的即时筛选使用记录级投影缓存。

## 验证

生产构建滚动采样、快照字节量和两端处理成本见[优化验收](../archive/benchmarks/complex-table-optimized-2026-10-26.md)。滚动夹具同时覆盖初始标量视口和复杂内容可见视口。后端基准与浏览器基准串行运行。

浏览器回归覆盖缩放、列宽变化、长候选搜索与循环导航、屏外复杂列行高、有限预览、选择后完整编辑、窗口卸载后的展开恢复和屏外自动行高。传输回归覆盖共享子描述、不同实例的枚举整数、i64 精度、输入不可变性和真实快照内容往返一致。
