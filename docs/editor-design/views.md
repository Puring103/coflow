# 编辑器视图与设置

## 视图结构

每个业务文件和实际记录类型分别维护视图。内置记录、表格和源码视图使用保留的 `__` ID；自定义表格和图谱视图具有独立 ID、名称、kind 与字段配置。自定义 ID 不能使用保留前缀，名称最多 80 字符。单例使用内置视图，其他类型按图谱能力及已保存配置提供自定义视图。

表格视图的 columns 保存列顺序，图谱视图的 fields 保存展示字段，relations 保存可见关系字段；group_filter 限定记录分组。业务数据、单例、维度与 Git Diff 默认使用表格视图，记录视图提供详情浏览，源码视图提供原文件编辑。

内置视图与命名视图使用平铺标签，标签保留名称，新增入口为加号。视图标签通过指针拖动排序，也可用 Alt+左右方向键调整顺序。保存时清洗视图 ID、名称、字段列表、列宽与分组配置，渲染时按当前字段模型应用投影；当前视图不可用时选择适用的内置视图。插件视图使用插件贡献 ID 并由前端插件宿主管理生命周期。

项目打开后并行预加载记录、表格、源码三个基础视图的代码，预加载与视图渲染共享模块加载结果。其他视图在导航与悬停时预取目标模块，文件数据按需读取，与模块加载并行。异步加载边界分别覆盖工作区内容和 Git 侧栏，加载期间保留导航、文件标签与项目工具栏。源码视图独立于结构化记录显示，文件导航同时启动源码编辑器模块加载和源码读取。预取与源码视图按会话、项目代次和文件路径共享读取请求；保存冲突检测直接读取磁盘基线。文本到达后即可编辑，语义着色与诊断异步更新。

## 共享与本机设置

项目共享设置位于 `editor-setting/editor.json`，version 为 1，只保存团队同步的数据：

- graph_positions：视图或类型的节点坐标。
- short_name_fields：记录类型的缩略名字段。
- views：业务文件、类型与自定义视图结构。
- record_groups：记录分组及成员。

本机设置同样使用 version 1，位于用户数据目录下 `coflow/cfd-editor/projects/<规范化项目路径摘要>/editor.json`：

- graph_compact_modes：图谱紧凑显示。
- view_order：视图标签顺序。
- default_table_column_widths：默认表格列宽。
- view_column_widths：自定义视图列宽。
- table_row_heights：按文件、类型、视图和记录身份保存的个人行高。
- workspace：打开标签、当前标签、记录坐标和维度目标。

项目路径摘要使用规范化绝对路径的 SHA-256，隔离不同项目。共享设置和本机设置中的文件路径均相对于项目根目录，项目外同盘文件使用 `..` 表达；读取已有绝对路径时转换为相对路径，下次保存时写回；运行时路径在写入前转换为相对路径，无法转换的跨盘位置会报错。列宽只保存有限值并满足 48 的最小宽度。

读取只组合当前共享格式和本机格式，版本不匹配时返回诊断。共享字段变化才更新项目文件，个人展示变化只更新用户目录。设置写入采用同目录临时文件和原子替换。

## 工作区恢复与维度

工作区 wire 使用 file_path、type_name、view_id、view_kind、dimension_target 和 active_tab_id。恢复时验证文件、类型、记录坐标、视图与维度目标是否仍存在，再生成内部标签与路由。

维度标签使用虚拟文件入口 `@dimension/<name>/<filePath>`；dimension_target 保存维度名与实际来源文件路径。持久化时转换实际文件路径，按两者恢复标签身份。文件行与覆盖来源的组织见 [维度文件与写入](dimensions.md)。

## Git Diff

Git Diff 与基础模式共用文件树、表格、记录视图及字段树。文件树按文件和类型导航，维度覆盖按维度及实际来源文件组织，HEAD 独有的文件保留对应目录层级。基础记录与各维度覆盖分别比较，混合文件可同时提供基础数据和维度入口。

两端快照分别保留所属 schema 的字段 label、描述与嵌套字段展示信息。差异定位到对象字段、数组索引和字典键；变化子字段的祖先默认展开，表格前后版本和记录左右窗格共享展开状态。记录窗格按相同字段路径对齐行高与空白，并同步纵向滚动。

## 单元格交互

字符串输入包含合法的 `self.field` 或 `&Type::id.field` 插值时，编辑器自动保存显式 `f"..."` 模板；移除全部合法插值后保存普通字符串。其他花括号作为字面文本保留，与插值混用时在模板源码中转义。字符串类型由输入内容确定，不提供手动模式下拉。

字符串单元格始终保留同一个无边框输入节点，首次单击正文或单元格留白选中单元格，再次单击或双击进入编辑；Enter、F2 或直接输入字符也可进入编辑。选中态方向键在单元格间移动，编辑态方向键移动文本光标。未选中时按当前行高显示完整文本行；单行在行尾省略，多行在底部渐隐；选中或编辑时仅当前单元格以浮层按正文向下展开，整行与相邻单元格保持原行高。列宽变化时重新测量正文高度。Enter 提交，Shift+Enter 换行，Esc 撤销尚未提交的正文，失焦提交；中文输入法确认候选词不触发提交。

鼠标选择保持点击位置，拖选使用边缘自动滚动；键盘导航和外部定位负责显示目标单元格。每次定位取消上一帧尚未完成的定位请求。单元格渲染组件身份保持稳定，数据快照更新不会重新挂载输入节点，自动估算列宽仅随文件、类型或字段结构变化更新。保存期间继续输入的草稿保留，失焦提交不恢复旧输入焦点。

导航、撤销重做和新增记录使用图标入口，完整操作名称通过悬停提示与无障碍标签提供；文件名、字段名、自定义视图名和错误原因保留文字。维度单元格以 `↳`、`•`、`∅` 分别表示继承、覆盖和显式空值，恢复基础值使用撤销图标。

## 表格渲染

普通表格与维度表格均按视窗虚拟化行，分组行参与同一高度测量，键盘定位可滚动到尚未挂载的目标。普通表格的选区矩形每次选择只计算一次，可见单元格通过行列索引判断选中状态；详情批量选区使用坐标索引读取记录。未编辑字符串由 CSS 控制高度，只有正在编辑的字符串测量正文并监听宽度。

浏览器性能基准使用 `node editors/cfd-editor/frontend/tests/browser/table-performance.mjs`，固定视窗比较不同数据量下的挂载行数和全选响应中位数。浏览器交互测试覆盖未挂载行的键盘定位，以及目标模块延迟加载期间继续切换文件。

## 面板与确认

表格和图视图的详情编辑通过按需弹窗呈现，普通选择只更新当前选择。表格双击记录 ID 打开整条记录；复杂单元格双击空白处或点击左上角放大按钮打开当前字段，简单值保持原位编辑。详情弹窗复用 Inspector 的记录、字段、批量编辑与插件内容，正文独立纵向滚动，点击窗口外空白处关闭。关闭前等待真实写入结果，失败时保留草稿；关闭后恢复原视图焦点和选择。左侧导航和底部诊断面板收展时使用尺寸动画，拖动尺寸时直接跟随指针。放弃视图草稿使用独立模态确认框，继续编辑保留当前输入。

## 撤销与发布

共享的视图结构和图布局变更由 mutation history 串行维护；本机列宽、标签顺序与工作区状态按各自设置命令保存。维度编辑的写入、刷新及历史记录均使用实际覆盖来源文件；虚拟维度路径只标识界面导航。后端完成写入后返回当前设置或数据版本，前端仅接纳当前会话与 revision 的结果。

## 模块职责

core 的 settings/model 维护磁盘模型和路径转换，settings/io 负责原子读写与版本校验，settings/sanitize 负责配置清洗。SessionStore 的设置命令桥接 runtime 查询与持久化，Tauri 只适配命令和事件。

前端 workspaceTabs 管理标签和 wire 转换，views 管理内置与自定义视图，generation controller 接纳后端数据，mutation history 串行执行撤销和重做。wire.ts 为各领域 wire 工具的统一公共入口；图布局纯计算与 Worker 客户端各自独立。

桌面端的单元格与记录复制粘贴通过原生系统剪贴板接口完成，由应用能力配置授予文本读写权限。浏览器预览使用浏览器剪贴板接口。

图视图卡片以业务名称作为主标题，记录 ID 与类型独立显示为次级信息；未配置业务名称时以记录 ID 作为主标题。放弃视图设置的确认弹窗在视口居中显示。

## 数据编辑与引用面板

字符串与数值使用同一标量编辑组件。Enter 保存成功后回到单元格导航，Shift+Enter 在多行文本中换行，Tab / Shift+Tab 保存后按可见顺序移动。输入法确认不提交。Esc 取消未提交内容。表格选区中的 Ctrl+Enter 通过批量写入填充整个选区。保存失败保留草稿；文件、视图和引用面板导航等待草稿写入完成。

引用前的 & 符号打开可编辑记录浮层，正文区域打开目标选择器，不显示下拉箭头。浮层复用 Inspector、项目数据缓存和写入历史控制器；嵌套引用复用同一浮层的记录历史，返回按钮恢复上一条记录。打开所在位置是显式导航操作。关闭浮层恢复原视图焦点。文本编辑中的撤销由输入框处理，数据撤销沿用项目历史。

表格、记录树和 Inspector 的粘贴通过同一规划器执行。单个数组值可以接收多个源单元格，包括对象或字典内的嵌套数组、数组中以数组为值的元素。标量元素按可见行列顺序组合；对象元素按 schema 字段顺序构建。目标字段的类型决定粘贴形状，字典保持字典语义。普通矩形目标必须尺寸匹配，超出边界、只读或解析错误使该批规划失败。外部表格文本按引号规则读取制表符与单元格内换行。

表格内剪切先记录来源快照；粘贴时校验来源未变更，并在同一次批量写入中写入目标及清除来源。重叠目标优先保留粘贴结果。Esc 取消待剪切状态。普通复制保持来源不变。


基础视图默认按表格、记录、源码排序，保存的用户顺序优先。拖动标签时显示悬浮副本并即时预览排序，松手后保存。自定义视图通过标签右键菜单删除，基础视图保留。筛选和新增记录与视图标签位于同一容器同一行的右侧，详情弹窗独立于工具栏布局。表格和图视图的设置通过标签右键菜单打开。

图视图使用系统指针和统一线框工具图标。已有连线重连到空白处时，列表引用删除对应项，可空引用清空；必填引用通过目标选择保持有效值。节点字段投影与关系解析按未变化的节点身份复用。


引用浮层使用单一标题栏展示记录 ID 与配置的缩略名，保留一个关闭入口；嵌入的 Inspector 只渲染字段内容。表格文本编辑器覆盖当前单元格的完整宽度，从该格顶部向下扩展，其他单元格与行高保持不变。

全局搜索在关键词或模式变化时立即清除上一轮结果；新结果到达后允许打开。搜索弹窗中的 Esc 关闭弹窗并保留查询，键盘选择结果时自动滚动到可见位置。图画布和节点拖动统一使用系统普通箭头。


字符串预览保留完整正文，按单元格实际可见宽高检测溢出，仅在内容显示不全时叠加渐变遮罩省略提示。进入编辑使用点击处的字形位置放置光标，编辑区正文宽度与预览一致，滚动条不挤占正文。引用浮层标题沿用记录卡片的类型配色。

## 有限预览与个人行高

复杂单元格使用有高度边界的字段树预览，默认预览上限为 120px。溢出内容以底部渐隐和省略号提示，未选中时预览区域不设置内部滚动条；选中或编辑时向下展开，较长内容在展开区域滚动，保留整行高度。悬停或键盘聚焦时显示放大按钮；结构标题、叶子编辑控件和引用入口保持各自的点击行为。放大与关闭使用原单元格边界作为动效起止位置，系统减少动态效果时直接切换。

拖动行底边调整整行高度；双击底边按当前已展开内容适配，右键底边或对焦后的 Home 恢复默认；上下方向键调整高度。高度按记录身份绑定，排序不改变绑定关系，重命名同步迁移身份。拖动时更新本地预览，结束后串行写入本机项目配置；共享项目配置保持不变。


界面动效按交互用途区分：菜单与下拉列表快速淡入，独立窗口以轻量缩放和短距离抬升进入，操作提示柔和浮现，导航与诊断面板沿尺寸方向收展。单元格选中、原位展开、输入与拖动立即响应，不对正文施加位移动效。放大编辑保留从单元格到窗口的开合动画；系统启用减少动态效果时关闭装饰动效。


字段树按声明顺序生成一层结构摘要，引用沿用目标显示名称，深层对象和集合使用结构与数量提示。摘要仅在折叠时显示，展开后保留实际字段；数组序号置于右侧辅助位置，字典保留键。多态字段的实际类型固定显示于左侧标签后，展开和折叠不改变位置；摘要从右侧值区域左端对齐，结构片段自然排列，显示数量随列宽增加，宽度不足的完整片段计入 +N；简单列表直接预览元素；可写字段保留类型切换入口，只读字段显示类型文字。表格内折叠和展开使用相同的行距，弹窗通过外围留白提供空间；引用摘要和编辑控件共用图标、颜色与间距。
