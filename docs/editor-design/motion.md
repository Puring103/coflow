# 编辑器动效

动效表达内容来源、编辑层级和真实操作结果。输入、连续选区、拖动、列宽调整与图谱几何即时响应。文件切换、数据刷新和虚拟行挂载直接呈现最终内容。

## 参数

`frontend/src/style.css` 的 `--motion-*` 变量是 CSS 与脚本动画的共同参数来源。

| 用途 | 时长 | 曲线 |
| --- | --- | --- |
| 菜单与表面反馈 | 80ms | linear |
| 普通窗口进入、编辑内容显现 | 100ms | cubic-bezier(.2,0,0,1)；透明度使用 linear |
| 单元格来源展开 | 180ms | cubic-bezier(.2,0,0,1) |
| 窗口退出 | 120ms | cubic-bezier(.4,0,1,1) |
| 侧栏、诊断面板布局调整 | 140ms | cubic-bezier(.4,0,.2,1) |
| 到达与提交强调 | 1000ms | 前 600ms 保持，后 400ms 线性淡出 |

普通窗口只使用轻量位移与淡入淡出。字段折叠箭头旋转 120ms，子内容直接更新；虚拟表格行高、图节点端口与连线在同一几何状态下显示。手动调整面板尺寸时关闭过渡。

## 单元格放大编辑

来源保存单元格身份及所属表格，通过当前 DOM 解析可见边界。选中后的溢出预览使用当前表面边界，表头、冻结列和滚动容器遮挡区域从来源矩形中裁掉。键盘入口只有唯一选中单元格时使用来源；多选和通用入口使用普通窗口进入方式。

外壳拥有窗口位置、尺寸、边框、圆角和阴影。展开时正文按最终尺寸排版，仅在外壳中裁切，文字保持正常比例。外壳展开 180ms；遮罩与正文同步用 100ms 显现，点击后立即开始响应。完成后释放固定尺寸，恢复响应式布局。窗口显示记录身份和字段路径，批量编辑显示目标数量。

关闭顺序为提交当前草稿、确认写入成功、重新解析来源、退出、恢复焦点。提交期间冻结当前编辑会话，超过 200ms 显示保存状态；失败时恢复输入并保留草稿和错误提示。重复关闭请求合并为一次提交。

可见来源使用 120ms 收回；来源移出视口、被删除或失效时使用 80ms 淡出。快速关闭从当前视觉帧接续。成功修改过来源的窗口关闭后，对来源单元格强调一次；普通关闭保留选择状态。窗口尺寸或系统动态偏好变化时结束进行中的动画并应用最终布局。

遮罩、关闭按钮和 Esc 共用提交与退场流程；表格的选区外点击监听保留完整浮层上下文。

引用面板首次打开轻量上移进入；深入引用从右侧进入，返回时当前内容向右退出、上一层从左侧进入，遮罩持续保留。关闭整层时窗口与遮罩同步退场。记录数据刷新保持原位，系统减少动态模式直接切换。

`useInspectorMotion` 管理窗口动效和资源释放，`editSession` 保持草稿提交职责。`useSurfaceExit` 负责普通窗口的显式退场，窗口的业务确认与导航由调用方管理。

## 定位与操作反馈

搜索、诊断和引用导航先完成视图切换、字段展开与挂载，再定位并强调目标。诊断面板处于展开动画时等待布局落定。

- 目标已经可见时只强调。
- 同一滚动容器内、不超过一屏的移动使用最多 140ms 的单调减速。
- 长距离定位直接到达，然后强调。
- 滚轮、指针、键盘和新的导航请求取消旧自动滚动。
- 强调使用主题强调色；错误和警告继续由严重程度标记与文字表达。

`useMutationFeedback` 从已提交的撤销历史变化生成反馈，覆盖字段修改、集合修改、批量写入、记录操作和成功的撤销重做。只访问已挂载的展示行；正在编辑的控件和被模态层隔离的背景不播放成功强调。普通刷新、失败提交与失败撤销保持原状态。

表格新增记录在真实数据到达后选中并定位；当前筛选或分组隐藏记录时显示说明。删除在刷新数据确认成功后，将焦点交给相邻可见记录；删除最后一条时保留表格键盘焦点。

## 减少动态效果与验证

系统开启减少动态效果时，位移、缩放、淡入淡出、箭头旋转和平滑滚动直接完成。目标保留短暂静态边界，选择、焦点、保存与错误处理语义一致。

无界面浏览器回归位于 `editors/cfd-editor/frontend/tests/browser/motion.browser.mjs`，覆盖来源几何、文字尺寸、动画中关闭、保存失败、来源失效、窗口尺寸变化、到达强调、导航中断、提交反馈、表格增删定位和普通窗口退出。运行方式：在前端目录执行 `node --test tests/browser/motion.browser.mjs`。仓库开发门禁按根目录 `AGENTS.md` 执行。

## 结构展开与标签导航

普通字段树展开与收回使用 140ms 高度和透明度过渡，收回完成后卸载子字段。快速反向切换从当前高度接续；收起期间子字段不可交互，内部焦点返回结构标题。图谱字段保持几何即时更新，箭头传达展开状态，端口与连线保持同步。引用摘要所在标题保留 24px 的值区高度。

标签选中使用 140ms 底色平移，工作区正文仅在文件或视图身份变化时轻量显现，不重新挂载正文。普通数据刷新保持原位。点击工作区空白清除选择，详情窗口正常收回仍保留来源选择；清除选择前完成当前编辑提交。

侧栏活动按钮与文件树使用独立伪元素绘制选中底色，在旧位置与新位置之间以 140ms 布局曲线移动，图标、文字和命中区域保持静止。快速切换从当前底色位置接续；窗口尺寸或减少动态偏好变化时立即落定。

单个单元格切换使用独立选框在 80ms 内移动到新目标；连续切换从当前选框接续。多选区域保持即时更新。原位溢出预览在真实溢出测量完成后使用 180ms 裁切揭示，文字保持正常尺寸，表格行高保持固定。滚动、窗口尺寸变化或系统减少动态偏好变化会结束当前动画。简单单元格的值统一左对齐、顶对齐。

选中底色使用 CSS 主题变量实时解析，首次挂载和主题切换保持一致。

选中单元格时按冻结列右缘、表头下缘和滚动条占用空间计算有效视口，最小幅度滚动以显示目标；大于视口的单元格优先展示左上边界。复杂单元格字段树左侧保留 14px 选中走廊。简单列表省略标签轨道，原位预览和放大界面保持一致。

文件 Tab、视图 Tab、侧栏按钮与文件树选中底色共用平移动效，不缩放。单元格选框以目标尺寸平移，文字和正文保持原位。

记录拖动以当前可见整行作为不可交互的跟随预览，冻结列和各值列保持原有屏幕位置，原行降低透明度。落点与排序、分组规则由原有指针拖动流程处理；取消和卸载移除预览并恢复原行。

## 源码搜索与动画交接

结构化视图和源码视图共用同一工具栏节点和搜索框高度。结构化视图搜索记录，源码视图执行本文件不区分大小写的字面文本搜索，保留独立查询状态。源码搜索高亮所有匹配并显示当前位置与总数；Enter、Shift+Enter 和前后按钮循环导航，Esc 清空查询，Ctrl+F 聚焦搜索框。搜索不修改文档、编辑选区或撤销历史；编辑导致匹配变化时更新高亮，保持当前编辑视口。

选框覆盖层在挂载前固定起点，终点帧持续保留至真实选框恢复。底色伪元素在创建时设置起点，动画结束先恢复静态样式再取消填充帧，快速切换按当前视觉位置接续。移动底色不叠加透明度动画或背景颜色过渡。原位预览仅裁切揭示，并为阴影保留裁切外缘。

单元格原位展开时，选框高度与正文裁切共用相同的时间起点、180ms 时长和进入曲线，逐帧保持底边一致。单元格切换先完成选框平移，再同步展开选框与正文；首次选中直接同步展开。展开完成后在同一交接中恢复真实边框并释放裁切，快速切换和减少动态模式统一清理临时状态。

## 主视图与业务延伸视图

普通文件、源码、Git Diff 与维度视图共用 `ViewToolbar`、`ViewSearchField` 和 `ViewPicker`。固定业务标签省略管理和排序入口；标签切换保留工具栏实例及高度。Ctrl+F 聚焦当前工具栏搜索，Esc 清空查询。Git Diff 的结构化筛选与源码搜索分别保留状态，源码匹配按 HEAD、当前工作区的顺序连续导航，两侧都高亮匹配，仅当前匹配滚动定位。

主表格、Git Diff 表格与维度表共用 `EditableCell`、`useCellMotion`、`useTableSelectionDismiss` 及表格选框样式。复杂值使用同一溢出预览和 `InspectorPanel` 放大窗口；只读标量使用相同的文本测量与展开表面。维度记录内容使用 `CardHeader` 和 `DataCardExpanded`，各记录列表共用底色平移动效。源内容变化更新快照，不重播视图切换动画。

Git Diff 保留版本、差异标记、字段过滤和双侧对齐。表格投影为各版本分配独立展示身份，标题、插件上下文、放大窗口与记录引用复制使用原业务坐标。维度保留 default 只读、继承、显式空值、覆盖与清除覆盖规则；复杂值编辑先按结构化路径投影为完整字段，再通过维度写入入口提交。维度网格继续负责变体列、分组、矩形选区、剪贴板与虚拟行，内容容器保持有限高度。

维度网格的首击选择值、再次点击进入编辑；只读值与空白点击将焦点保留在网格。方向键从当前活动端点移动，Shift 连续扩选保留起点并移动终点。选中状态保留键列的 sticky 定位。导航与选框共用表格可见区域计算，只滚动当前网格，避开冻结列和表头；实际滚动立即释放屏幕坐标选框，避免旧位置残留。
