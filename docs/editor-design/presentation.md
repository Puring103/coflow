# 编辑器信息与视觉呈现

呈现层使用既有业务状态表达操作结果、内容范围与当前位置。保存、写入、撤销重做、筛选、导航和编辑控制器负责各自的时机与语义；样式和动效负责展示。

## 状态与通知

`ContentState` 统一展示加载、空内容、筛选无结果和失败。状态使用图标、标题与必要说明，加载和错误分别提供状态播报与警报语义。各调用方保留原有状态判定、内容切换和操作入口。

`FeedbackNotice` 将表格、记录、维度、检查器和项目操作提示放入同一通知区域，按消息自然高度纵向排布。普通提示、成功、警告、错误分别使用语义图标和边界色，文字保持完整换行。提示内容与显示周期由调用方管理，显示与更新保持当前编辑焦点。

源码保存状态使用独立宽度，文件路径在剩余空间内省略并保留完整路径提示。错误说明在编辑区上方完整换行，长内容在有限高度内滚动。磁盘冲突明确标识输入已保留，并保留使用磁盘内容、保留本地并覆盖、恢复项目与重试保存入口。

诊断栏显示错误、警告和信息数量；无诊断时显示明确说明。筛选区展示当前作用范围和显示数量，零结果明确标识为当前筛选下无诊断。日志与反馈面板使用编辑器语义主题色和共用控件样式，错误内容、时间、编号与导出操作具有独立层级。

## 视觉状态组合

表格的分组色与 Git 增删改颜色属于内容语义底色。悬停、拖动落点和选择以独立轻量叠色表达，单元格选区保留边框；差异边标、记录选择标记与诊断标记同时可见。冻结列继续保持不透明背景和固定位置。

字段类型与数组序号使用可读的次级文字；鼠标悬停、键盘焦点和字段选择均能显示相关操作。样式保持原有按钮位置、命中区域和键盘顺序。

关系图默认连线和节点采用克制的描边与阴影，悬停和选中关系使用更高对比度。明暗主题分别定义节点阴影；连线几何、端口尺寸、拖动命中路径与缩放规则保持一致。

## 验证

视觉组合覆盖亮色和暗色主题、悬停、记录与单元格选择、编辑、诊断和 Git 差异。交互验证覆盖通知与模态层、键盘焦点、保存失败、冻结列、虚拟行、连线拖动和减少动态模式。动效生命周期见 [编辑器动效](motion.md)，仓库门禁见根目录 `AGENTS.md`。
