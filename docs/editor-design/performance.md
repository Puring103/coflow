# 编辑器性能约束

## 数据结构

表格向 Inspector 传递视图行顺序、字段顺序与矩形边界。展示选区不展开单元格笛卡尔积；复制、清空、填充及批量写入在执行阶段枚举目标。实际写入使用记录坐标与字段路径，保留排序、筛选和隐藏字段规则。

Inspector 单遍聚合兼容类型、混合值与只读状态；不兼容类型立即结束聚合。范围聚合每行定位一次记录，直接读取字段，不创建逐格路径。兼容批量编辑器的身份根据选中行列集合确定，视图排序不改变同一目标集合的编辑身份。

记录数组保持展示顺序；按不可变数组身份共享坐标索引，字段查找复用后端的 `field_index`。快照更新创建新数组，旧索引随 WeakMap 键回收。Schema 字段顺序和字段形状在 Rust 会话代际内缓存。

## 后端统计

Rust 在构建文件记录快照的同一次遍历中，按实际类型汇总列的最大内容估宽、复杂值标记、声明类型、标签、说明和下拉种类。前端只结合标题、类型标签和控件边距确定初始列宽。内容估宽保留原来的 Unicode 宽度规则和 600px 上限；真实溢出仍由浏览器排版结果判断。用户调整后的列宽及保存时冻结列宽的行为保持不变。

本地 Git 差异投影和演示数据使用等价的 TypeScript 统计函数，常规后端文件快照直接使用 Rust 统计结果。

## 挂载与布局

表格虚拟化行，并按横向视口挂载标量和内置复杂编辑器。连续屏外列合并为保留总宽度的占位单元格。列分段由整张表共享，区间宽度从列宽前缀作差取得。屏外高度估算达到预览上限即停止，不统计省略尾部。活动列保留挂载，避免横向滚动丢失编辑草稿；展开路径由视图级存储保留。插件展示和差异展开内容保留实际挂载与测量。

字符串预览共用尺寸观察器。测量队列按帧合并，按读取行高、写入预览尺寸、读取溢出、发布状态的阶段执行，避免逐格交错读写触发重复同步布局。同一表格单元格支持多个观察订阅，卸载只移除对应订阅。

摘要统一调度精确测量，片段和计数尺寸按样式与内容共享，全部计算使用 CSS 逻辑像素。复杂预览的所有展开层级共用可见行预算，耗尽后不访问后续子树，省略尾部只添加溢出标记。选中后恢复完整编辑内容，由浏览器自动扩展单元格表面，整行高度保持不变。双击适配行高时才统计各可见列的完整展开高度，包括当前横向屏外列；折叠子树始终不参与统计。数据结构、失效规则及共享描述协议见[复杂表格设计](../development/editor-performance-review.zh-CN.md)。

## 图节点几何与窗口

图关系投影按不可变字段数组共享，端口、结构化路径、强制展开与追加入口使用同一索引。独立行几何模型保存所有展开逻辑行，以树状数组维护高度前缀；坐标查找和单行高度修改为 O(log R)，窗口查询只访问命中的兄弟区间和活动行。平移和缩放复用投影及几何，不重新展开字段树。

字段注解在传输时省略默认空值、空集合及 false。生成的 TypeScript 属性标记为可选，几何、关系投影与布局通过共享注解访问器读取默认语义；浏览器回归同时覆盖省略属性的真实传输形状。

节点保持完整外框尺寸，按画布视口和 180 个逻辑像素的 overscan 挂载内部行。屏外区间以等高空块占位；缩略模式卸载明细。全部端口坐标通过 React Flow 的公开 Node.handles 和 updateNode 接口提供，屏内端口保留交互 Handle。框架尺寸观察覆盖端口时，适配层在下一帧重新发布完整几何。连线按真实端口折线裁剪，两个端点均在屏外的穿屏线仍可命中和拖动；选择、筛选、布局和写入始终使用完整逻辑图。

连线发光使用视口附近的绘制路径，直线段裁剪到带余量的画布范围，二次曲线保留原有控制点与圆角。完整路径继续承担命中和线体拖动，端点及重连仍读取逻辑几何。该分离限制屏外超长线段参与滤镜计算的范围，保持屏内线形与发光样式。

固定形态的控件共享实测行高。只读文本逐行测量；未知高度使用每帧至多 12 个样本的屏外卡片测量队列，完成后统一更新外框和端口。活动编辑器及错误提示单独实测，避免把其临时高度传播给其他行。字体加载和主题样式变化使高度缓存失效，重新分帧测量。首次投影和全量端口发布仍随逻辑行数增长，长文本的全部精确几何需要额外测量时间。

焦点、输入法、指针操作和拖线会固定活动行及祖先。活动编辑或连接期间保留节点外壳，内部非活动行仍按窗口挂载；操作结束后恢复画布级节点裁剪。外部数组缩短、插入、多项替换或排列变化，以及本地删除/移动会结束原索引行的编辑身份，防止草稿写到另一元素。单项普通值更新与末尾追加保留输入 DOM、光标和草稿。移除逻辑节点时释放其几何和动作缓存；观察器、字体监听及待执行帧随视图销毁清理。

同一图视图的布局队列至多保留一个运行请求和一个最新等待请求。被替换的等待 Promise 明确结束，过期运行结果不发布；共享 ELK worker 不因单视图过期而终止。

## 查询缓存

当前 revision 的文件、源码、维度和图查询继续复用。旧 revision 的非活动查询及时释放；仍有观察者的查询保留到观察者退出。会话隔离和版本校验保持不变，撤销历史由修改历史控制器维护，不依赖查询缓存中的旧快照。

## 验证

图专项生产基准位于 `editors/cfd-editor/frontend/tests/browser/graph-acceptance.mjs`，覆盖首屏、连续平移缩放、密集边、复杂行、十万项压力、连续更新和视图回收。采样协议、原始数据与未达性能项见[核心增量与超大图节点验收](../archive/benchmarks/incremental-graph-acceptance-2026-10-26.md)。

生产构建基准位于 `editors/cfd-editor/frontend/tests/browser/performance.mjs`。基准同时覆盖窄表、宽表、Inspector 和百万单元格选区。滚动报告帧间隔与浏览器脚本/布局耗时；全选端到端计时包含两次动画帧等待，不能解释为纯 CPU 时间。

后端大工程基准使用 `editors/cfd-editor/core/examples/perf_smoke.rs`，与浏览器基准串行运行。功能回归覆盖编辑光标、独立单元格展开、粘贴、剪切失败保护，以及横向虚拟化期间的草稿和焦点保持。
