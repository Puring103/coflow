# 增量代次与复用边界

## 输入与存储

schema 编译身份、结构限制、记录身份、顺序及维度变体集合共同决定模型复用范围。模型保存不可变输入批次清单，通过批次 token 识别未变化输入；变化批次继续核对成员与来源。通用逐条输入执行完整核对。源码位置变化只更新来源，业务对象与维度值继续共享，旧代次保持不可变。

`coflow-storage` 提供共享分页容器。记录目录、来源目录和引用邻接表按 512 项分页，局部写入复制页目录与命中页。页目录复制仍随目录规模增长。引用边按宿主分块，相同引用块直接复用；批量变化按目标汇总入边修改，再恢复确定性顺序。

来源缓存保存实际文本、草稿、加载状态与诊断。内容相同则复用语法结果与健康模型；读失败不视为成功加载，mtime 和文件长度不替代内容核对。实际变化的 CFD 文件仍整份解析。

## 模型与维度

运行时比较变化输入的字段存储语义，向模型提供直接变化字段。模板依赖按宿主顶层字段维护正反向关系，包含嵌套字段及跨记录读取。无关字段不扩大读者闭包；维度上下文读取取并集，受影响记录完整重建并发布新读集，同值结果仍保守传播。

维度覆盖索引按宿主分页，共享未变化覆盖位置。批次目录保存 token 和键，从本次输入按需取得草稿；模型不保留覆盖草稿值树。新增、替换、删除及来源位置变化更新对应宿主，重复覆盖与无法证明可复用的输入执行完整构建。

纯字面量根在一次构建事务内复用真实节点与深度预算成本；预算不足时恢复正常遍历，保留失败路径。模板继续执行上下文验证。字段求值与字面量复用分别计数。

记录新增、删除、重命名、顺序或变体集合变化、被拒绝记录恢复，以及无法安全归并诊断的输入执行完整构建。完整构建与增量构建使用同一默认值、模板、引用和容错语义。

## 检查与 schema 计划

引用与内联 data-check 可达性计划绑定 schema 代次共享，覆盖继承、多态、递归类型、Option 与集合。无内联检查的分支跳过无意义枚举。`records(Type)` 的有序成员视图按需构建，身份稳定的字段更新复用该视图。

检查读集包含字段、引用来源与目标、失败查找、条件分支和维度访问。字段变化选择实际读取者，整条规则失效后重新求值；成员变化或不完整读集扩大失效范围。未变化读集共享，变化读集按差集维护反向索引。求值顺序、根预算、请求预算与未完成检查恢复规则保持语言契约。

## 写入与宿主

同一源码快照上的独立字段批次合并不重叠补丁，一次构造候选文本并验证语法和结构预算。顺序相关修改保留逐步错误与预算语义。解析候选降低为草稿后移交构建阶段；发布前继续核对磁盘基线。

运行时发布结果包含实际发布字节摘要或删除状态。宿主据此登记内部版本，外部变化由 watcher 核对实际内容；内部期望不从发布后的磁盘反读。源码 writer 使用中立值路径模块。事务保障见[路径与产物发布](paths-and-publication.md)。

编辑器候选计算在会话锁外完成，提交时验证 revision，旧代次在锁外释放。LSP 复用内容未变的文本、语法树、诊断和定义索引，保留未保存草稿及版本隔离。

## 验证与边界

确定性和固定种子混合操作逐步对照完整构建，比较字段、维度覆盖与来源、引用顺序、诊断、旧快照独立性和错误恢复。批量修改对照顺序修改，增量检查对照完整执行；预算耗尽单独验证失败位置与资源边界。

工作量计数区分身份核对、来源访问、字段求值、记录复用、引用维护与规则执行。完整重试成本计入端到端耗时。现有测量及尚未达到的性能目标见[性能验证](../development/performance-validation.md)。
