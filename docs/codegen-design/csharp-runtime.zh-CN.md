# C# 生成类型与完整数据构建

## 职责与交付边界

`coflow-codegen-csharp` 根据已编译 schema 生成普通业务类型、枚举、描述符和一次性构建回调。`Coflow.Loader` 解析 CFD、校验结构和值、解析稀疏覆盖、连接引用并计算模板。CFT 业务规则由 `coflow-checker` 执行，生成描述不携带规则执行器。

成功返回的配置根、记录、结构体、集合、维度容器和查询索引均已构建完成。最终对象图不持有 `LoadContext`、`BuildSession`、`CfdReader`、已绑定表达式或求值委托。业务读取和维度查询不启动构建、连接引用或计算模板。依赖程序集保持现有组织方式。

## 生成类型

| CFT | C# |
| --- | --- |
| table / singleton / data | partial class，保留 abstract、sealed 和继承 |
| @struct sealed data | partial struct，直接保存业务字段 |
| int / long / float / double / bool / string | 同名类型 |
| enum | int；@int64 使用 long |
| &Table | 直接业务对象引用 |
| Option<T> | 独立保留每层存在状态的 Option<T> |
| [T] / {K: V} | 完成构建的 IReadOnlyList<T> / IReadOnlyDictionary<K,V> |

业务属性为自动属性，提供公开 getter 与 internal setter；加载适配代码与生成类型位于同一程序集，构建完成后不再赋值。记录和单例具有只读 `id`，内联 data 的 `id` 是普通业务字段。结构体默认值采用 CLR 普通值语义，不持有读取器。Option 在存在标记之外通过装箱隔断递归结构体布局，`None`、`Some(None)` 和 `Some(Some(value))` 保持区别。

业务扩展使用独立 partial 文件。C# 关键字使用 `@` 转义，类型引用全局限定，无法表达的名称和生成成员冲突在生成时报告。枚举 ID 映射每个枚举只生成一次，稳定数字来自 enum lock；普通快照表与维度表均提供类型明确的 Get/TryGet 扩展。

## 对外数据形态

`CoflowData.Load(sources, options)` 返回 `LoadResult<CoflowData>`。配置根通过 `Table<T>()` 获取 `Table<Dimension<T>>`，通过 `Singleton<T>()` 获取 `Dimension<T>`。`.Base` 返回基础普通业务对象，`.For(dimension, variant)` 返回对应的已构建业务对象。

配置根的 `Base` 和 `For` 返回 `CfdSnapshot`。快照内 `Table<T>()` 返回 `Table<T>`，`Singleton<T>()` 返回普通 T。逐记录与整体查询引用同一上下文的同一业务对象，父表和派生表保持同一记录身份。

`Dimension<T>` 只保存结果数组、共享不可变选择目录和显式覆盖信息。单维查询使用维度与变体的索引；组合通过不可变 `DimensionSelection` 的规范键定位。组合顺序不影响结果，重复维度参数报错。`TryFor` 对未知或未构建选择返回 false，`For` 明确报告未知维度、未知变体或未构建组合。空选择取得基础结果。

`Variants(dimension)` 返回已加载的变体名称，包括空覆盖块声明的变体。`HasVariant(field, variant)` 判断源中是否显式赋值；显式 None、空字符串和同值覆盖都算存在，未绑定维度的字段报参数错误。元数据在加载时复制为纯数据，不保留字段描述或语法节点。

## 构建范围

加载默认构建基础上下文和输入中已声明的全部单维变体。`LoadOptions.Combinations` 指定附加多维组合；加载开始时验证名称，规范化并去重。组合不会自动扩展为笛卡尔积。所有请求上下文成功后才交付配置根；任一上下文的数据错误通过 LoadResult.Diagnostics 返回，不交付部分结果。无效加载选项作为参数错误报告。

## 构建过程与临时表示

1. 解析源文件，建立类型继承、记录身份和字段序号索引。
2. 绑定基础字段和实际覆盖；普通值与纯值集合只构造一次，未覆盖位置不分配覆盖值。
3. 为每个请求上下文创建构建会话；覆盖在读取器创建时解析为实际命中的字段索引。
4. 先创建记录对象并登记身份，再构建全部有效字段，执行生成的赋值回调。循环引用取得已登记身份，不重复创建记录。
5. 模板路径在绑定时解析为记录身份和字段序号；求值缓存与依赖栈只服务构建。内联对象、Option、数组和字典在该阶段全部完成。
6. 注册完整快照、维度容器、表与单例，交付后构建器、源节点、读取器及求值缓存均可回收。

`CfdType<T>` 使用 `create(id)` 与 `fill(value, reader)` 两个回调。fill 返回 T，使类和结构体使用统一赋值协议。生成回调仅使用字段序号，不通过成员反射读取或赋值。抽象类型不提供构造回调。

固定标量、字符串、纯值只读集合和完全固定的内联值可以共享。不同上下文的记录分别构建；不能仅凭本记录没有覆盖就共享记录，因为其模板或引用目标可能受覆盖影响。覆盖替换整个字段，不逐项合并集合。最终内存取决于请求上下文及其完整对象图，源覆盖稀疏不等于最终记录对象稀疏。

## 校验与诊断

缺失字段仅在有显式默认值时允许；Option 不自动补 None。普通字符串保留字面值，显式模板在各请求上下文中计算成 string。模板末端允许 string、数字、bool、枚举；不能穿过 Option 或以复合值为末端。self 指向所属记录或内联 data，集合元素继承所属对象。

已知变体未覆盖的字段使用基础表达式，并在目标上下文求值。普通记录引用环合法，模板依赖环报告 CFD-INTERPOLATION-CYCLE。内联对象绑定和动态模板求值各具有 256 层限制，固定终值不计入动态求值深度。普通记录引用只连接预创建身份，不递归填充目标，不消耗模板深度预算。包括显式多维组合在内的错误均在加载时报告；失败结果不允许访问 Data。

读取已交付的只读数据不使用会话锁；多线程调用方负责安全发布和替换数据根，并避免通过同程序集 partial 代码修改配置字段。重新加载生成独立对象图，旧对象不会切换到新上下文。

## 验证

Rust 与 C# 共享 parser/runtime parity 夹具，生成集成项目实际编译业务类型并验证结构体、继承、枚举 ID、引用、模板和维度数据。C# 测试验证预构建组合、加载期失败、对象身份、并发读取、动态集合零热读取分配，以及最终对象图不保留构建状态。当前门禁见 [AGENTS.md](../../AGENTS.md)，性能验证约束见 [性能验证](../development/performance-validation.md)。
