# 函数与表达式

> 状态：语言设计
>
> 范围：函数、self、局部变量、控制流、运算符和内建调用。

## 1. 函数值与 self

```text
function-literal := "fn" "(" [ named-param { "," named-param } [ "," ] ] ")" "->" type block
named-param := identifier ":" type
```

函数类型由参数类型序列和返回类型决定，参数名不参与签名相等。
用户函数没有泛型参数，内建方法可以由编译器提供泛型签名。

```cft
table Item {
  price: int;

  total: fn(count: int) -> int => {
    self.price * count
  };
}
```

- self 是函数所属对象，只读；字段通过 self.field 访问。
- 取出 `item.total` 后仍绑定 item，保存或传递不会换绑对象。
- 普通函数需要其他记录时，使用显式参数。
- 普通常量函数没有隐式 self，不继承调用方的当前记录。
- CFT 默认实现和 CFD 实现使用同一调用规则；CFD 只改变具体对象最终使用的实现。

### 1.1 创建位置与绑定

函数和 fstring 在创建时确定 self。绑定规则同时适用于 CFT 默认值、CFD 字段值和函数内对象构造。

| 创建或使用位置 | self 的来源 |
| --- | --- |
| 对象字段中直接声明的函数或 fstring | 正在初始化的所属对象 |
| 字段的数组、字典或可选值中直接声明的函数或 fstring | 该字段所属对象；集合和可选值不建立新的对象上下文 |
| 嵌套对象自身字段中直接声明的函数或 fstring | 该嵌套对象 |
| 函数体内创建的普通局部闭包或局部文本函数 | 捕获创建位置的外层 self |
| 已有函数值或文本模板存入另一对象、集合或局部变量 | 保持原有绑定 |
| 维度基础值及覆盖值中直接声明的函数或 fstring | 原业务对象，具体规则见[维度](./09-维度.md) |

新对象字段中的函数字面量和 fstring 按新对象的上下文检查 self。
访问外层对象时，先把外层 self 保存到局部变量，再在新字面量中捕获该变量。
普通字段初始化表达式仍按其所在的外层表达式作用域求值。

```cft
data Other {
  name: string;
  text: fstring;
  read: fn() -> string;
}

table Item {
  name: string;

  make: fn() -> Other => {
    var owner: Item = self;
    var readOwner: fn() -> string = fn() -> string { self.name };
    Other {
      name: "Other",
      text: f"{self.name} / {owner.name}",
      read: readOwner,
    }
  };
}
```

当 Item.name 为 `"Item"` 时，返回对象的 text 读取得到 `"Other / Item"`。
readOwner 在 Item 的函数体中创建，放入 Other.read 后仍绑定原 Item，调用得到 `"Item"`。
text 里的 owner 按普通捕获规则保存，self 则绑定新建的 Other。

## 2. 闭包与生命周期

- 函数可以保存、返回、放入集合和跨宿主边界传递。
- 闭包按值捕获实际使用的外层参数和局部值，捕获值只读。
- 使用 self 时保留所属对象的只读引用，不复制整个对象。
- 后续给外层局部变量赋值，不改变已有捕获值。
- 常量按只读定义访问，不进入普通局部捕获环境。
- 函数值绑定所属 Runtime。Runtime 释放后调用报失效错误。
- 对象、集合和函数句柄由宿主保活；运行时临时值按可达性回收，允许引用环。
- 独立复制出的普通标量和字符串不依赖 Runtime。携带记录、函数或文本函数的值不能跨 Runtime 隐式混用。

## 3. 语句和作用域

```text
block := "{" { statement } [ block-tail ] "}"
statement := var-stmt | assign-stmt | return-stmt | break-stmt
           | continue-stmt | while-stmt | for-stmt | expr-stmt
var-stmt := "var" identifier ":" type "=" expression ";"
assign-stmt := identifier assignment-op expression ";"
assignment-op := "=" | "+=" | "-=" | "*=" | "/=" | "%=" | "//=" | "**="
               | "<<=" | ">>=" | "&=" | "|=" | "^="
return-stmt := "return" [ expression ] ";"
break-stmt := "break" ";"
continue-stmt := "continue" ";"
while-stmt := "while" expression block
for-stmt := "for" identifier [ "," identifier ] "in" expression block
expr-stmt := if-expr [ ";" ] | expression ";"
block-tail := expression
```

- block 最后的表达式产生 block 值。没有尾表达式时为 unit。
- if 作为语句可省略分号；位于 block 末尾时产生 block 值。
- 同一作用域禁止重复声明局部变量，参数与函数最外层局部变量也不能同名。
- 内层块可以遮蔽外层局部变量。self 始终保留。
- 变量声明后类型固定，只允许给局部变量赋值，不允许修改参数、捕获值、对象字段或集合。
- var 局部变量声明必须显式写出类型。初始化表达式按声明类型检查，不从初始化值推断变量类型。
- for 和 Some 引入的绑定变量由已知输入类型推断，保留不带类型标注的绑定写法。
- 复合赋值先执行对应运算，再检查结果能否写回原变量，不做额外的数值收窄。
- return 结束当前函数；已终止的路径不参与后续类型合并。
- 每个可到达的函数出口必须符合返回类型。
- None、空数组和空字典按声明、参数或返回值提供的明确期望类型检查。

## 4. 表达式文法

```text
expression := literal | qualified-name | "self" | reference-value
            | paren-expr | field-access | index-access | call
            | array-expr | dict-expr | object-expr | unary | binary
            | is-expr | propagate | if-expr | function-literal | return-expr
literal := int-literal | float-literal | bool-literal
         | string-literal | fstring-literal | "None" | unit-literal
unit-literal := "(" ")"
paren-expr := "(" expression ")"
field-access := expression "." member-name
member-name := identifier | reserved-member-name
index-access := expression "[" expression "]"
call := expression "(" [ expression { "," expression } [ "," ] ] ")"
array-expr := "[" [ expression { "," expression } [ "," ] ] "]"
dict-expr := "{" [ expression ":" expression { "," expression ":" expression } [ "," ] ] "}"
object-expr := qualified-name "{" [ expr-field { "," expr-field } [ "," ] ] "}"
expr-field := identifier ":" expression
unary := ( "!" | "~" | "-" ) expression
binary := expression operator expression
is-expr := expression "is" ( qualified-name | "Some" "(" identifier ")" )
propagate := expression "?"
if-expr := "if" expression block [ "else" ( if-expr | block ) ]
return-expr := "return" [ expression ]
```

`reserved-member-name` 是成员位置允许的保留名称，例如 id、for、default、int。
运算符见 §7；引用值使用[CFD 数据](./05-CFD数据.md)中的统一语法。

表达式位置的 `{ ... }` 是字典。if、while 条件和 for 头部之后的顶层花括号是语句体。
这些位置若以对象构造结尾，应加括号消歧。

## 5. 条件、可选值和收窄

```cft
data Lookup {
  choose: fn(enabled: bool) -> int? => {
    if enabled { 1 } else { None }
  };
}
```

- if 条件必须为 bool。
- 分别检查每个可到达分支能否赋给明确的期望类型，不通过分支合并推断结果类型。
- 缺少 else 时，成功分支必须为 unit 或直接终止。
- `is TypeName` 是 bool 判断，在 if/while 条件成立的范围内提供子类型信息。
- 变量重新赋值后撤销此前的类型收窄，按声明类型重新检查。
- 收窄保留于局部变量、参数、self 及以它们为根的只读普通字段路径；根变量重新赋值时，同时撤销其字段路径上的收窄。
- 函数调用、索引计算和动态文本读取不属于稳定路径，不因 is 检查自动缓存结果。需要复用时先保存到显式声明类型的局部变量；`getItem() is Sword` 不改变第二次 `getItem()` 的类型或结果。
- `is Some(value)` 引入只读解包值，可以用于同一条件中后续的 && 部分和成功分支。
- Some 绑定的类型取自被检查可选表达式的内容类型；例如 int? 解包得到 int，写作 `is Some(number)`。
- 括号只分组，不改变绑定。`||` 和 `!` 不向外提供该绑定。
- `value?` 只在返回可选类型的函数中传播 None；独立嵌套函数有自己的返回边界。
- fstring 插值不能向外传播 ? 或 return，也不能向外 break/continue。

## 6. 循环与读取

```cft
data Counter {
  sum: fn(values: [int]) -> int => {
    var total: int = 0;
    for index, value in values {
      if value < 0 { continue; }
      total += value;
    }
    total
  };
}
```

- for 只遍历数组和字典；数组单绑定为值，双绑定为索引和值；字典必须绑定 key 和 value。
- for 绑定从集合类型确定：数组索引为 int，字典 key 使用声明的 key 类型，值使用元素的普通读取类型。
- 例如 `[int]` 的 `for index, value in values` 中两者均为 int；`[Item]` 的 item 为 Item；`[fstring]` 的元素绑定为 string。
- 数组按元素顺序遍历；字典按原始 CFT/CFD 声明顺序遍历，函数内构造的字典按字面量书写顺序遍历。
- break 和 continue 属于当前函数中最近的循环，不能跨函数使用。
- while/for 不产生业务值，返回函数结果使用 return。
- 数组、字典索引返回相应值，缺失索引或 key 产生执行错误。
- 字符串按 Unicode 码点索引，索引从 0 开始，返回一个完整码点组成的 string；负索引或越界产生执行错误。
- 普通读取具体 fstring 值时生成 string；明确要求 fstring 的位置保留模板。获取集合不执行其中的文本函数。
- 临时对象只构造 data，使用其字段类型、默认值和引用规则；data 不定义 check。

## 7. 运算符

| 类别 | 运算符 | 类型与结果 |
| --- | --- | --- |
| 逻辑 | !、&&、\|\| | bool，&& 和 \|\| 短路 |
| 相等 | ==、!= | 按类型与值中的相等规则 |
| 顺序比较 | <、<=、>、>= | 数值、同一 enum、string |
| 算术 | +、-、*、** | 两个 int 得到 int，混合数值提升为 float |
| 字符串连接 | + | 两侧为 string |
| 真除法 | / | 数值，结果为 float |
| 整数除法、余数 | //、% | int |
| 移位 | <<、>> | int |
| 位运算 | &、\|、^、~ | int 或同一 flag 类型 |
| 类型判断 | is | 对象、记录引用或可选值 |

- int 使用 checked 32 位运算，溢出报错。
- float 使用 IEEE 754 binary32。混合数值比较也把 int 提升为 float。
- int 的 // 向零截断，% 的符号跟随被除数；分母为零报错。
- float 除零遵循 IEEE 754，得到无穷或 NaN。
- 移位位数为 0—31；右移为算术右移，左移按 32 位截断。
- int 幂的负指数报错；i32 最小值取负或取绝对值报错。
- flag 使用全部 32 位；~ 只翻转已声明位，未知位构造报错。
- enum 不与 int 隐式转换；普通 enum 的显式构造接受非负 int。
- 字符串按 Unicode 码点序列进行与区域设置无关的字典序比较：从左到右比较码点数值，前缀相同时较短字符串在前。
- 链式比较如 a < b < c 不合法。

从高到低的优先级：

1. 成员、索引、调用、可选传播：.、[]、()、?
2. 一元：!、~、-
3. 幂：**，右结合
4. *、/、//、%
5. +、-
6. <<、>>
7. &
8. ^
9. |
10. ==、!=、<、<=、>、>=
11. is
12. &&
13. ||

其他二元运算从左到右结合；连续 ? 不合法。

## 8. 求值顺序与常量优化

- 普通操作数、调用目标及参数按源码从左到右求值。
- 短路逻辑和 if 只执行选中的分支；require 按普通 Host 调用立即求值全部参数。
- fstring 插值从左到右，每处一次；两次字段读取是两次计算。
- CFT 编译时尽量把确定的计算变成常量。输入未知、优化预算耗尽或尝试求值出错时保留原计算。
- 优化不执行 Host 调用，不提前产生 check 报告，不改变函数身份和动态读取次数。
- 优化预算与执行预算分开。正常常量声明所需的固定值仍必须在编译时确定。
- CFD 不重新折叠或修改 CFT 契约，只编译自己的内容。

## 9. 内建方法与转换

通用内建方法遵循下述规则，当前实现范围见[当前实现范围](../2-架构/00-当前实现范围.md)。

| 方法 | 适用类型 | 结果 |
| --- | --- | --- |
| len() | string、数组、字典 | Unicode 码点数或集合元素数，int |
| contains(x) | string、数组、字典 | 子串、元素或 key 是否存在 |
| isUnique() | int、bool、string、enum 数组 | bool |
| min() / max() | int、float、enum 数组 | 元素类型 |
| sum() | int、float 数组 | 元素类型 |
| keys() / values() | 字典 | 按字典保存的源码声明顺序返回数组 |
| matches("pattern") | string | 正则匹配，pattern 为普通字符串字面量 |
| startsWith(x) / endsWith(x) | string | bool |
| isBlank() | string | 空文本或全为 Unicode 空白 |
| abs() | int、float | 原数值类型 |
| isFinite() | float | bool |
| isSome() / isNone() | 可选值 | bool |
| approxEqual(other, epsilon) | float | 绝对误差比较；epsilon 有限且非负 |
| containsKey(x) / containsValue(x) | 字典 | bool |
| isSorted() / isStrictlySorted() | 可排序标量数组 | bool |
| intersects(x) / isDisjoint(x) | 支持集合比较的标量数组 | bool |
| isSubsetOf(x) / isSupersetOf(x) | 支持集合比较的标量数组 | bool |
| for(variant) / default() / variants() | 维度记录 | 指定变体、基础值或全部变体的有效值；详见[维度](./09-维度.md) |

高阶方法使用以下签名。T、K、V、R、U 和 Read 仅为文档中的类型记号，
不是用户声明语法。Read(T) 表示普通读取类型：fstring 为 string，fstring? 为 string?，
其他类型保持不变，不递归转换集合中的模板。回调参数和返回类型按函数声明规则显式写出。

| 方法 | 数组 `[T]` | 字典 `{K: V}` |
| --- | --- | --- |
| map(callback) | callback: fn(Read(T)) -> R，返回 `[R]` | callback: fn(K, Read(V)) -> R，返回 `[R]` |
| filter(predicate) | predicate: fn(Read(T)) -> bool，返回 `[T]` | predicate: fn(K, Read(V)) -> bool，返回 `{K: V}` |
| fold(initial, callback) | callback: fn(U, Read(T)) -> U，返回 U | callback: fn(U, K, Read(V)) -> U，返回 U |
| any(predicate) / all(predicate) | predicate: fn(Read(T)) -> bool，返回 bool | predicate: fn(K, Read(V)) -> bool，返回 bool |

fold 的初值与累计结果均按回调明确声明的 U 检查，累计值为第一个回调参数。
数组按元素顺序、字典按保存的键值项顺序调用回调。map 按此顺序保存回调结果；
filter 保留入选项的原存储值及相对顺序，不改变容器类型。
数组回调不接收索引，需要索引时使用 for 的索引绑定。
any 在首个 true 后停止，all 在首个 false 后停止；后续元素不读取、不执行模板或回调。
空集合 map、filter 返回对应空容器，fold 返回初值，any 为 false，all 为 true，均不调用回调。
读取元素或执行回调出错时，方法停止并传播执行错误，不返回部分结果。
fstring 元素及字典 values() 遵循[集合操作中的模板](./03-类型与值.md#55-集合操作中的模板)。

空数组 min()、max() 返回执行错误，sum() 返回对应数值类型的 0。
float 数组的 min()、max()、sum() 遇到 NaN 返回 NaN；
isSorted()、isStrictlySorted() 遇到 NaN 返回 false，包括仅含一个 NaN 的数组。

matches("pattern") 使用 Rust regex 语法，默认判断是否存在匹配子串，整串匹配使用 ^ 和 $。
模式必须是普通字符串字面量，在编译时验证；支持 Unicode，不支持反向引用或环视。
内建方法在执行阶段求值，工作量计入当前执行链预算。

声明字段优先于同名内建方法。遍历和内建处理的工作量计入当前执行预算。

字符串的长度、索引和比较共用 Unicode 码点规则。这里的码点为 Unicode 标量值，
不包含代理项；一个补充平面字符计为一个码点，组合字符序列按其实际码点数处理。
字符串保持原有序列，不自动进行 Unicode 规范化。

| 表达式 | 结果 |
| --- | --- |
| `"😀".len()` | 1 |
| `"😀"[0]` | `"😀"` |
| `"e\u{301}".len()` | 2 |
| `"e\u{301}"[1]` | 单个 U+0301 组合重音组成的 string |
| `"é" == "e\u{301}"` | false，两侧码点序列不同 |
| `"\u{E000}" < "\u{10000}"` | true，按码点数值比较 |

UTF-8 字节位置用于源码定位，UTF-16 位置可用于宿主编辑协议；两者都不改变语言层的字符串索引单位。

| 转换 | 来源 | 结果与失败方式 |
| --- | --- | --- |
| .int() | float | 向零截断；NaN、无穷或越界报错 |
| .float() | int | float |
| .string() | int、float、bool、enum | 与区域设置无关的规范文本 |
| .parseInt() | string | int?，失败为 None |
| .parseFloat() | string | float?，失败为 None |
| EnumName(int) | int | 普通 enum 非负值；flag 还检查未知位 |

parseInt()、parseFloat() 完整匹配输入，不自动去除空格，接受正负号。
整数使用十进制；浮点支持小数和指数形式，以及 inf、-inf、NaN。
不符合格式的输入按解析失败返回 None。
string() 与插值共用数字输出规则：小数点为 .，无千位分隔，
float 使用能还原原 binary32 值的最短文本，保留负零，不受宿主区域设置影响。

## 10. 执行环境

同一 Runtime 同时只执行一条调用链。同线程同步重入共用顶层调用预算。
另一线程在执行链活跃时调用，立即返回 Runtime 忙执行错误，不在内部等待。
Runtime 空闲后允许换线程使用，不固定归属于创建线程。
普通调用、间接调用、Host 调用和 fstring 读取使用相同的执行错误处理。

Host 函数按正常调用执行，可能有外部副作用。未处理的 Host 异常转为绑定调用位置的执行错误。
预算限制核心内执行工作，不能强制终止阻塞的 Host 函数。
