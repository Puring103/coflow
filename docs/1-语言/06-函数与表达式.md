# 函数与表达式

> 状态：语言设计
>
> 范围：CFT/CFD 共享的函数值、闭包、表达式、局部变量、控制流、运算符和内建方法。

CFT 与 CFD 的函数体、check 体使用同一套表达式和函数执行语义。

## 1. 函数值

```text
function-literal := "fn" "(" [ param { "," param } [ "," ] ] ")" "->" type block
param            := identifier ":" type
```

```cft
type Calculator {
  classify: fn(value: int) -> string => {
    if value >= 10 { "large" } else { "small" }
  };
}
```

```cfd
calculator: Calculator {
  classify: fn(value: int) -> string {
    if value >= 10 { "large" } else { "small" }
  },
}
```

```text
CallableValue
├── Signature
├── DirectFunction
│   └── function identity
├── Closure
│   ├── function identity
│   └── captured values
└── HostFunction
    └── configured host binding
```

- CFT 声明函数签名，普通函数字段可以同时声明默认 body；默认 body 用 `=>` 省略重复签名，也可用完整 `= fn(...) -> ...` 写法。CFD 提供同字段函数值时覆盖默认实现。
- `@Host` 函数可以声明默认 body，CFD 不能为其提供实现；宿主绑定优先覆盖默认实现。
- 函数签名由参数类型序列和返回类型组成，参数名不参与签名相等性或调用 ABI。
- 用户函数不能声明泛型参数；内建集合方法可以具有编译器提供的泛型签名。

## 2. 闭包

- 闭包是一等函数值，可以返回、保存和跨边界传递。
- 闭包只按值捕获实际使用的外层参数和局部值，捕获值不可修改。
- 无捕获匿名函数可以直接表示为函数引用。
- 编译期完成捕获分析。
- 所有全局量都是常量，可在编译期内联或从只读常量存储读取，不进入捕获环境。
- 函数引用与其所属执行环境生命周期绑定；执行环境释放后，既有函数引用调用返回失效错误。
- 不同执行环境的执行值不能隐式混用。
- 纯数据经类型验证后深拷贝导入；带有函数身份或闭包环境的值保持所属执行环境，跨环境调用返回失效
  fault。
- 运行期闭包、集合和其他动态值按可达性跟踪回收，允许循环引用，不会无限保留到进程结束。
- 同一执行环境同时只执行一条调用链，支持同线程同步重入并沿用顶层执行预算。

## 3. block 与 statement

```text
block         := "{" { statement } [ expression ] "}"
statement     := var-stmt | assign-stmt | return-stmt | break-stmt | continue-stmt
               | while-stmt | for-stmt | expr-stmt
var-stmt      := "var" identifier [ ":" type ] "=" expression ";"
assign-stmt   := lvalue ( "=" | "+=" | "-=" | "*=" | "/=" | "%=" | "//=" | "**=" | "<<=" | ">>=" | "&=" | "|=" | "^=" ) expression ";"
return-stmt   := "return" [ expression ] ";"
break-stmt    := "break" ";"
continue-stmt := "continue" ";"
while-stmt    := "while" expression block
for-stmt      := "for" identifier [ "," identifier ] "in" ( range | expression ) block
range         := expression ( ".." | "..=" ) expression
expr-stmt     := expression ";"
lvalue        := identifier
```

- block 由零个或多个 statement 组成，并可由最后一个未加分号的表达式产生 block 值。
- 局部变量通过 `var` 引入，声明后类型固定。
- 赋值只允许写入局部变量。
- 复合赋值先按普通运算符完成类型检查，再写回同一局部变量；结果必须可赋给变量声明的类型，不做提升或收窄。
- 显式 `return` 立即结束当前函数。
- 一个可到达函数出口的路径必须产生声明返回类型；已经终止的路径不参与后续表达式的类型合并。
- `for` 的头部可以是 `range`，或产生 list、dict 的表达式。

```cft
type Counter {
  step: fn(start: int) -> int = fn(start: int) -> int {
    var total = start;
    total += 1;
    total
  };
}
```

```cft
type Search {
  find_first: fn(values: [int], target: int) -> int? = fn(values: [int], target: int) -> int? {
    var index = 0;
    while index < values.len() {
      if values[index] == target {
        return index;
      }
      index += 1;
    }
    return None;
  };
}
```

## 4. 表达式

```text
expression   := literal
              | path
              | field-access
              | index-access
              | call
              | construction
              | unary
              | binary
              | if-expr
              | match-expr
              | lambda
              | return-expr
literal      := int-literal | float-literal | bool-literal | string-literal | "None"
path         := qualified-name
field-access := expression "." identifier
index-access := expression "[" expression "]"
call         := expression "(" [ expression { "," expression } [ "," ] ] ")"
construction := array | dict | object
array        := "[" [ expression { "," expression } [ "," ] ] "]"
dict         := "{" [ expression ":" expression { "," expression ":" expression } [ "," ] ] "}"
object       := qualified-name "{" [ field-init { "," field-init } [ "," ] ] "}"
field-init   := identifier ":" expression
unary        := ( "!" | "~" | "-" ) expression
binary       := expression operator expression
if-expr      := "if" expression block [ "else" ( if-expr | block ) ]
match-expr   := "match" expression "{" match-arm { "," match-arm } [ "," ] "}"
lambda       := "fn" "(" [ param { "," param } [ "," ] ] ")" "->" type block
return-expr  := "return" [ expression ]
```

`block` 只出现在 `if`、`while`、`for`、函数体和 match arm；表达式位置的 `{ ... }` 一律是字典。
在 `if`/`while` 条件、`for` 头部和 `match` 被匹配位置，头部表达式解析完成后出现的顶层 `{` 一律作为
body/block；这些位置若需要以对象构造结尾，必须加括号，例如 `for x in (make(Item { hp: 1 })) { }`。

### 4.1 字面量与路径

```cft
type Demo {
  f: fn(item: Item) -> Item? = fn(item: Item) -> Item? {
    var owner: Item? = None;
    var present: Item? = item;
    present
  };
}
```

- 可选值构造直接写 `None` 或裸存在值，不使用包装。
- 可取出的只有裸值本身；`Some` 只用于匹配。
- 在返回 `T?` 的函数体内，表达式后缀 `?` 传播 `None`：表达式为 `None` 时整个函数立即返回 `None`。

### 4.2 字段、索引与调用

```cft
type Demo {
  f: fn(item: Item, index: int) -> int = fn(item: Item, index: int) -> int {
    item.stats.hp + item.tags[index].len()
  };
}
```

### 4.3 构造

```cft
type Demo {
  make: fn() -> Stats = fn() -> Stats {
    Stats {
      hp: 100,
      tags: [weapon, rare],
      attrs: { "attack": 10 },
    }
  };
}
```

### 4.4 一元与二元

```cft
type Demo {
  f: fn(value: int, flag: bool) -> int = fn(value: int, flag: bool) -> int {
    var a = -value;
    var b = if flag { 1 } else { 0 };
    var c = ~value;
    a + b + c
  };
}
```

### 4.5 if

```cft
type Demo {
  f: fn(value: int) -> string = fn(value: int) -> string {
    if value >= 10 {
      "large"
    } else if value > 0 {
      "small"
    } else {
      "none"
    }
  };
}
```

`if` 条件必须是 `bool`；两个有值分支必须产生相同静态类型。缺少 `else` 时 then 分支必须是 unit（不产生值），否则报错。

### 4.6 match

```text
match-arm     := pattern "=>" ( expression | block )
pattern       := literal-pattern | bool-pattern | enum-variant
               | "None" | "Some" "(" identifier ")"
               | type-pattern | binding-pattern | "_"
literal-pattern := int-literal | float-literal | string-literal
type-pattern  := qualified-name
```

```cft
type Demo {
  f: fn(rarity: Rarity, owner: Item?) -> string = fn(rarity: Rarity, owner: Item?) -> string {
    match rarity {
      Common => "common",
      Rare => "rare",
      _ => "other",
    }
  };
}
```

```cft
type Demo {
  f: fn(owner: Item?) -> int = fn(owner: Item?) -> int {
    match owner {
      Some(item) => item.level,
      None => 0,
    }
  };
}
```

- `match` 在编译期检查 pattern 与被匹配值的类型，并要求表达式位置上的分支穷尽。
- pattern 依据被匹配值的静态类型解析：enum 值匹配变体，object 值匹配类型。
- pattern 绑定只在对应 arm 内可见。
- `=>` 同时用于 match arm 和 CFT 函数字段默认体，两者语法位置不相交。

### 4.7 控制流循环

```cft
type Demo {
  sum: fn(values: [int]) -> int = fn(values: [int]) -> int {
    var total = 0;
    for index, value in values {
      if value < 0 {
        continue;
      }
      total += value;
      if total > 1000 {
        break;
      }
    }
    total
  };
}
```

- range `for` 按整数顺序迭代，并区分开区间 `..` 与闭区间 `..=` 终点。
- list `for` 按稳定整数顺序读取元素。
- dictionary `for` 使用只读集合的稳定枚举快照。
- `for` 只接受 range、list 和 dict；其他类型报错。
- 双绑定的顺序固定为 `(索引或 key, 值)`；list 允许单绑定表示元素，dictionary 必须双绑定，range 单绑定表示索引。
- `break` 和 `continue` 只在最近循环内有效。
- 循环表达式结果是 unit；从循环返回函数值必须使用 `return`。
- 循环和高阶集合操作受执行预算约束。

## 5. 运算符

运算符由 operand 静态类型决定，不执行运行时重载搜索。

| 类别 | 运算符 | 支持的值 |
| --- | --- | --- |
| 逻辑 | `!`、`&&`、`||` | `bool` |
| 相等 | `==`、`!=` | 相同或兼容类型 |
| 顺序比较 | `<`、`<=`、`>`、`>=` | 数值（混合时提升为 `float`）、同一 enum、`string` |
| 算术 | `+`、`-`、`*`、`**` | 两侧同为 `int` 时为 `int`；混合数值时 `int` 提升为 `float` |
| 除法 | `/` | 两侧为数值，结果总是 `float`（真除法） |
| 整数除法和余数 | `//`、`%` | `int` |
| 移位 | `<<`、`>>` | `int` |
| 位运算 | `&`、`|`、`^`、`~` | `int` 或同一个 `@flag` enum |
| 模式判断 | `is TypeName`、`is Some(name)` | 对象、记录引用或 `T?` |
| 空值合并 | `??` | 左侧 `T?`、右侧 `T` |
| 区间 | `..`、`..=` | `int`（仅 `for` 头部） |

```cft
type Demo {
  f: fn(level: int, permissions: Permission) -> bool = fn(level: int, permissions: Permission) -> bool {
    (0 < level <= 100) && (permissions & Permission.Read) != Permission(0)
  };
}
```

- 整数运算为 checked 32 位运算。
- 浮点运算为 IEEE 754 binary32。
- `int` 在混合数值运算和比较中隐式提升为 `float`；两侧同为 `int` 的 `+`、`-`、`*`、`**` 结果仍为 `int`。`/` 结果总是 `float`，`//` 是整数除法。
- 移位位数必须在 `0..32` 内，越界 fault；`>>` 为算术右移，`<<` 结果按 32 位截断。
- `int ** int` 的负指数 fault。
- `//` 向零截断；`%` 的符号跟随被除数。
- 浮点 `/` 的分母为零遵循 IEEE 754，得到 `inf` 或 `nan`，不 fault；只有整数 `//`、`%` 分母为零 fault。
- 对同一个 `@flag` enum，`&`、`|`、`^`、`~` 的结果仍是该 enum。
- 字符串连接只接受 `string` operand。
- 比较两侧类型必须兼容，`string` 使用 ordinal 语义。
- 逻辑运算只接受 `bool`，并保持短路求值。
- 比较可以连续书写，例如 `0 <= level <= 100`。
- enum 不会和整数隐式转换；需要构造没有具名变体的 enum 值时使用 `EnumName(int)`，`int` 必须非负，负值 fault。
- `a ?? b` 的结果是 `T`，不能继续 `??`。

### 5.1 优先级

从高到低：

1. 字段访问、索引和调用：`.field`、`[index]`、`()`
2. 一元运算：`!`、`~`、`-`
3. 幂：`**`，从右向左结合
4. 乘除：`*`、`/`、`//`、`%`
5. 加减：`+`、`-`
6. 移位：`<<`、`>>`
7. 位与：`&`
8. 位异或：`^`
9. 位或：`|`
10. 比较：`==`、`!=`、`<`、`<=`、`>`、`>=`
11. 类型判断：`is`
12. 逻辑与：`&&`
13. 逻辑或：`||`
14. 空值合并：`??`
15. 区间：`..`、`..=`

算术、移位、位运算、比较、逻辑与区间的先后顺序与 Rust 一致：乘除高于加减，加减高于移位，
位运算按 `&` > `^` > `|` 分级并低于移位，区间低于逻辑或。`**`、`is` 和 `??` 是 Coflow 独有层级：`**`
位于一元运算之后，`is` 位于比较之后，`??` 位于逻辑或与区间之间。

```cft
type Demo {
  f: fn(a: int, b: int, c: int) -> int = fn(a: int, b: int, c: int) -> int {
    a + b * c
  };
}
```

```cft
type Demo {
  f: fn(a: int, b: int, c: int) -> int = fn(a: int, b: int, c: int) -> int {
    a + b << c     # 等价于 (a + b) << c
  };
}
```

区间用于 `for`：

```cft
type Demo {
  f: fn() -> int = fn() -> int {
    var total = 0;
    for index in 0..10 {
      total += index;
    }
    total
  };
}
```

```cft
type Demo {
  f: fn(a: int, b: int, c: int) -> int = fn(a: int, b: int, c: int) -> int {
    a + b & c      # 等价于 (a + b) & c
  };
}
```

## 6. 内建方法

```text
method-call := expression "." identifier "(" [ expression { "," expression } [ "," ] ] ")"
```

| 方法 | 适用类型 | 返回值 | 说明 |
| --- | --- | --- | --- |
| `value.len()` | string / array / dict | `int` | Unicode 字符数或元素数量 |
| `value.contains(x)` | string / array / dict | `bool` | 子串、array 元素或 dict key 是否存在 |
| `array.isUnique()` | int、bool、string、enum 数组 | `bool` | 检查元素是否唯一 |
| `array.min()` / `array.max()` | int / float / enum array | 元素类型 | 最小值 / 最大值 |
| `array.sum()` | int / float array | 元素类型 | 求和 |
| `dict.keys()` / `dict.values()` | dict | array | key / value 数组 |
| `text.matches("pattern")` | string | `bool` | 正则表达式匹配 |
| `text.startsWith(prefix)` / `endsWith(suffix)` | string | `bool` | 前缀或后缀匹配 |
| `text.isBlank()` | string | `bool` | 空字符串或全为 Unicode whitespace |
| `number.abs()` | int / float | 原数值类型 | 绝对值 |
| `value.isFinite()` | float | `bool` | 是否为有限浮点数 |
| `value.isSome()` / `isNone()` | `T?` | `bool` | 是否含值 |
| `value.approxEqual(other, epsilon)` | float | `bool` | 绝对误差比较，epsilon 必须有限且非负 |
| `dict.containsKey(key)` / `containsValue(value)` | dict | `bool` | key 或 value 是否存在 |
| `array.isSorted()` / `isStrictlySorted()` | 可排序标量数组 | `bool` | 非递减或严格递增 |
| `array.intersects(other)` / `isDisjoint(other)` | 支持集合比较的标量数组 | `bool` | 是否有交集或无交集 |
| `array.isSubsetOf(other)` / `isSupersetOf(other)` | 支持集合比较的标量数组 | `bool` | 数学集合包含关系 |

```cft
type Demo {
  f: fn(tags: [string], text: string) -> bool = fn(tags: [string], text: string) -> bool {
    tags.isUnique() && text.startsWith("id_") && tags.len() > 0
  };
}
```

高阶内建方法：

```text
value.map(lambda) | value.filter(lambda) | value.fold(init, lambda) | value.find(lambda) | value.any(lambda) | value.all(lambda)
```

```cft
type Demo {
  f: fn(values: [int]) -> [int] = fn(values: [int]) -> [int] {
    values.filter(fn(value: int) -> bool { value > 0 })
  };
}
```

- 高阶内建必须验证 callback 签名。
- `find` 返回 `T?`，空集合返回 `None`。
- 空集合上的 `fold` 使用显式初值。
- `any` / `all` 使用各自的空集合恒等值。
- 线性内建的元素工作量计入执行预算。

`matches` 的 pattern 必须是字符串字面量，使用正则表达式语法；`^...$` 表示完整匹配。

## 7. 类型转换

除 `int` 到 `float` 的隐式提升外，类型之间不做隐式转换。转换分三类：`.类型()` 方法、字符串解析
`.parseInt()` / `.parseFloat()`、enum 构造 `EnumName(...)`。

| 转换 | 来源 | 结果 | 说明 |
| --- | --- | --- | --- |
| `value.int()` | float | int | 向零截断；NaN、无穷或超出 32 位范围时 fault |
| `value.float()` | int | float | 整数转浮点 |
| `value.string()` | int / float / bool / enum | string | 生成规范文本 |
| `value.parseInt()` | string | int? | 十进制解析，失败返回 `None` |
| `value.parseFloat()` | string | float? | 小数或指数解析，失败返回 `None` |
| `EnumName(int)` | int | enum | 构造没有具名变体的 enum 值 |

- `.int()`、`.float()`、`.string()` 按来源类型区分，只接受各自列出的来源类型。
- 转换方法、字符串解析方法和 enum 构造是三类独立形式；`.类型()` 只接受表中列出的来源类型。
- 字符串解析失败返回 `None`，不使用 fault；数值范围转换失败产生 fault。
- `value.string()` 生成十进制或名称文本，不使用区域设置。
- `i32::MIN` 取负或取绝对值产生 fault。
