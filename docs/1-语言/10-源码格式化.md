# 源码格式化

> 范围：CFT、CFD、check 与基础插值模板的规范排版。

## 1. 原则

格式化只调整空白和布局，保留非空白 token、注释内容与源码顺序。
不补默认值，不求值模板或执行 check。输出幂等，未完成源码也尽量保持稳定布局。
使用 LF、两空格缩进，文件末尾一个换行，连续空行最多一个。

## 2. 通用规则

二元运算符和 = 两侧留空格，冒号与逗号后留一个空格。
::、成员点号与一元运算符内侧无空格。
顶层声明、记录和维度覆盖块之间留一个空行。
注解单独一行并紧贴声明，注释内容保持原样。

## 3. CFT 与 check

类型和 check 的左花括号与头部同行，块体展开。
字段、常量和别名以分号结束，check 声明块不增加分号。

```cft
table Item {
  name: string;
  label: fstring = f"名称：{self.name}";
  price: int;

  check {
    price >= 0 : "价格不能为负";
  }
}
```

## 4. CFD 与维度覆盖

基础记录与覆盖记录展开，字段分行，保留已有分隔逗号。
维度名紧接左方括号，方括号内变体名不留空格，右方括号与左花括号间一个空格。

```cfd
sword: Item {
  name: "Sword",
  price: 100,
}

language[ja] {
  sword: Item {
    name: "剣",
  }
}
```

数组、字典和内联对象按源码的单行或展开布局排版。

## 5. fstring

f 与开引号相邻。模板文本、转义和文本花括号保持原样。
插值使用字段路径排版，成员点号和 :: 内侧不留空格。
编辑器写回原模板，预览文本不进入源码。
