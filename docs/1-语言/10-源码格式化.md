# 源码格式化

> 状态：语言设计
>
> 范围：CFT、CFD、函数体和 fstring 的规范排版。

## 1. 原则

格式化只调整空白和布局，不改写非空白 token、不重排声明、不补默认值，也不执行函数或 fstring。

- 保留 token、注释内容和源码顺序。
- 对未完成文本尽量提供稳定布局；格式化成功不代表源码有效。
- 输出幂等，重复格式化不再变化。
- 使用 LF、两空格缩进，文件末尾保留一个换行。
- 连续空行最多保留一个，清除行尾空白。

## 2. 通用规则

- 二元运算符、=、->、=> 两侧留空格。
- 冒号和逗号后留一个空格。
- ::、成员访问点号和一元运算符内侧不加空格。
- 顶层声明或记录之间留一个空行。
- 注解单独一行，紧贴对应声明。
- # 注释内容保持不变，缩进跟随所在结构。
- 多行参数和续行增加一级缩进。

## 3. CFT

结构性 type、enum、check 块展开，左花括号与头部同行。
字段、常量和别名以分号结束；check 声明块本身不增加分号。

```cft
use Coflow::Check::require;

type Item {
  name: string;
  label: fstring = f"名称：{self.name}";
  price: int;

  total: fn(count: int) -> int => {
    self.price * count
  };

  check {
    require(self.price >= 0, "价格不能为负");
  }
}
```

enum 变体以逗号分隔，多项时每行一个。
数组、字典和对象默认值按源码选择单行或展开，不通过格式化重写值。

## 4. CFD

顶层记录展开，字段分行，保留已有分隔逗号，不补写新 token。
嵌套数组、字典和带类型名对象按源码单行或展开状态排版。
函数体使用相同两空格缩进，手工保留的单个空行不删除。

```cfd
sword: Item {
  name: "Sword",
  label: f"名称：{self.name}",
  price: 100,
  total: fn(count: int) -> int {
    self.price * count
  },
}
```

## 5. fstring

f 与开引号保持相邻。模板文本、转义和文本花括号保持原样。
插值内部按表达式规则处理空白，但不引入跨行字符串，不改变求值顺序或次数。

编辑器始终写回原始 f"..."，预览文本不进入源码。
