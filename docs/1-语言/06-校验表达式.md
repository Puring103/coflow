# 校验表达式

> 范围：现行 check 中的读取、局部变量、控制流、运算和内建操作。

## 1. 读取与作用域

记录 check 用只读 self 访问记录字段及 string 类型的 self.id。
顶层 check 使用 records(Type) 获取记录。内联 data 用普通字段路径访问。

同一作用域禁止重复局部声明，内层块可遮蔽外层局部值，self 保留且只读。
var 声明显式写出类型；for 与 Some 绑定的类型取自已知输入。
赋值只修改局部变量，记录字段、内联对象及集合保持只读。

## 2. 语句与表达式

```text
check-body := "{" { statement } "}"
statement := var-stmt | assign-stmt | break-stmt | continue-stmt
           | while-stmt | for-stmt | if-stmt | expr-stmt
var-stmt := "var" identifier ":" type "=" expression ";"
assign-stmt := identifier assignment-op expression ";"
assignment-op := "=" | "+=" | "-=" | "*=" | "/=" | "%=" | "//=" | "**="
               | "<<=" | ">>=" | "&=" | "|=" | "^="
break-stmt := "break" ";"
continue-stmt := "continue" ";"
while-stmt := "while" expression check-body
for-stmt := "for" identifier [ "," identifier ] "in" expression check-body
if-stmt := "if" expression check-body [ "else" (if-stmt | check-body) ]
expr-stmt := expression ";"
```

check 不接受参数、不返回业务值。require 的现行调用形式与报告规则见[Check 校验](./07-Check校验.md)。

表达式读取字面量、常量、局部值、self、记录引用、字段与索引，支持括号、运算、
类型判断、条件表达式，以及已知内建操作。结构化临时值仍遵守原数据类型规则。
if 表达式的各可到达分支按使用位置的明确期望类型检查。

fstring 使用独立的字段路径插值文法，具体规则见[类型与值](./03-类型与值.md)。

## 3. 条件与可选值

- if 与 while 条件必须为 bool。
- `is TypeName` 判断对象或记录类型，在条件成立的范围内提供子类型信息。
- 重新赋值局部变量后撤销此前的类型收窄。
- `is Some(value)` 引入只读解包值，可用于同一条件后续的 && 部分及成功分支。
- `||` 和 `!` 不向外提供 Some 绑定。
- 动态文本读取和索引计算不是稳定字段路径，需要复用时先保存到带明确类型的局部变量。

## 4. 遍历

数组单绑定读取值，双绑定读取索引和值；字典双绑定读取 key 和 value。
数组按元素顺序、字典按原始键值项声明顺序遍历。
读取 fstring 元素时生成 string。break 和 continue 作用于最近的循环。

```cft
use Coflow::Check::require;

table Item {
  prices: [int];

  check pricesValid {
    for index, price in self.prices {
      require(price >= 0, f"价格无效，索引：{index}");
    }
  }
}
```

索引缺失或越界产生求值错误。字符串索引按 Unicode 码点，从 0 开始，
返回一个完整码点组成的 string。

## 5. 运算与求值顺序

| 类别 | 运算符 | 类型与结果 |
| --- | --- | --- |
| 逻辑 | !、&&、\|\| | bool；&& 与 \|\| 短路 |
| 相等 | ==、!= | 按类型和值规则比较 |
| 顺序比较 | <、<=、>、>= | 数值、同一 enum、string |
| 算术 | +、-、*、** | 两个 int 得到 int，混合数值提升为 float |
| 字符串连接 | + | string |
| 真除法 | / | float |
| 整数除法、余数 | //、% | int |
| 移位 | <<、>> | int |
| 位运算 | &、\|、^、~ | int 或同一 flag 类型 |
| 类型判断 | is | 对象、记录引用或可选值 |

int 使用 checked 32 位运算；float 使用 IEEE 754 binary32。
整数 // 向零截断，% 符号跟随被除数；整数除零和溢出报错。
移位位数为 0—31；int 幂的负指数报错；flag 的 ~ 只翻转已声明位。
字符串按 Unicode 码点序列比较，链式比较不合法。

优先级从高到低为：成员／索引／内建调用，一元运算，幂，乘除余数，加减，移位，
位与，位异或，位或，比较，is，&&，||。幂右结合，其他二元运算左结合。

普通操作数和参数从左到右求值；短路逻辑和条件只执行选中的分支。
require 的现行参数求值规则为条件和消息均立即求值。

## 6. 内建操作与转换

| 操作 | 适用类型 | 结果 |
| --- | --- | --- |
| len() | string、数组、字典 | Unicode 码点数或集合元素数 |
| contains(x) | string、数组、字典 | 子串、元素或 key 是否存在 |
| isUnique() | int、bool、string、enum 数组 | 是否无重复值 |
| min() / max() / sum() | 支持对应操作的标量数组 | 最小值、最大值或总和 |
| keys() / values() | 字典 | 原声明顺序的数组 |
| matches("pattern") | string | 正则匹配，模式为普通字符串字面量 |
| startsWith(x) / endsWith(x) / isBlank() | string | 文本条件 |
| abs() / isFinite() / approxEqual(other, epsilon) | 对应数值类型 | 数值计算或条件 |
| isSome() / isNone() | 可选值 | 是否有值或为空 |
| containsKey(x) / containsValue(x) | 字典 | 是否包含指定 key 或 value |
| isSorted() / isStrictlySorted() | 可排序标量数组 | 顺序条件 |
| intersects(x) / isDisjoint(x) / isSubsetOf(x) / isSupersetOf(x) | 支持集合比较的标量数组 | 集合关系 |
| default() / for(variant) / variants() | 维度字段 | 基础值、指定变体或全部有效变体 |
| int() / float() / string() | 支持对应转换的标量 | 转换后的值 |
| parseInt() / parseFloat() | string | 解析结果，失败为 None |

空数组 min()、max() 报求值错误，sum() 返回相应数值类型的 0。
float 聚合遇到 NaN 返回 NaN，排序条件遇到 NaN 返回 false。
approxEqual 的 epsilon 必须有限且非负。

matches 使用 Rust regex 语法，默认查找匹配子串，整串匹配使用 ^ 和 $。
模式在编译时验证，支持 Unicode，不支持反向引用和环视。

字符串按 Unicode 标量值计长与索引，不自动规范化。例如 "😀" 的长度为 1，
"e\u{301}" 的长度为 2，且与 "é" 不相等。
parseInt、parseFloat 完整匹配输入，不自动去除空白。
float 转 int 向零截断，NaN、无穷和越界报错。
string() 与插值使用与区域设置无关的规范文本，float 使用可还原 binary32 值的最短文本。
