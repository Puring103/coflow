# 校验表达式

## 1. 读取与作用域

记录 check 直接读取当前记录字段，字段路径使用 `stats.hp` 等形式。顶层 check 使用 `records(Type)` 获取记录，通过集合规则绑定访问 `item.price`、`item.id`。

表达式可以读取字面量、常量、字段、集合索引及集合规则绑定。检查只读取数据，绑定由 `all`、`any`、`none` 及 `is Some(value)` 引入。

## 2. 条件与可选值

条件必须为 bool。`when condition { ... }` 控制内部规则是否执行。

`is TypeName` 判断对象或记录的实际类型，在条件成立的范围内提供子类型信息。`is Some(value)` 绑定可选值的内容，绑定可用于同一条件后续的 `&&` 部分及成立时执行的规则。

`&&` 和 `||` 短路求值。索引缺失、越界或读取不可用的值产生计算诊断。

## 3. 运算

检查条件支持逻辑、相等与顺序比较、算术、位运算、类型判断以及括号。普通操作数从左到右求值；逻辑运算按短路规则求值。

类型必须与操作匹配。整数除零、溢出及无效移位产生计算诊断。链式顺序比较要求方向一致。

## 4. 检查专用内建操作

内建操作具有固定名称和类型约束，用于构造检查条件。常用形式包括：

```cft
check ItemNames {
  all item in records(Item) {
    item.name.len() > 0 : "名称不能为空";
    item.tags.isUnique() : "标签不能重复";
    item.name.matches("^[A-Za-z]+$") : "名称只能包含英文字母";
  }
}
```

字符串及集合可以使用 `len()`、`contains(...)` 等检查操作；字典提供 `keys()`、`values()`，可选值通过 `is Some(value)` 和 `is None` 判断。维度字段提供 `.default()`、`.for(variant)`、`.variants()`。

`records(Type)` 用于顶层规则，Type 为静态记录类型，结果包含该类型及其子类型记录。

## 5. 消息插值

普通字符串中的花括号是字面文本。`f"..."` 只插入绑定或字段路径对应的基础值，使用 `{{`、`}}` 表示花括号。

```cft
check Prices {
  all item in records(Item) {
    item.price >= 0 : f"物品 {item.id} 的价格 {item.price} 无效";
  }
}
```

消息插值遵循基础值转文本规则。运算及检查专用内建操作写在检查条件中，插值部分只读取路径。

规则文法及报告见[Check 校验](./07-Check校验.md)。
