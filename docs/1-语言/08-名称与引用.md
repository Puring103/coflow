# 名称与引用

## 项目全局名称

全部 CFT 文件的 table、data、singleton、enum、const、类型别名和命名 check 共同组成项目全局声明集合。类型或常量使用声明名访问，文件目录与文件名只决定来源，不改变名称。

名称必须唯一。类型别名指向静态类型，别名依赖必须无环；常量按依赖顺序解析，错误保留所有相关声明位置。

```cft
const LIMIT = 100;
enum Quality { Common, Rare }
table Item { quality: Quality; limit: int = LIMIT; }
```

枚举成员通过 `Quality::Rare` 限定，也可以在已知 Quality 字段中使用短成员名。C# 的 namespace 由 codegen target 配置，只控制生成源码的目标语言命名空间。

## 记录身份

CFD 记录使用 `key: Type { ... }`。key 在类型的整棵继承树内唯一，不同继承树可以使用相同 key。分组限定声明要求实际类型属于该分组类型的继承域。

```cft
abstract table Entity { name: string; }
table Item: Entity { next: Option<&Entity> = None; }
```

```cfd
first: Item { name: "First", next: Some(&Entity::second) }
second: Item { name: "Second", next: Some(&first) }
```

`&Type::key` 明确查找类型与 key；`&key` 使用字段的静态目标类型。基础目标类型允许查找到其具体子类型，具体目标类型只接受该类型或其子类型。

引用连接记录身份，不复制记录内容。所有身份先建立，再验证引用并读取字段，因此跨文件引用和引用成环不依赖输入顺序。

## 内联值与路径

字段中的 data 名称使用内联内容构造，`&TableName` 使用记录链接，两者有独立的值类型。内联对象的实际子类型必须可赋给声明类型。

fstring 使用 self 的字段路径或 `&Type::key` 的字段路径读取已知对象。检查表达式使用当前字段、集合绑定和顶层 `records(Type)` 建立作用域；名称解析不改变字段及记录来源。
