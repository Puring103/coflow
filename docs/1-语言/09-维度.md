# 维度

> 状态：语言设计

## 1. 声明

维度为同一个字段保存基础值和任意数量的变体值。`@localized` 等价于
`@dimension("language")`。

```cft
table Item {
  @localized
  name: string;

  @dimension("region")
  price: int;
}
```

一个字段只能绑定一个维度。维度字段可以声明在 table、singleton 或其父类型上；
data 不声明维度字段。注解不改变字段原始值类型，也不生成辅助类型。

## 2. CFD 表示

维度值直接保存在所属业务记录中：

```cfd
sword: Item {
  name: dimension {
    default: "Sword",
    zh: "剑",
    ja: "剣",
  },
  price: dimension {
    default: 100,
    cn: 90,
  },
}
```

- 维度字段必须显式使用 `dimension { ... }`，不能用普通值简写。
- `default` 必填，且只能出现一次。
- 其他字段名是变体名，使用普通标识符规则。
- 每个变体的值必须符合原字段类型。
- 只有原字段类型为 `T?` 时，变体才可以显式写 `None`。
- CFD 不包含辅助记录、辅助类型或独立维度文件。

变体集合由当前加载的全部 CFD 动态汇总。同一维度的任一字段都可以引入新变体，
因此 Mod 可以在自己的业务记录中增加变体，无需修改 schema 或项目配置。

## 3. 读取与回退

```cft
item.name.default()
item.name.for("zh")
item.name.variants()
```

`.default()` 返回基础值。`.for(variant)` 返回显式变体值；字段没有该变体或传入未知
变体名时返回基础值。可选字段显式写入的 `None` 是有效覆盖，不触发回退。

`.variants()` 返回同一维度在整个数据模型中的变体并按名称排序。每个字段缺少的变体
会在结果中使用该字段的基础值，因此它与逐项调用 `.for(variant)` 的结果一致；
`default` 不作为字典项。

fstring 和函数保持所属业务对象的 `self` 绑定。变体值中的内联对象仍遵循普通对象的
绑定规则。遍历、模板执行和结果构造均计入当前执行预算，任一项求值失败时整个调用失败。

## 4. 运行时与编辑器

运行时将维度作为带基础值和变体映射的值保存，不把它注册为可在 CFT 中引用的新类型。
目标语言绑定使用专用运行时包装，例如 C# 的 `CoflowDimension<T>`。

编辑器可以按维度提供聚合展开视图，但该视图是虚拟导航结构。所有修改直接写回记录
所属的业务 CFD 文件，记录的移动、重命名和删除也自然携带其维度数据。
