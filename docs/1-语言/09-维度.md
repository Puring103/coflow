# 维度

## 1. 声明

维度为同一个字段保存基础值和任意数量的变体值。`@localized` 等价于
`@dimension("language")`。

```cft
table Item {
  @localized
  name: string;

  @dimension("region")
  price: int;
}
```

一个字段只能绑定一个维度。维度字段声明在 table 或 singleton 字段上并由继承保留；
覆盖块定位已有记录。注解保留字段的原始值类型。

## 2. 基础记录与覆盖块

基础记录按普通字段语法提供基础值，也可以使用 CFT 声明的默认值：

```cfd
sword: Item {
  name: "Sword",
  price: 100,
}
```

维度覆盖使用独立的顶层块：

```cfd
language[ja] {
  sword: Item {
    name: "剣",
  }
}

region[jp] {
  sword: Item {
    price: 120,
  }
}
```

```text
dimension-block := identifier "[" identifier "]" "{" { record-override } "}"
record-override := record-key ":" qualified-name "{" [ field-list ] "}"
```

- 外层名称是维度名，方括号内是变体名，两者使用普通标识符规则。
- 顶层名称后接 `:` 表示基础记录，接 `[` 表示维度覆盖块；语法解析不依赖 CFT 名称查询。
- 覆盖块内用类型与记录 key 定位已有记录，不创建新的基础记录。
- 只填写需要覆盖的字段；未填写的字段使用该记录的基础值。
- 被覆盖字段必须通过 CFT 注解绑定到该维度，值必须符合原字段类型。
- 覆盖替换整个字段值；对象、数组和字典按完整值替换。
- 只有原字段类型为 `Option<T>` 时，覆盖值才可以显式写 `None`。
- 未知维度、记录、类型、字段及不匹配的字段维度均产生加载诊断。
- 同一维度、变体、目标记录和字段的覆盖在全部来源中只能出现一次；不同字段可分散在多个块或文件。

## 3. 文件组织与变体发现

基础记录与覆盖块可以放在同一文件，也可以分文件保存。一份 CFD 可以包含多个覆盖块。
文件名和目录不决定维度或变体，不产生覆盖优先级。

例如基础记录放在 `items.cfd`，日语覆盖放在 `localization/ja.cfd`。将后者纳入项目 CFD
来源即可提供 `language` 的 `ja` 变体，无需修改基础记录或在 `coflow.yaml` 中单独声明变体。

变体集合由全部已加载 CFD 的覆盖块汇总。基础记录与覆盖块的来源顺序不影响覆盖结果；
目标记录在全部来源中解析。

## 4. 读取与回退

```cft
item.name.default()
item.name.for("ja")
item.name.variants()
```

`.default()` 返回基础值。`.for(variant)` 返回显式覆盖值；字段没有该变体或传入未知
变体名时返回基础值。可选字段显式写入的 `None` 是有效覆盖，不触发回退。

`.variants()` 返回同一维度在整个数据模型中的变体并按名称排序。每个字段缺少的变体
会在结果中使用该字段的基础值，因此它与逐项调用 `.for(variant)` 的结果一致。
基础值不作为变体字典项。

覆盖中的 fstring 以被覆盖字段所属业务对象为 `self`；内联对象自身字段中的模板
以该内联对象为 `self`。模板仅提供字段路径插值，规则见[类型与值](./03-类型与值.md)。

## 5. 编辑与来源

目标语言绑定使用专用维度包装，例如 C# 的 `DimensionValue<T>`。

```csharp
item.name.Default
item.name.For("ja")
item.name.Variants
```

所有变体在加载阶段合成，`For(variant)` 在同一份已加载数据中选择有效值。

编辑器保留每个覆盖字段的文件与源码位置。修改已有覆盖时写回原文件；首次增加覆盖时
由用户选择目标 CFD 文件，向该文件写入对应的覆盖块、目标记录和字段。
清除覆盖只删除该覆盖字段，基础记录保持原值。

基础记录重命名时同步更新各文件中的覆盖目标；删除基础记录时同步删除对应覆盖。
基础记录移动文件不改变类型和 key，因此各覆盖块继续定位同一记录。
