# 维度

> 状态：语言设计
>
> 范围：维度数据的声明、访问、自动生成类型和覆盖语义。

维度为同一个字段提供多组变体值。维度由基础数据和变体覆盖组成，不保存当前语言、地区或其他隐式
选择状态。访问维度值必须显式调用 `.for(...)`。

## 1. 模型

一个维度字段包含：

- 一份基础值。
- 按变体名称索引的稀疏覆盖。

没有覆盖的变体使用基础值；显式覆盖表示该变体存在独立值。维度查询不修改任何状态。

## 2. 字段声明

```text
dimension-annotation := "@dimension" "(" string-literal ")"
localized-annotation := "@localized"
```

```cft
type Item {
  @dimension("language") name: string;
  @localized description: string;
}
```

- `@dimension("name")` 绑定指定维度。
- `@localized` 等价于绑定 `language` 维度。
- `@localized` 与 `@dimension` 不能同时用于同一字段。
- 一个字段只绑定一个维度。
- 维度字段不能位于 sealed 内联 type 中。

## 3. 访问

```text
dimension-access := expression "." "for" "(" string-literal ")"
base-access      := expression "." "default" "(" ")"
```

维度值必须显式访问变体，不提供隐式当前选择。变体名称只接受字符串：

```cft
type Demo {
  f: fn(item: Item) -> string = fn(item: Item) -> string {
    item.name.for("zh")
  };
}
```

```cft
check Localization {
  for item in records(Item) {
    require(item.name.for("en").len() > 0, "英文名称不能为空");
    require(item.name.default().len() > 0, "基础名称不能为空");
  }
}
```

- `.for(variant)` 返回原始字段类型，参数是字符串字面量。
- `.default()` 返回基础值。
- 不生成变体 enum。
- 变体缺失或覆盖为空时回退基础值。
- 维度查询是只读操作，返回值可以被局部变量和闭包持有。
- 读取 dimension 字段的 check 规则会分别检查基础值和对应变体。

## 4. 自动生成类型

维度数据以字段为单位生成具体类型。类型名规则为：

```text
<原始类型>_<字段>_<维度名称>
```

例如 `Item` 的 `name: string` 字段绑定 `language` 维度时，生成类型 `Item_name_language`。该类型
保存字段基础值和稀疏变体覆盖；`.for(...)` 返回原始字段类型 `string`。

```cft
type Item {
  @dimension("language") name: string;
  @dimension("language") description: string;
}
```

- `Item_name_language` 与 `Item_description_language` 分别生成，即使它们绑定同一维度。
- `_` 是名称分隔符。
- 生成类型位于保留命名空间 `coflow::dimension`：不参与普通短名解析，但在维度数据记录位置按短名解析到该命名空间。
- 当前命名空间若存在同名用户类型，报短名歧义，要求改名或显式限定。
- 自动生成类型纳入契约和目标语言绑定。

## 5. 覆盖语义

- 覆盖以整个字段值为单位：变体值整体替换基础值。
- 覆盖未提供某字段时使用基础值。
- 显式覆盖值为 `None` 时表示明确为空，仅适用于可选字段。
- 存储层必须区分“没有覆盖”和“覆盖为空”。
- 基础值仍须满足对应的 check 规则；变体值缺失或显式 `None` 时，使用基础字段值执行校验。
- 未知变体不参与运行时加载，按回退处理；编辑器可以提供诊断提示。

```cft
type UiText {
  @localized text: string;
  @localized subtitle: string?;
}
```

```cfd
welcome: UiText {
  text: "Welcome",
  subtitle: None,
}
```

## 6. 维度数据

维度数据以字段为单位记录，记录 key 与基础记录一致，记录类型直接写生成类型的短名：

```cfd
welcome: UiText_text_language {
  en: "Welcome",
  zh: "欢迎",
}
```

- 记录类型使用生成类型短名，由维度解析隐式绑定到 `coflow::dimension` 命名空间。
- 维度记录不作为业务表暴露；业务数据通过字段上的 `.for(...)` 访问。
- 继承字段的维度数据归属声明该字段的类型。
- 变体集合由维度定义静态给出，生成类型的字段集合因此在 codegen 阶段已知。

## 7. 生命周期

- 维度查询不建立隐式缓存。
- 返回的维度值遵循其所属执行环境的生命周期；闭包可以捕获 `.for(...)` 的结果。
- 数据更新通过切换独立执行环境完成，维度数据随所属数据一同发布。
