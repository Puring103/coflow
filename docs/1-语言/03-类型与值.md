# 类型与值

> 范围：静态类型、结构化值、记录引用和 fstring 读取。

## 1. 类型文法

```text
type := unit-type | scalar-type | optional-type | list-type
      | dict-type | func-type | paren-type | qualified-name
unit-type := "(" ")"
paren-type := "(" type ")"
scalar-type := "int" | "float" | "bool" | "string" | "fstring"
optional-type := (scalar-type | list-type | dict-type
                | func-type | paren-type | qualified-name) "?"
list-type := "[" type "]"
dict-type := "{" type ":" type "}"
func-type := "fn" "(" [ param { "," param } [ "," ] ] ")" "->" type
param := [ identifier ":" ] type
```

`fn() -> T?` 是返回可选值的函数；可选函数写 `(fn() -> T)?`。
命名类型直接写声明名。Item 为 table 或 singleton 时，`Item` 表示一条记录，`Item?` 表示可选记录。
Stats 为 data 时，`Stats` 表示普通数据对象。类型位置不使用 `&`；函数类型中的参数名不影响类型相等。

## 2. 基本类型规则

| 类型 | 含义 |
| --- | --- |
| () | 无返回值 |
| int / float / bool | 32 位整数、binary32 浮点数、布尔 |
| string | 已经生成的文本 |
| fstring | 用 f"..." 声明的文本函数，读取得到 string |
| enum | 独立的命名枚举类型 |
| D（data 声明） | 普通对象内容，用于字段、内联值、局部值和参数 |
| R（table 或 singleton 声明） | 一条配置记录，保留记录身份 |
| [T] / {K: V} | 只读数组、字典 |
| T? | None 或一个 T 值 |
| fn(...) -> R | 普通函数值 |

- int 可隐式提升为 float；其余普通数值转换使用显式方法。
- 子类型可以用于父类型位置。
- `@struct` 是目标代码的值类型表示，相等规则仍按对象内容。
- 集合类型参数不变；函数的参数和返回类型也不变。
- 字典 key 只允许 int、bool、string 或 enum。
- 函数值可出现在字段、集合、可选值、内联对象、默认值和常量中，按所在位置的类型检查。
- abstract 类型在任何位置都不能直接构造；必须使用具体子类型。

## 3. data 与记录

data 对象与记录是两类不同的语言值，均使用 `.field` 读取已声明字段。

- data 可以在字段、集合、默认值和函数体中构造；函数体中可通过局部构造创建修改后的不可变值。data 不能作为 CFD 顶层记录。
- table 和单例声明记录类型，不能作为内联对象或在函数中通过对象字面量构造。
- 记录不能隐式转换为 data 对象；函数参数按已声明的记录类型或 data 类型检查。
- 记录的 `id` 类型固定为 string，记录参数和记录自身的 self 都可以正常访问 id。
- data 不具有记录身份，不提供记录 id。
- `records(T)` 用于查询记录类型，规则见[Check 校验](./07-Check校验.md)。
- `@idAsEnum` 只影响目标代码生成，不改变 `id` 的语言类型。
- data 对象的直接或间接内容递归必须经过可选类型；数组、字典本身不作为递归例外。
- Node 为 data 时，`next: Node` 和 `children: [Node]` 不能用于 Node 的递归字段；`next: Node?` 可以。
- 允许可选递归不代表允许无限展开默认值；默认值物化仍须有限。
- 记录引用本身可以形成循环，不能因为引用环而递归复制记录。

引用写法见[CFD 数据](./05-CFD数据.md)。

```cft
data Stats {
  hp: int;
}

table Item {
  stats: Stats;
  next: Item? = None;
}

const readId: fn(item: Item) -> string =
  fn(item: Item) -> string { item.id };
```

Item 字段和函数参数保存记录引用，Stats 字段保存 data 对象。
引用具体记录的值写作 `&Item::sword`；`&` 属于值语法，不是类型前缀。
两个记录按所属 Runtime 和记录身份比较；两个 data 对象按实际 data 类型和字段内容比较。
记录与 data 之间不进行混合内容比较。

## 4. 可选值

`T?` 使用 `None` 或裸 `T` 值，不使用 Some 构造器。
可选类型不能嵌套，例如 `(int?)?` 不合法。

None 与 0、false、空字符串和默认对象都是不同的值。可选递归在运行时通过间接引用表示，不把对象无限内联到自身。

| 字段输入 | 结果 |
| --- | --- |
| 提供值 | 使用该值 |
| 省略且有默认值 | 使用默认值 |
| 省略、无默认值、可选 | None |
| 省略、无默认值、必填 | 加载错误 |
| 显式 None | 可选字段明确为空 |

在返回可选类型的函数内，`value?` 遇到 None 时立即返回 None，否则取出其中的值。
check 本身和 fstring 插值不能使用这种向外传播。

同类型可选值可以比较，也可以与 None 比较；与裸值比较前需要解包。
`is Some(name)` 在条件中引入只读绑定，规则见[函数与表达式](./06-函数与表达式.md)。

## 5. fstring

### 5.1 声明和读取

`fstring` 是独立的文本函数类型，模板起源是 `f"..."` 字面量。
已有模板可在明确要求 fstring 的位置保存、传递和返回；普通字符串、普通函数值和已求值文本不能转换为模板。

```cft
table Item {
  name: string;
  label: fstring = f"名称：{self.name}";
  labels: [fstring] = [f"{self.name}", f"固定文本"];
  note: fstring? = None;
}
```

- 普通读取 fstring 字段时执行文本函数，得到普通 string，无需括号或 render 方法。
- 每次读取重新计算，不缓存上次结果。已经确认不变的部分可以编译为常量。
- `var text: string = item.label;` 只计算一次，之后 text 是普通 string。
- fstring? 为 None 时读取得到 None；有值时读取得到 string，因此读取结果是 string?。执行错误不会转成 None。
- 获取 `[fstring]` 或字典本身不计算元素；索引的普通读取或遍历读取具体 fstring 元素时才计算。
- `[fstring]` 不自动转换为 `[string]`。字典 value 适用相同规则。
- fstring 不能作为字典 key。

### 5.2 使用位置和绑定

有明确 fstring 期望类型的位置保留文本函数，包括对象字段、集合元素、可选值、
显式声明的局部存储、赋值目标、函数参数、函数返回值和常量定义。
普通表达式位置的 `f"..."` 则在执行到该表达式时生成 string：

```cft
var text: string = f"名称：{item.name}";
```

文本函数里的 self 按创建位置绑定，只读。对象字段及字段集合中的文本字面量绑定该对象；
普通局部文本函数捕获外层 self。嵌套对象、已有绑定和完整示例见[函数与表达式](./06-函数与表达式.md#11-创建位置与绑定)。
运行时创建文本函数时，实际使用的外层参数和局部值按创建时的值捕获。
以后重新给外层局部变量赋值，不改变已保存的捕获值。

插值从左到右，每处执行一次。计算失败时整个读取失败，不返回半截文本。
相互读取造成的循环沿用函数的调用深度和预算限制。

### 5.3 基本读取场景

下表描述字段、局部值和集合元素的普通读取。

| 使用方式 | 得到的结果 | 文本执行 |
| --- | --- | --- |
| 声明 `label: fstring = f"..."` | 保存文本函数定义 | 初始化不读取模板结果 |
| 普通读取 `item.label` | string | 每次读取执行一次文本函数 |
| `var text: string = item.label;` 后读取 text | string | 初始化时执行，随后读取 text 不再执行模板 |
| 普通读取值为 None 的 fstring? | string? 中的 None | 不执行文本函数 |
| 普通读取有值的 fstring? | string? 中的文本 | 执行一次，错误按执行错误返回 |
| 获取 `[fstring]` 字段 | 原集合 | 不执行元素文本函数 |
| 索引读取一个 fstring 元素 | string | 执行被读取的元素 |
| for 遍历 `[fstring]` | 每次迭代取得 string | 读取到哪个元素，就执行哪个元素 |
| 普通表达式 `var text: string = f"...";` | string | 执行到该表达式时生成文本 |

这里的“一次”指一次文本函数调用；其中的每个插值按源码顺序求值一次。
模板内部若继续读取其他 fstring，按各次读取分别执行。

### 5.4 模板传递与返回

编译器根据当前位置的期望类型选择保留模板或生成普通读取。
明确要求 fstring 时，已有 fstring 字段、局部值、常量、集合元素或函数返回值按模板传递。
明确要求 fstring? 时，同样保留可选模板，None 保持为空。
没有模板期望类型的普通读取产生 string 或 string?。

| 使用方式 | 结果 |
| --- | --- |
| `var saved: fstring = item.label;` | 保存原模板及绑定，不执行模板 |
| `var text: string = item.label;` | 执行模板，保存 string |
| 给已声明的 fstring 局部变量赋已有模板 | 替换该局部变量保存的模板，保持被传入模板的绑定 |
| 向 fstring 参数传入字段或元素 | 传递原模板，不先计算文本 |
| 向 string 参数传入 fstring 字段或元素 | 执行模板，将结果文本作为参数 |
| 从返回类型为 fstring 的函数返回已有模板 | 返回原模板及绑定 |
| 普通读取返回类型为 fstring 的函数调用结果 | 先调用普通函数，再执行其返回的模板 |
| 在 fstring 期望类型位置使用返回 fstring 的函数调用 | 执行普通函数以取得模板，取得后保留模板 |

保留模板只省去该模板的文本执行。为了取得模板而进行的调用、索引计算和其他操作
仍按普通求值顺序执行，也仍可能产生执行错误。
模板传递保留 self 和捕获值；存入另一个对象时沿用已有绑定。

```cft
const TITLE: fstring = f"固定标题";
const COPY: fstring = TITLE;

const makeText: fn(value: string) -> fstring =
  fn(value: string) -> fstring { f"内容：{value}" };

const reuseText: fn(value: fstring) -> fstring =
  fn(value: fstring) -> fstring { value };
```

调用位置可以写 `var saved: fstring = reuseText(makeText("示例"));` 保存模板，
随后 `var text: string = saved;` 执行模板并得到 `"内容：示例"`。
模板常量复用仍遵循 CFT 常量的编译期确定规则。
普通数据位置的文法保持不变，任意函数调用只用于函数体和插值等表达式位置。

### 5.5 集合操作中的模板

集合保存元素的声明类型。操作按其职责区分读取文本与复制原模板：

| 操作 | 对 fstring 的处理 |
| --- | --- |
| `{K: fstring}.values()` | 按原顺序复制 value 的模板及绑定，返回 `[fstring]`，不执行模板 |
| `[fstring].filter(predicate)` | 每个元素先读为 string 交给判定回调；入选项保存原模板，结果为 `[fstring]` |
| `[fstring].map(callback)` | 元素读为 string 交给回调，结果元素类型由回调返回类型确定 |
| `{K: fstring}.filter(predicate)` | 回调接收 key、求值后的 string；结果字典保留入选项的 key、原模板及顺序 |
| `{K: fstring}.map(callback)` | 回调接收 key、求值后的 string；按回调返回类型产生结果数组 |
| fstring 集合的 fold、any、all | 仅将实际访问的元素读为 string 交给回调；any、all 短路后不读取剩余元素 |
| map 回调返回 string | 保存本次回调产生的文本，结果为 `[string]` |
| map 回调返回 fstring | 保存回调返回的模板及绑定，结果为 `[fstring]` |

filter 为判定某个元素读取一次原模板，保存入选模板时不再执行它。
以后普通读取入选元素仍会重新执行原模板，筛选时得到的字符串不是缓存。
map 保存声明返回类型为 fstring 的回调结果时采用模板期望类型。
可选 fstring 元素按相同规则读取为 string?，原模板复制保留可选状态。

```cft
const selectText: fn(values: [fstring]) -> [fstring] =
  fn(values: [fstring]) -> [fstring] {
    values.filter(fn(text: string) -> bool { text.len() > 0 })
  };

const readTexts: fn(values: [fstring]) -> [string] =
  fn(values: [fstring]) -> [string] {
    values.map(fn(text: string) -> string { text })
  };
```

## 6. 集合与相等

- 数组保留顺序；字典保留原始 CFT 或 CFD 中键值项的声明顺序，key 必须唯一。
- 使用 CFT 默认值或常量中的字典时保留其 CFT 顺序；CFD 提供字典时保留该 CFD 值的顺序。复制、编译和加载都不重排键值项。
- 函数体中的字典字面量按源码中键值项的书写顺序构造。遍历、keys() 和 values() 均使用所保存的顺序，不按 key 或哈希表顺序排列。
- data 对象按实际类型及字段内容比较；记录按所属 Runtime 和记录身份比较。
- 比较对象中的引用字段时只比较引用身份，不继续展开被引用记录。
- 函数按函数身份比较；复制同一个函数值保留身份。
- 同一字段连续取得的函数具有相同身份。同一个闭包表达式每执行一次创建一个新函数身份，即使代码与捕获值完全相同也不相等。
- 数组按顺序逐项比较；字典按 key 及对应 value 比较，相等判断不要求声明顺序相同。
- float 使用数值相等，NaN 不等于自身。
- string 按 Unicode 码点序列比较，不自动规范化；组合序列与单个预组合字符保持各自的值。
- data 或集合的内容比较读取 fstring 字段或元素时会计算文本，可能产生执行错误。不能因为访问的是同一 data 对象而省略动态读取。

## 7. 显式类型与结构化值

类型别名不创建新类型。`const` 必须声明类型；常量的值、函数定义或文本函数定义在 CFT 编译时确定。
普通 string 常量保存固定文本，动态文本应声明为 fstring 或普通函数。

var 局部变量、字段、常量和函数签名必须显式声明类型。
初始化、赋值、参数及返回表达式分别检查能否赋给声明的期望类型，
不通过初始值或 if 分支推断变量类型，也不搜索共同父类型生成隐式声明。
`None`、`[]`、`{}` 使用所在位置已经声明的类型；if 的每个可到达分支分别按该类型检查。

for 循环和 Some 解包的绑定类型由已知输入类型直接推断。
`for item in records(Item)` 中 item 为 Item；`int?` 值通过 `is Some(number)` 解包后，number 为 int。
这些绑定直接采用所遍历或解包的输入类型，不适用 var 声明必须标注类型的要求。

```cft
const choose: fn(enabled: bool) -> float =
  fn(enabled: bool) -> float {
    var value: float = if enabled { 1 } else { 1.5 };
    value
  };
```

value 的类型由 `: float` 指定，整数分支按已有 int 到 float 的赋值规则转换。
省略 `: float` 属于声明缺少类型，不执行类型推断。

```text
value := unit-literal | scalar-value | string-literal | fstring-literal | bit-expr
       | array-value | dict-value | object-value | reference-value
       | "None" | function-value
unit-literal := "(" ")"
scalar-value := [ "-" ] (int-literal | float-literal) | bool-literal
bit-expr := bit-xor { "|" bit-xor }
bit-xor := bit-and { "^" bit-and }
bit-and := bit-term { "&" bit-term }
bit-term := qualified-name | "(" bit-expr ")"
array-value := "[" [ value { "," value } [ "," ] ] "]"
dict-value := "{" [ value ":" value { "," value ":" value } [ "," ] ] "}"
object-value := qualified-name "{" [ field-init { "," field-init } [ "," ] ] "}"
field-init := identifier ":" value
reference-value := "&" [ qualified-name "::" ] record-key
function-value := "fn" "(" [ named-param { "," named-param } [ "," ] ] ")" "->" type block
named-param := identifier ":" type
```

单独的限定名可以表示常量或 enum 变体。位表达式只用于同一 flag 类型，优先级与普通表达式一致。
普通数据值不包含任意函数调用；函数体和 fstring 插值内可以使用完整表达式。
