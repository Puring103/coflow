# 类型与值

## 类型文法

```text
type := "int" | "float" | "bool" | "string" | "fstring"
      | identifier | "&" type | "Option<" type ">"
      | "[" type "]" | "{" type ":" type "}" | "(" type ")"
```

| 声明 | 语义 |
| --- | --- |
| int / float | 有符号 64 位整数 / 有限 binary64 浮点数 |
| bool / string | 布尔 / 普通文本 |
| fstring | 字段路径插值模板，加载后提供生成的文本 |
| TypeName | 内联对象，使用字段内容表示 |
| &TypeName | 按记录身份连接的引用 |
| Option<T> | 独立的一层 None 或 Some(T)，可以嵌套 |
| [T] / {K: V} | 数组 / 字典 |
| EnumName | 独立的命名枚举类型 |

记录与内联对象共享 `type` 声明。`@singleton` 类型用于项目单例；其他类型既可声明顶层记录，也可构造内联对象。记录 `id` 是 string，内联对象没有记录身份。

int 可以提升为 float；子类型可用于父类型位置。集合参数保持声明类型，字典 key 使用 int、string 或 enum。

```cft
type Stats { hp: int; }
type Item {
  stats: Stats;
  next: Option<&Item> = None;
}
```

## 可选值

`None` 表示当前层没有值，`Some(value)` 表示当前层存在值。裸值在已知的 `Option<T>` 位置物化为一层 Some。嵌套可选值保留各层状态，例如 `None`、`Some(None)` 和 `Some(Some(3))` 相互不同。

```cft
type Entry {
  nested: Option<Option<int>> = Some(None);
}
```

省略字段时优先使用 schema 默认值；没有默认值的 Option 字段物化为 None。其他必填字段缺失会产生诊断。显式 None 只能用于可选位置，不能代替数值、对象或必填引用。

检查通过 `is Some(value)` 解包一层，通过 `is None` 判断当前层的空态。

## 递归与默认值

必填内联对象字段组成的直接或间接循环无合法有限构造，声明检查拒绝该循环。Option、数组、字典允许有限的递归数据；记录引用连接预先分配的记录身份，允许成环。

默认值必须能够有限展开。`None`、空集合以及显式提供的终止字段可结束递归；循环读取其他字段默认值会生成默认值物化诊断。常量可以推断无歧义类型；None、空集合等需要明确声明类型。常量依赖必须无环，常量不包含需要所属对象的 fstring。

## fstring

普通字符串保持原始文本。模板使用 `f"..."`，字段及集合中的模板按所属对象绑定 self，嵌套内联对象的模板使用该内联对象作为 self。维度覆盖的文件位置不改变绑定对象。

```cft
type Item {
  name: string;
  price: int;
  label: fstring = f"名称：{self.name}，价格：{self.price}";
  note: Option<fstring> = None;
}
```

```cfd
sword: Item { name: "Sword", price: 100 }
shield: Item {
  name: "Shield",
  price: 80,
  label: f"同类物品：{&Item::sword.name}",
}
```

模板只读取字段路径，末端为 string、int、float、bool、enum 或已生成文本的 fstring。检查消息也可以读取作用域绑定。对象、集合和 Option 层不是可直接转换的文本末端。

模板从左到右生成文本，基础值转换不受区域设置影响。路径错误、读取错误和循环依赖返回来源诊断。源码保留模板，加载后的业务对象保存求值文本。

## 集合与相等

数组保持元素顺序，字典 key 唯一；数据构建保留源码声明项的顺序。数组逐项比较，字典按 key 和对应 value 比较。内联对象按实际类型与字段内容比较，记录引用按所属模型及记录身份比较，并不展开被引用记录。Option 按每层状态与内容比较。

字符串按 Unicode 内容比较；浮点按数值规则比较。fstring 在需要文本值时使用求值结果，错误保留来源。
