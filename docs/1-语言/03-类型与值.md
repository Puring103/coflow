# 类型与值

> 范围：静态类型、结构化值、记录引用和基础字符串插值。

## 1. 类型文法

```text
type := scalar-type | optional-type | list-type | dict-type | paren-type | qualified-name
paren-type := "(" type ")"
scalar-type := "int" | "float" | "bool" | "string" | "fstring"
optional-type := (scalar-type | list-type | dict-type | paren-type | qualified-name) "?"
list-type := "[" type "]"
dict-type := "{" type ":" type "}"
```

命名类型直接写声明名。Item 为 table 或 singleton 时，`Item` 表示记录引用，
`Item?` 表示可选记录引用。Stats 为 data 时，`Stats` 表示内联数据对象。
类型位置不使用 `&`。

| 类型 | 含义 |
| --- | --- |
| int / float / bool | 32 位整数、binary32 浮点数、布尔 |
| string | 普通文本 |
| fstring | 字段路径插值模板，读取得到 string |
| enum | 独立的命名枚举类型 |
| D（data 声明） | 内联数据对象 |
| R（table 或 singleton 声明） | 带记录身份的引用 |
| [T] / {K: V} | 只读数组、字典 |
| T? | None 或一个 T 值 |

int 可隐式提升为 float；子类型可用于父类型位置。集合类型参数不变。
字典 key 只允许 int、bool、string 或 enum。

## 2. data 与记录

- data 用于字段、集合、常量和默认值，不作为 CFD 顶层记录。
- table 和 singleton 通过记录引用使用，不通过对象字面量内联构造。
- 记录与 data 不互相转换；abstract 类型必须使用具体子类型。
- 记录的 `id` 类型固定为 string，data 不提供记录身份。
- data 的直接或间接内容递归必须经过可选类型；数组和字典本身不打断递归。
- 默认值展开必须有限。记录引用允许成环，按记录身份链接。
- `@struct` 只影响目标语言表示，data 相等仍按内容比较。
- `@idAsEnum` 只影响目标代码，不改变记录 id 的语言类型。

```cft
data Stats { hp: int; }
table Item {
  stats: Stats;
  next: Item? = None;
}
```

Item 字段保存记录引用，Stats 字段保存内联内容。引用值写作 `&Item::sword`。

## 3. 可选值

`T?` 使用 `None` 或裸 `T` 值，不使用 Some 构造器。可选类型不能嵌套。
None 与 0、false、空字符串和默认对象不同。

| 字段输入 | 结果 |
| --- | --- |
| 提供值 | 使用该值 |
| 省略且有默认值 | 使用默认值 |
| 省略、无默认值、可选 | None |
| 省略、无默认值、必填 | 加载错误 |
| 显式 None | 可选字段明确为空 |

校验条件中的 `is Some(name)` 引入只读解包值；具体规则见[校验表达式](./06-校验表达式.md)。

## 4. fstring

### 4.1 声明与读取

fstring 用 `f"..."` 声明模板。普通 string 的花括号保持为文本。
字段、集合元素及可选值中的模板按声明的 fstring 类型保存，普通读取得到 string；
fstring? 为 None 时读取得到 None，有值时读取得到 string。
获取模板集合本身不生成文本，读取具体元素时生成该元素的文本。

```cft
table Item {
  name: string;
  price: int;
  label: fstring = f"名称：{self.name}，价格：{self.price}";
  note: fstring? = None;
}
```

源码保留原模板，编辑器预览和宿主读取返回生成的文本。每次读取按字段路径生成文本，
已生成的 string 是普通字符串。

### 4.2 插值文法

```text
interpolation := "{" field-path "}"
field-path := path-root { "." identifier }
path-root := "self" | identifier | reference-value
```

插值只读取字段路径。数据模板中的 self 是字段所属对象；记录引用使用 CFD 的引用规则。
check 消息可以读取校验作用域中已有的局部值及其字段路径。

```cfd
sword: Item {
  name: "Sword",
  price: 100,
  label: f"名称：{self.name}，价格：{self.price}",
}

shield: Item {
  name: "Shield",
  price: 80,
  label: f"同类物品：{&Item::sword.name}",
}
```

插值末端支持 string、int、float、bool、enum，以及读取为 string 的 fstring。
对象、集合及可选值必须在使用前取得可转换为文本的具体值。
模板内容还可以包含固定文本、普通字符串转义，以及表示文本花括号的 `{{`、`}}`。

### 4.3 所属对象与错误

字段及其集合中的模板以该字段所属对象为 self；嵌套 data 自身字段中的模板以该 data 为 self。
维度覆盖中的模板以被覆盖字段所属业务对象为 self，文件位置不改变绑定。
已有模板复用时保留其所属对象。

插值从左到右读取并生成文本。字段不存在、读取失败或模板形成循环时返回带来源位置的错误，
不返回部分文本。基础值的文本转换不受宿主区域设置影响。

## 5. 集合与相等

- 数组保留元素顺序；字典保留原始 CFT/CFD 键值项的声明顺序，key 必须唯一。
- data 按实际类型和字段内容比较；记录按所属 Runtime 与记录身份比较。
- 对象内的记录引用只比较身份，不展开被引用记录。
- 数组逐项比较；字典按 key 与对应 value 比较，相等判断不要求声明顺序相同。
- float 使用数值相等，NaN 不等于自身。
- string 按 Unicode 码点序列比较，不自动规范化。
- 比较 fstring 字段或元素时读取生成的文本，读取错误保留来源。

## 6. 值文法

字段、常量和类型别名显式声明类型。None、空数组和空字典使用所在位置的声明类型。
默认值与常量可以包含结构化数据和模板；默认值中的记录引用在加载时链接。

```text
value := scalar-value | string-literal | fstring-literal | bit-expr
       | array-value | dict-value | object-value | reference-value | "None" | qualified-name
scalar-value := [ "-" ] (int-literal | float-literal) | bool-literal
bit-expr := bit-xor { "|" bit-xor }
bit-xor := bit-and { "^" bit-and }
bit-and := bit-term { "&" bit-term }
bit-term := qualified-name | "(" bit-expr ")"
array-value := "[" [ value { "," value } [ "," ] ] "]"
dict-value := "{" [ value ":" value { "," value ":" value } [ "," ] ] "}"
object-value := qualified-name "{" [ field-init { "," field-init } [ "," ] ] "}"
field-init := identifier ":" value
reference-value := "&" [ qualified-name "::" ] record-key
```

qualified-name 在值位置解析为已声明常量或枚举成员。CFD 保存声明对应的数据值，
check 内的计算规则另见[校验表达式](./06-校验表达式.md)。
