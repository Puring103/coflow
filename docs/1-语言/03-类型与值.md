# 类型与值

> 状态：语言设计
>
> 范围：CFT 与 CFD 共享的静态类型类别、可选类型、值语法和值语义。

## 1. 类型语法

```text
type       := unit-type
            | scalar-type
            | optional-type
            | list-type
            | dictionary-type
            | reference-type
            | function-type
            | paren-type
            | qualified-name
unit-type  := "(" ")"
paren-type := "(" type ")"
scalar-type := "int" | "float" | "bool" | "string"
optional-type := ( scalar-type | list-type | dictionary-type | reference-type | function-type | paren-type | qualified-name )
                 "?"
list-type  := "[" type "]"
dict-type  := "{" type ":" type "}"
ref-type   := "&" qualified-name
func-type  := "fn" "(" [ param { "," param } [ "," ] ] ")" "->" type
param      := [ identifier ":" ] type
```

## 2. 类型类别

| 类别 | 类型 | 案例 |
| --- | --- | --- |
| unit | `()` | `fn() -> ()` |
| scalar | `int`、`float`、`bool`、`string` | `hp: int` |
| nominal | enum、普通 type、`@struct` type | `rarity: Rarity` |
| collection | `[T]`、`{K: V}` | `tags: [string]`、`attrs: {string: int}` |
| optional | `T?` | `owner: Item?` |
| 记录引用 | `&T` | `source: &Item` |
| callable | `fn(A...) -> R` | `normalize: fn(int) -> int` |

```cft
type Demo {
  unit_fn: fn() -> ();
  hp: int;
  ratio: float;
  enabled: bool;
  title: string;
  rarity: Rarity;
  tags: [string];
  attrs: {string: int};
  owner: Item?;
  source: &Item;
  normalize: fn(value: int) -> int;
}
```

## 3. 类型规则

- `int` 是有符号 32 位整数，`float` 是 IEEE 754 binary32。
- `bool` 只有 `true` 和 `false` 两个规范值。
- enum 是 nominal type；不同 enum 即使底层整数相同也不兼容；enum 不参与继承。
- 普通 type 既可作为顶层记录类型，也可作为字段中的内联对象；`abstract` type 不能直接创建顶层
  记录；`sealed` type 不允许继续派生。
- 继承只允许子类型用于声明的父类型位置。
- `@struct` 生成值类型，只能修饰 `sealed` type；字段类别不受限制（包括函数字段）。它不参与继承，不能作为父类型，也不能被派生。
- list 元素类型、dictionary key/value 类型和可选 payload 都是不变的静态类型参数。
- dictionary key 只允许 `int`、`bool`、`string` 或 enum 类型，不允许 `float`。
- 函数类型的参数类型序列和返回类型都是不变的静态类型参数，用户函数不能声明泛型参数。
- 可选函数类型写成 `(fn(...) -> R)?`；`&T?` 是可选引用 `(&T)?`，`&` 只能指向 object 类型，因此没有歧义。
- 允许 `int` 到 `float` 的隐式提升；不执行 `float` 到 `int`、`string`/enum、`T?`/`T` 的隐式转换。

## 4. 可选类型

```text
optional-type := ( scalar-type | list-type | dictionary-type | reference-type | function-type | paren-type | qualified-name )
                 "?"
none-value    := "None"
```

- 可选类型写为 `T?`。
- 空值写为 `None`。
- 有值时直接使用 `T` 的值，构造可选值不需要包装。
- 可选 payload 不能再是可选类型，语义层拒绝 `(int?)?`、`(Item?)?`，不存在嵌套可选。
- 在返回 `T?` 的函数体内，表达式后缀 `?` 表示传播：表达式为 `None` 时整个函数立即返回 `None`，否则取出裸值继续求值。
- 传播 `?` 是最高优先级后缀，与 `.`、`[]`、`()` 同级并从左向右结合：`f()?` 等于 `(f())?`，`a?.b` 等于 `(a?).b`；不允许连续 `?`。
- `a ?? b`：`a` 为 `None` 时取 `b`，否则取裸值；`a` 是 `T?`、`b` 是 `T`，结果为 `T`。
- Option 支持与 `None` 做 `==`/`!=`，因此 `x != None` 可判断存在。
- 传播只适用于返回 `T?` 的函数；check 体内不能使用传播。
- 字段省略使用 CFT 默认值；CFD 显式写 `None` 表示明确为空，即使字段默认值不是 `None`。
- 没有默认值的可选字段在 CFD 省略时为 `None`。

```cft
type Demo {
  f: fn(a: Item?, b: Item?) -> int? = fn(a: Item?, b: Item?) -> int? {
    var x = a?;
    var y = b?;
    x.level + y.level
  };
}
```

```cft
type Monster {
  title: string;
  subtitle: string? = None;
  owner: &Monster? = None;
}
```

```cfd
slime: Monster {
  title: "Slime",
  subtitle: "A weak monster",
  owner: None,
}
```

```cfd
boss: Monster {
  title: "Boss",
  # subtitle 省略，使用 CFT 默认值 None
  owner: None,
}
```

## 5. 值形状

```text
ValueShape
├── Unit
├── Scalar(T)
├── Object(T)
├── List(T)
├── Dictionary(K, V)
├── Optional(T)
│   ├── tag: None
│   └── payload(T)
└── Function
    ├── signature
    └── identity or closure or host binding
```

值形状只描述逻辑结构；数据值与函数值使用同一套静态类型。

## 6. 数据值语义

- 普通 CFD 字段只接受 schema-guided 的结构化值。
- 默认值、引用、继承字段和集合在候选构建阶段解析，不在字段首次读取时延迟求值。
- 可选值的 schema-guided 写法是 `None` 或裸 `T` 值；结构化 writer 规范写回裸值。
- 记录引用按声明的目标记录域和 key 解析。
- inline object 与 record reference 是不同值类别。
- list 保留源顺序；dictionary key 必须唯一。
- object 值可以通过可选类型、list、dictionary 和记录引用形成有限递归结构；必填 object 包含环和
  默认值物化环在 schema 编译阶段拒绝。
- 发布后的数据不可变，函数执行不能修改配置记录或集合。

## 7. 常量与别名

```text
alias-decl := "type" identifier "=" type ";"
const-decl := "const" identifier ":" type "=" value ";"
```

- 类型别名只为已有类型提供名称，不创建新的 object type。
- 常量必须声明类型；局部变量可由初始值推断类型。
- 常量在编译期内联或从只读常量存储读取。

```cft
type ItemId = string;
type Callback = fn(value: int) -> int;

const MAX_LEVEL: int = 100;
const DEFAULT_TAGS: [string] = ["common"];
```

## 8. 相等与转换

- 相等遵循对应类型或集合的语言相等语义；dictionary 相等按 key 匹配，不依赖排列顺序。
- 浮点相等遵循数值相等规则，包括 NaN 不等于自身。
- `@struct` 相等按字段逐个比较，函数字段按函数身份比较。
- 除 `int` 到 `float` 的隐式提升外，转换都需要显式方法，失败产生 fault。
- 类型判断使用 `is` 结构；判断成立的分支中，变量或字段访问路径收窄为目标类型。

```cft
type Reward {
  payload: RewardPayload;

  check {
    if payload is CurrencyReward {
      require(payload.amount > 0, "奖励金额必须为正");
    }
  }
}
```

## 9. 值语法

CFT 默认值与 CFD 字段值共享以下值文法：

```text
value        := scalar-value
              | string-literal
              | bit-expr
              | array-value
              | dict-value
              | object-value
              | reference-value
              | "None"
              | function-value
scalar-value := [ "-" ] ( int-literal | float-literal ) | bool-literal
bit-expr     := bit-term { ( "|" | "^" | "&" ) bit-term }
bit-term     := qualified-name | "(" bit-expr ")"
array-value  := "[" [ value { "," value } [ "," ] ] "]"
dict-value   := "{" [ value ":" value { "," value ":" value } [ "," ] ] "}"
object-value := qualified-name "{" [ field-init { "," field-init } [ "," ] ] "}"
field-init   := identifier ":" value
reference-value := "&" [ qualified-name "::" ] record-key
function-value  := "fn" "(" [ param { "," param } [ "," ] ] ")" "->" type block
```

- `string-literal` 包含普通字符串和格式化字符串，规则见 [02-词法与源码](./02-词法与源码.md) §7、§8。
- `bit-expr` 用于 `@flag` enum；单独一个 `qualified-name` 表示 enum 变体或 `const` 路径。
- CFT 默认值可用全部产生式；CFD 普通数据字段不允许 `function-value`。
- `function-value` 只允许直接作为函数字段的默认值，不能嵌套在集合、可选类型或 object 值中。
- 负数由 `scalar-value` 的前导 `-` 表达；enum 值不允许为负。
