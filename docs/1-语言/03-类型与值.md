# 类型与值

> 状态：语言设计
>
> 范围：静态类型、结构化值、记录引用和 fstring 读取。

## 1. 类型文法

```text
type := unit-type | scalar-type | optional-type | list-type
      | dict-type | ref-type | func-type | paren-type | qualified-name
unit-type := "(" ")"
paren-type := "(" type ")"
scalar-type := "int" | "float" | "bool" | "string" | "fstring"
optional-type := (scalar-type | list-type | dict-type | ref-type
                | func-type | paren-type | qualified-name) "?"
list-type := "[" type "]"
dict-type := "{" type ":" type "}"
ref-type := "&" qualified-name
func-type := "fn" "(" [ param { "," param } [ "," ] ] ")" "->" type
param := [ identifier ":" ] type
```

`fn() -> T?` 是返回可选值的函数；可选函数写 `(fn() -> T)?`。
`&T?` 是可选记录引用。函数类型中的参数名不影响类型相等。

## 2. 基本类型规则

| 类型 | 含义 |
| --- | --- |
| () | 无返回值 |
| int / float / bool | 32 位整数、binary32 浮点数、布尔 |
| string | 已经生成的文本 |
| fstring | 用 f"..." 声明的文本函数，读取得到 string |
| enum | 独立的命名枚举类型 |
| T | 对象内容，可用于记录或内联对象 |
| &T | 配置记录引用 |
| [T] / {K: V} | 只读数组、字典 |
| T? | None 或一个 T 值 |
| fn(...) -> R | 普通函数值 |

- int 可隐式提升为 float；其余普通数值转换使用显式方法。
- 子类型可以用于父类型位置。
- `@struct` 是目标代码的值类型表示，相等规则仍按对象内容。
- 集合类型参数不变；函数的参数和返回类型也不变。
- 字典 key 只允许 int、bool、string 或 enum。
- 函数值可出现在字段、集合、可选值、内联对象、默认值和常量中，按所在位置的类型检查。
- abstract 类型在任何位置都不能直接构造；必须使用具体子类型。

## 3. 对象与记录引用

`T` 表示对象内容，`&T` 表示有记录身份的引用。两者都使用 `.field` 读取字段。

- `&T` 可用于需要 `T` 的位置，读取原对象内容，不复制记录。
- 内联对象不能自动变成记录引用。
- 记录引用的 `id` 类型固定为 string。`T` 不承诺记录身份，不能读取 `id`。
- `records(T)` 返回 `[&T]`，规则见[Check 校验](./07-Check校验.md)。
- `@idAsEnum` 只影响目标代码生成，不改变 `id` 的语言类型。
- 直接或间接的递归字段必须经过可选类型或记录引用；数组、字典本身不作为递归例外。
- `next: Node` 和 `children: [Node]` 不能用于 Node 的递归字段；`next: Node?`、`next: &Node`、`children: [&Node]` 可以。
- 允许可选递归不代表允许无限展开默认值；默认值物化仍须有限。
- 记录引用本身可以形成循环，不能因为引用环而递归复制记录。

引用写法见[CFD 数据](./05-CFD数据.md)。

## 4. 可选值

`T?` 使用 `None` 或裸 `T` 值，不使用 Some 构造器。
可选类型不能嵌套，例如 `(int?)?` 不合法。

None 与 0、false、空字符串和默认对象都是不同的值。可选递归在运行时通过间接引用表示，不把对象无限内联到自身。

| 字段输入 | 结果 |
| --- | --- |
| 提供值 | 使用该值 |
| 省略且有默认值 | 使用默认值 |
| 省略、无默认值、可选 | None |
| 省略、无默认值、必填 | 加载错误 |
| 显式 None | 可选字段明确为空 |

在返回可选类型的函数内，`value?` 遇到 None 时立即返回 None，否则取出其中的值。
check 本身和 fstring 插值不能使用这种向外传播。

同类型可选值可以比较，也可以与 None 比较；与裸值比较前需要解包。
`is Some(name)` 在条件中引入只读绑定，规则见[函数与表达式](./06-函数与表达式.md)。

## 5. fstring

### 5.1 声明和读取

`fstring` 是独立类型，只接受 `f"..."` 初始化。普通字符串、函数值和已求值的文本不能代替该字面量。

```cft
type Item {
  name: string;
  label: fstring = f"名称：{self.name}";
  labels: [fstring] = [f"{self.name}", f"固定文本"];
  note: fstring? = None;
}
```

- 读取 fstring 字段时执行文本函数，得到普通 string，无需括号或 render 方法。
- 每次读取重新计算，不缓存上次结果。已经确认不变的部分可以编译为常量。
- `var text = item.label;` 只计算一次，之后 text 是普通 string。
- fstring? 为 None 时读取得到 None；有值时读取得到 string，因此读取结果是 string?。执行错误不会转成 None。
- 获取 `[fstring]` 或字典本身不计算元素；索引或遍历读取具体 fstring 元素时才计算。
- `[fstring]` 不自动转换为 `[string]`。字典 value 适用相同规则。
- fstring 不能作为字典 key。

### 5.2 使用位置和绑定

有明确 fstring 存储类型的位置保留文本函数，包括对象字段、集合元素、可选值和显式声明的局部存储。
普通表达式位置的 `f"..."` 则在执行到该表达式时生成 string：

```cft
var text = f"名称：{item.name}";
```

文本函数里的 self 是所属对象，只读。运行时创建文本函数时，实际使用的外层参数和局部值按创建时的值捕获。
以后重新给外层局部变量赋值，不改变已保存的捕获值。

插值从左到右，每处执行一次。计算失败时整个读取失败，不返回半截文本。
相互读取造成的循环沿用函数的调用深度和预算限制。

## 6. 集合与相等

- 数组保留顺序；字典保留原始 CFT 或 CFD 中键值项的声明顺序，key 必须唯一。
- 使用 CFT 默认值或常量中的字典时保留其 CFT 顺序；CFD 提供字典时保留该 CFD 值的顺序。复制、编译和加载都不重排键值项。
- 函数体中的字典字面量按源码中键值项的书写顺序构造。遍历、keys() 和 values() 均使用所保存的顺序，不按 key 或哈希表顺序排列。
- 普通对象按实际类型及字段内容比较；记录引用按所属 Runtime 和记录身份比较。
- 比较对象中的引用字段时只比较引用身份，不继续展开被引用记录。
- 函数按函数身份比较；复制同一个函数值保留身份。
- 数组按顺序逐项比较；字典按 key 及对应 value 比较，相等判断不要求声明顺序相同。
- float 使用数值相等，NaN 不等于自身。
- 内容比较读取 fstring 字段或元素时会计算文本，可能产生执行错误。不能因为访问的是同一对象而省略动态读取。

## 7. 常量、推断和结构化值

类型别名不创建新类型。`const` 必须声明类型；常量的值、函数定义或文本函数定义在 CFT 编译时确定。
普通 string 常量保存固定文本，动态文本应声明为 fstring 或普通函数。

局部变量可以推断类型。`None`、`[]`、`{}` 单独不足以确定类型，必须从声明、参数、返回值等位置取得期望类型。
有期望类型时，分别检查 if 的各分支能否赋给该类型。

```text
value := unit-literal | scalar-value | string-literal | fstring-literal | bit-expr
       | array-value | dict-value | object-value | reference-value
       | "None" | function-value
unit-literal := "(" ")"
scalar-value := [ "-" ] (int-literal | float-literal) | bool-literal
bit-expr := bit-xor { "|" bit-xor }
bit-xor := bit-and { "^" bit-and }
bit-and := bit-term { "&" bit-term }
bit-term := qualified-name | "(" bit-expr ")"
array-value := "[" [ value { "," value } [ "," ] ] "]"
dict-value := "{" [ value ":" value { "," value ":" value } [ "," ] ] "}"
object-value := qualified-name "{" [ field-init { "," field-init } [ "," ] ] "}"
field-init := identifier ":" value
reference-value := "&" [ qualified-name "::" ] record-key
function-value := "fn" "(" [ named-param { "," named-param } [ "," ] ] ")" "->" type block
named-param := identifier ":" type
```

单独的限定名可以表示常量或 enum 变体。位表达式只用于同一 flag 类型，优先级与普通表达式一致。
普通数据值不包含任意函数调用；函数体和 fstring 插值内可以使用完整表达式。
