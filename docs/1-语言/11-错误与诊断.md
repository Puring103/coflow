# 错误与诊断

> 范围：编译加载错误、执行错误和可选检查报告。

## 1. 错误边界

| 类别 | 结果 |
| --- | --- |
| 语法、类型、必填值、引用和链接错误 | 构建失败，仍返回诊断与可用分析结果 |
| 函数或 fstring 执行错误 | 当前调用或读取失败 |
| require 不满足 | 记录检查问题，继续当前 check |
| check 执行错误 | 记录错误，结束当前 check，继续其他 check |
| 检查总预算耗尽 | 停止检查，报告未完成 |

check 可选，其报告不决定 Runtime 是否可用。
普通函数通过返回值表达业务结果，不把业务结果自动当成诊断。

## 2. 词法与语法

| 条件 | 说明 |
| --- | --- |
| 非法字符或标识符 | 不符合 token 或名称规则 |
| 非法转义 | 转义未知，Unicode 超出范围、为代理项或位数不合法 |
| 字符串未闭合 | 到换行或输入末尾仍未闭合 |
| 数字不完整 | 小数或指数缺少数字 |
| fstring 插值未闭合 | 花括号或其中的表达式未闭合 |
| fstring 孤立右花括号 | 文本右花括号未写为 }} |
| 缺少符号 | 缺少分隔符、括号、冒号或分号 |
| 表达式不完整 | 缺少操作数、参数或函数体 |

普通字符串中的单个花括号不是错误，只有 f"..." 解释插值。

## 3. 声明和名称

| 条件 | 说明 |
| --- | --- |
| 声明重名 | 同一命名空间的声明名称重复 |
| 成员重名 | 类型及继承链中字段或命名 check 同名 |
| 局部重名 | 同一作用域重复声明，或与参数重名 |
| 使用保留名称 | 声明 self 等保留名称，或覆盖系统声明 |
| 未知或歧义名称 | 类型、常量、成员或导入不能唯一解析 |
| namespace/use 错误 | 位置错误、重复 namespace、导入冲突或目标无效 |
| enum 重复或越界 | 变体名或值重复，普通 enum 超出非负 i32 |
| flag 声明错误 | 超出 32 位、非零值不是单个位或重复 |
| abstract 直接构造 | 记录、默认值或函数体直接构造抽象类型 |
| 继承错误 | 继承 sealed 或 singleton、继承环、多父类型、struct 参与继承，或不符合 table/data/singleton 的父类型规则 |
| 非法递归字段 | 递归路径未经过可选类型或记录引用，包含仅由数组、字典包裹的递归 |
| 默认构造无界 | 默认值无限展开，即使类型允许可选递归也报错 |
| 别名或常量依赖环 | 无法得到有限类型或常量定义 |
| 注解错误 | 目标不支持、重复或互相冲突 |
| Host 声明错误 | @Host 未用于 singleton，或其函数字段声明了默认实现 |
| singleton 错误 | 普通单例缺少唯一记录、记录数量不为一或 key 不正确 |
| idAsEnum 元数据错误 | 目标不是空 enum 或与 singleton 冲突 |
| check 声明错误 | 在 data 中声明 check、未置于字段之后，同一记录类型多个匿名 check 或命名冲突 |

## 4. 类型与值

| 条件 | 说明 |
| --- | --- |
| 值不可赋值 | 初始化、参数、赋值或返回不符合期望类型 |
| 类型用途错误 | 在类型位置使用 & 前缀，将 data 用作记录，或将记录用作内联 data |
| 缺少类型声明 | var 声明、字段、常量或函数签名未显式声明要求的类型；for 和 Some 绑定使用输入类型 |
| 分支不匹配 | 可到达分支不能赋给明确声明的期望类型 |
| 函数签名错误 | 参数数量、参数类型或返回类型不匹配 |
| 非法赋值 | 修改只读参数、self、捕获值或普通不可变字段、集合 |
| 非法局部构造 | 目标不是具体 data、数组或字典，构造绑定逃逸、读取未初始化字段、正常出口缺失必填值或冻结前读取未发布绑定 |
| 收窄失效 | 重新赋值后继续按旧子类型访问 |
| 无效字段或方法 | 成员不存在或不适用于该类型 |
| id 访问错误 | 在 data 上访问记录 id；table 和 singleton 的记录及 self 正常访问 id |
| 字典 key 错误 | 类型不支持或重复 key |
| 索引类型错误 | 索引不符合数组、字典或字符串要求 |
| 可选值误用 | 未解包、非法传播、嵌套可选或与裸值直接比较 |
| 类型判断错误 | is 目标或 Some 绑定位置不合法 |
| 运算符错误 | 类型不支持或链式比较 |
| 循环错误 | 迭代类型、绑定数量或 break/continue 位置不合法 |
| 返回错误 | 返回类型不符或可到达出口缺少返回值 |
| fstring 初始化错误 | 在 fstring 期望类型位置提供普通 string、普通函数或其他非模板值，或用作字典 key |
| 插值类型错误 | 结果不能直接转换为文本 |
| 插值控制流错误 | 向外使用 ?、return、break 或 continue |

函数字面量可嵌套于集合、可选值、对象和默认值；按所在位置的函数类型检查。
fstring? 执行错误不是 None；已有普通字符串不会在后续读取时重新求值。

## 5. 记录与维度加载

| 条件 | 说明 |
| --- | --- |
| 数值越界 | 普通 int 超出范围，或 flag 值包含未知位 |
| 记录字段错误 | 必填字段缺失、未知字段或重复字段 |
| 记录 key 重复 | 同一继承树中的记录 key 不唯一，包含父子类型及兄弟类型之间的重复 |
| 内联类型错误 | 未写类型名、使用抽象类型或类型不可赋值 |
| Host 数据来源错误 | 用 CFD 记录或用户内联对象构造 Host 服务，或用 CFD 覆盖 Host 实现 |
| 悬空引用 | 指定类型中的记录不存在 |
| 引用类型错误 | 目标类型不能赋给声明类型，或引用写成字符串 |
| 无本类型上下文 | 使用裸 &key 却没有本类型 |
| 无效维度覆盖 | 字段内变体的值不能赋给业务字段声明类型 |
| 无效维度访问 | 非维度字段调用维度方法 |
| 非法维度位置 | data 或用户内联对象声明维度字段 |

可选字段的维度显式 None 是有效覆盖；缺失或未知变体回退到 default。
未知变体按维度规则处理，不因为无覆盖而产生必填字段错误。

## 6. 执行错误

| 条件 | 说明 |
| --- | --- |
| 整数溢出 | checked 算术超出 i32，包括最小值取负和 abs |
| 整数除零 | // 或 % 的分母为零 |
| 非法移位或幂 | 位数不在 0—31，或 int 幂为负指数 |
| 非法转换 | float 转 int 为 NaN、无穷或越界，enum 构造不合法 |
| 无效索引 | 数组或字符串负索引及越界、字典 key 不存在；字符串边界按 Unicode 码点数检查 |
| 内建前置条件不满足 | 方法参数或输入不满足约定 |
| 无效函数调用 | 函数缺失或目标不可调用 |
| Host 异常 | 未处理的外部异常 |
| Host 未绑定 | 实际调用未绑定服务的函数，或读取其宿主数据 |
| 预算耗尽 | 指令、调用深度、临时值或集合工作量超限 |
| 失效句柄 | Runtime 已释放、所属 Runtime 不符，或动态值已回收且位置被复用 |
| 运行时数据错误 | 发现无效地址索引、程序引用或内部状态 |

fstring 复用上述错误，不返回半截文本、不缓存错误前的部分结果。
循环文本读取沿用调用深度和预算限制。
执行错误退出时清理本次调用栈、寄存器和临时保活记录，保留外层调用及宿主仍持有的值。
契约读取处理必要的格式、版本和读取错误，不重复执行完整语义验证。
Host 绑定缺失允许构建成功，与普通记录的悬空引用、必填值缺失和函数签名错误分别处理。

## 7. check 专用限制

check 可以调用任何普通函数和 Host 函数，不产生“调用普通函数越权”错误。

check 不是普通可调用值；普通函数不能主动调用 check。
check 本体不能 return 或向外传播可选值。
records 只用于顶层 check。require 是普通 Host 函数，可以在普通函数和闭包中调用、保存和传递。
require 的参数按普通调用立即求值，条件为 true 时仍求值消息；消息计算错误保留真实调用位置。
check 外调用 require 的行为由宿主绑定负责，不产生语言或 VM 的专用调用权限错误。

## 8. 诊断内容

每条诊断包含稳定错误码、级别、消息、必要源码位置和相关位置。
涉及记录时附带记录身份，涉及函数或 fstring 时附带调用或读取位置。
基本错误位置始终保留，详细调试追踪可以关闭。

编辑器根据分析结果展示错误和未完成源码；运行检查报告与编译诊断分别展示。
