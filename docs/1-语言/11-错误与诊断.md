# 错误与诊断

> 状态：语言设计
>
> 范围：CFT/CFD 全部错误、诊断和 fault 条件。

本文档集中定义语言层会产生的全部错误。各主题文档只描述正常语义，错误条件以本文档为准。

## 1. 结果模型

| 结果 | 产生位置 | 表现 |
| --- | --- | --- |
| 类型验证失败 | 数据或边界值进入执行环境前 | 诊断，阻止值进入 |
| 业务返回值 | 普通函数 | 普通返回类型、枚举或业务结构 |
| check 失败 | check 执行 | 可继续收集的结构化诊断 |
| 执行 fault | 执行不变量、预算、非法操作、未处理外部异常 | 绑定源码位置和调用信息的执行错误 |

诊断和 fault 都绑定最小可定位的 source span。业务返回值不是错误，通过普通返回类型、枚举或业务
结构表达。

## 2. 词法错误

| 条件 | 说明 |
| --- | --- |
| 非法字符 | 出现不属于任何 token 的字符 |
| 非法转义 | 字符串中出现 `\"`、`\\`、`\n`、`\r`、`\t`、`\u{...}` 之外的转义 |
| 字符串未闭合 | 字符串到达输入结束或换行仍未闭合 |
| 数字缺小数位 | `.` 后没有数字 |
| 数字缺指数位 | `e`/`E` 后没有数字 |
| 插值未闭合 | 格式化字符串中的 `{` 没有对应 `}` |
| 未配对 `}` | 格式化字符串中出现无法配对的 `}` |
| 非法标识符 | 需要标识符的位置出现不符合标识符规则的文本 |

```cfd
name: "unterminated,
ratio: 12.,
label: "{name",
literal: "}",
```

## 3. 语法错误

| 条件 | 说明 |
| --- | --- |
| 意外 token | 当前位置不允许该 token |
| 缺少 token | 缺少必需的 `;`、`,`、`:`、`}`、`)`、`]` 或 `=>` |
| 未闭合结构 | block、数组、字典、对象、enum 或类型体未闭合 |
| 表达式不完整 | 运算符缺少操作数或表达式缺失 |
| match arm 不完整 | arm 缺少 `=>` 或结果表达式 |
| 函数体错误 | 函数体不合语法或包含块外文本 |

```cft
type Item {
  name string;      # 缺少 `:`
}
```

## 4. 声明错误

| 条件 | 说明 |
| --- | --- |
| 重复声明 | 同一命名空间内出现同名 type、enum、常量或 check |
| 重复字段 | 同一 type 声明了两个同名字段 |
| 重复 enum 变体 | 同一 enum 声明了两个同名变体 |
| enum 值冲突 | 两个变体显式使用了相同整数值 |
| enum 值类型错误 | 变体值不是合法 `i32` 或为负数 |
| `@flag` 值错误 | `@flag` enum 出现非 2 的幂值或重复值 |
| 抽象类型作记录 | `abstract` type 被直接用作顶层记录 |
| 派生 sealed 类型 | 对 `sealed` type 继续派生 |
| 多重继承 | 一个 type 声明了多个直接父 type |
| 继承环 | type 继承关系形成环 |
| 必填 object 包含环 | 直接或间接的必填 object 包含形成环 |
| 默认值物化环 | 默认值展开形成无界环 |
| 别名错误 | 类型别名成环或指向不存在的类型 |
| 常量类型错误 | `const` 的类型与值不匹配，或常量依赖成环 |
| 注解目标错误 | 注解用于其允许目标之外的位置 |
| 重复注解 | 同一目标重复使用同名注解 |
| 维度注解冲突 | `@localized` 与 `@dimension` 同时用于同一字段 |
| 维度字段位置错误 | 维度字段位于 sealed 内联 type 中 |
| `@idAsEnum` 错误 | 目标 enum 非空、缺失或与 `@singleton` 同时使用 |
| 函数默认值位置错误 | 函数默认值嵌套在集合、可选类型或 object 默认值中 |
| 函数默认值签名错误 | 函数默认实现与字段签名不一致 |
| `@Host` 实现错误 | CFD 为 `@Host` 函数提供了实现 |
| 保留名称冲突 | 声明使用系统保留名称 |

```cft
type Item {
  name: string;
  name: int;    # 重复字段
}
```

## 5. 名称与命名空间错误

| 条件 | 说明 |
| --- | --- |
| 未知名称 | 引用了不存在的类型、enum、常量、字段或函数 |
| 短名歧义 | 一个短名在当前作用域匹配多个声明 |
| 导入冲突 | 两条 `use` 引入同名声明 |
| 命名空间位置错误 | `namespace` 出现在导入或声明之后 |
| 重复命名空间 | 一个文件声明了多条 `namespace` |
| 覆盖系统声明 | 声明与 `std` 系统名称冲突 |
| `::` 误用 | 在不允许的位置使用 `::` |

```cft
type Monster {
  drop: &MissingItem;   # 未知类型
}
```

## 6. 类型错误

| 条件 | 说明 |
| --- | --- |
| 类型不可赋值 | 值与期望类型不兼容 |
| 参数数量错误 | 函数调用或声明的参数数量不匹配 |
| 字典 key 类型错误 | key 类型不是 `int`、`bool`、`string` 或 enum |
| for 绑定错误 | dictionary `for` 未使用双绑定，或绑定数量不符合容器 |
| for 可迭代类型错误 | `for` 头部不是 range、list 或 dict |
| 返回类型错误 | 函数出口类型与声明返回类型不一致 |
| 缺少返回 | 可到达出口的路径没有返回值 |
| 分支类型不一致 | `if` 或 `match` 分支产生不同静态类型 |
| match 不穷尽 | 表达式位置的 `match` 未覆盖全部情况 |
| 运算符操作数错误 | operand 类型不受该运算符支持 |
| 字段或方法不存在 | 访问不存在的字段或内建方法 |
| 索引类型错误 | 索引表达式类型与集合索引不匹配 |
| 类型判断目标错误 | `is` 的目标不是有效类型或可选模式 |
| 显式转换错误 | 使用了未注册的转换 |
| 可选类型误用 | 未处理 `None` 就按存在值使用 |
| 可选传播错误 | `?` 用于非返回 `T?` 的函数，或作用于非 Option 值 |
| 空值合并类型错误 | `??` 左侧不是 Option，或右侧类型与 payload 不匹配 |
| if 分支值错误 | 无 `else` 的 `if` 的 then 分支产生非 unit 值 |
| 复合赋值类型错误 | 复合赋值结果不可赋给变量声明的类型 |
| 非法 `??` 链 | `??` 的结果继续参与 `??` |
| 嵌套可选 | 可选 payload 仍是可选类型 |

```cft
type Demo {
  f: fn(value: int) -> string = fn(value: int) -> string {
    value + 1     # 返回 int，与声明的 string 不一致
  };
}
```

## 7. CFD 值与引用错误

| 条件 | 说明 |
| --- | --- |
| 整数越界 | 整数字面量超出 `int` 范围 |
| 未知 enum 变体 | 使用了 enum 未声明的变体 |
| flag 位表达式错误 | 位表达式操作数不是同一 `@flag` enum |
| 缺少必填字段 | 记录缺少无默认值的必填字段 |
| 未知字段 | 记录出现 CFT 未声明的字段 |
| 重复字段 | 记录对同一字段赋值两次 |
| 重复 record key | 同一类型域出现重复 record key |
| 类型不匹配 | 字段值与声明的字段类型不兼容 |
| type marker 缺失 | 内联对象未写类型名，`{ ... }` 只作字典 |
| type marker 错误 | type marker 指定的类型不可赋给字段类型 |
| 字典 key 重复 | 字典字面量出现重复 key |
| 悬空引用 | 记录引用指向不存在的 record key |
| 引用歧义 | `&key` 在目标类型域内匹配到多条记录 |
| 引用类型错误 | 被引用记录的实际 type 不可赋给声明类型 |
| 引用加引号 | 记录引用写成了字符串 |
| 格式化字段错误 | 格式化字符串引用了不存在或不可插值的字段 |
| 函数签名不匹配 | CFD 函数值与 CFT 字段签名不一致 |

```cfd
sword: Item {
  rarity: Legendary,   # 未知 enum 变体
  owner: "&other",     # 引用不能加引号
}
```

## 8. check 诊断

| 条件 | 说明 |
| --- | --- |
| 规则不满足 | `require` 条件为 `false` |
| 求值错误 | 除零、越界、非法转换、空值访问或无效数值 |
| 预算耗尽 | check 工作量或迭代次数超限 |
| 非法能力 | check 访问了不允许的 Host 外部服务 |
| 调用图违规 | check 调用了普通函数，或普通函数调用了 check |
| check 内 return | check 体内使用 `return` |
| `records` 误用 | `records(Type)` 用于顶层 check 之外的位置 |

```cft
type Monster {
  level: int;

  check {
    require(level > 0, "等级必须大于 0");   # 条件为 false 时产生诊断
  }
}
```

`require` 的自定义消息替换该条诊断的解释，但不覆盖求值错误。

## 9. 执行 fault

| 条件 | 说明 |
| --- | --- |
| 整数溢出 | checked 32 位运算溢出 |
| 移位位数错误 | 移位位数不在 `0..32` 内 |
| 幂指数错误 | `int` 幂使用负指数 |
| 数值越界转换 | `.int()` 得到 NaN/无穷/越界，或 `i32::MIN` 取负、取绝对值 |
| enum 负值构造 | `EnumName` 传入负值 |
| 除零 | 整数除法 `//` 或 `%` 分母为零 |
| 非法转换 | 显式转换失败 |
| 无效索引 | 数组、字典或字符串索引越界 |
| 前置条件不满足 | 内建操作不满足语言前置条件 |
| 缺失函数 | 调用了没有实现的普通函数 |
| 未绑定 Host | 调用了未绑定的 Host 函数 |
| Host 异常 | Host 函数抛出未处理异常 |
| 无效间接调用 | 间接调用目标无效 |
| 状态不变量破坏 | 执行状态不满足不变量 |
| 预算耗尽 | 指令、frame、寄存器、集合、导入或逸出值预算超限 |
| 失效函数引用 | 调用了所属执行环境已释放的函数引用 |

```cft
type Demo {
  f: fn(value: int) -> int = fn(value: int) -> int {
    value // 0     # 除零 fault
  };
}
```

## 10. 诊断字段

每条诊断至少包含：

- 稳定标识和严重级别。
- 消息。
- 最小 source span。
- 相关位置和上下文。

涉及跨记录依赖的诊断额外携带所属记录和依赖的顶层字段。
