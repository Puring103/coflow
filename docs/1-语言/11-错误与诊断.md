# 错误与诊断

> 范围：声明与数据加载诊断、模板读取错误和检查报告。

## 1. 错误边界

| 类别 | 结果 |
| --- | --- |
| 语法、类型、必填值、引用或覆盖错误 | 构建失败，返回来源诊断 |
| fstring 读取错误 | 本次文本生成失败 |
| require 条件不满足 | 记录检查问题，继续当前 check |
| check 求值错误 | 记录错误，结束当前规则，继续其他规则 |
| 检查总预算耗尽 | 停止检查，报告未完成 |

检查报告不改变已构建 Runtime 的可用状态。

## 2. 词法与语法

非法字符、标识符、转义、未闭合字符串和块、缺失分隔符均保留准确源码位置。
数字必须符合字面量格式；Unicode 转义必须是有效标量值。
fstring 用字段路径插值，文本花括号写为 {{ 与 }}，路径与花括号必须完整。
普通 string 中的花括号是文本。

基础记录以 `key: Type` 开头，维度覆盖以 `dimension[variant]` 开头。
记录体中的字段使用冒号和值，维度覆盖块的内部使用目标记录体。

## 3. 声明与名称

| 条件 | 说明 |
| --- | --- |
| 声明或成员重名 | 同一命名空间、类型或继承链中名称冲突 |
| 未知或歧义名称 | 类型、常量、成员或导入不能唯一解析 |
| namespace/use 错误 | 位置错误、重复 namespace 或导入冲突 |
| enum/flag 错误 | 变体名或值重复、越界或非法标志位 |
| 继承错误 | 继承类别不匹配、环、封闭父类型或 struct 参与继承 |
| 抽象类型构造 | 记录或默认值直接使用 abstract 类型 |
| 递归或默认值无界 | data 递归未经过可选类型，或默认值不能有限展开 |
| 注解错误 | 使用目标不匹配、重复或冲突 |
| singleton 错误 | 唯一记录缺失、数量不为一或 key 不正确 |
| check 声明错误 | 声明位置、匿名规则数量或命名冲突 |

## 4. 数据与维度覆盖

| 条件 | 说明 |
| --- | --- |
| 值类型错误 | 字段、集合项或默认值不符合声明类型 |
| 记录字段错误 | 必填值缺失、未知字段或重复字段 |
| 记录 key 重复 | 同一继承树中出现重复 key |
| 引用错误 | 目标不存在、类型不匹配或缺少静态本类型上下文 |
| 未知维度 | 覆盖块头部的维度没有对应 CFT 声明 |
| 覆盖目标错误 | 目标记录或类型不存在 |
| 覆盖字段错误 | 字段不存在或没有声明对应维度 |
| 重复覆盖 | 全部来源中同一维度、变体、记录和字段出现多个覆盖 |
| 覆盖值错误 | 覆盖值不符合原字段类型 |
| 模板错误 | 初始化类型、插值字段路径或末端文本类型不符合要求 |

可选字段的显式 None 是有效覆盖；未覆盖的字段和未知变体查询返回基础值。
诊断定位到出错的覆盖文件与字段，重复覆盖附带相关来源位置。

## 5. 求值与检查错误

check 中整数溢出、整数除零、非法转换、索引越界与内建前置条件不满足产生求值错误。
局部变量与绑定必须符合已声明类型和作用域，字段及集合保持只读。
可选值解包、类型收窄、循环与运算按[校验表达式](./06-校验表达式.md)检查。
records 只用于顶层 check；require 的现行条件与消息均立即求值。

fstring 字段读取错误及循环模板读取保留模板来源和读取位置，不返回部分文本。
遍历、内建操作和文本生成受执行预算约束，预算耗尽报告检查未完成。

## 6. 诊断内容

每条诊断包含稳定错误码、级别、消息及必要源码位置与相关位置。
记录相关诊断附带类型和 key，覆盖相关诊断附带维度、变体及覆盖字段来源。
模板错误附带模板与字段读取位置，检查问题附带规则及被检查数据位置。

编辑器分别展示声明／加载诊断和业务检查报告。
