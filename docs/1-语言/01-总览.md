# Coflow 语言总览

> 范围：CFT 与 CFD 的共同语言规则。

## 1. 基本原则

- CFT 定义类型、默认值、常量、维度字段和 check；CFD 提供基础记录与维度覆盖。
- table 声明可引用记录，data 声明内联值，singleton 声明唯一记录；字段中的声明名称决定引用或内联语义。
- 配置数据只读；数据更新通过重新加载完成。
- 字段与类型别名显式声明类型；常量可以推断无歧义的值类型。
- 普通字符串保存文本，fstring 提供字段路径插值，读取得到普通字符串。
- check 是编辑器执行的声明式数据校验规则。
- 集合顺序、数值规则和源码位置由语言统一规定。

## 2. 生成与加载

```text
CFT -> 声明检查 -> 类型描述 -> 生成业务类型
                                  |
CFD -> C# 加载器 -> 默认值、覆盖、引用与基础插值 -> 业务数据

CFT + CFD -> 编辑器数据模型 -> check 报告
```

基础记录与维度覆盖可以跨文件。记录引用允许成环，加载时按身份链接。
fstring 按字段路径生成文本；C# 加载器在加载时完成基础插值。

## 3. 字符串与维度

```cft
table Item {
  @localized
  name: string;
  price: int;
  label: fstring = f"价格：{self.price}";
}
```

```cfd
sword: Item {
  name: "Sword",
  price: 100,
}

language[ja] {
  sword: Item {
    name: "剣",
  }
}
```

普通记录使用 `key: Type { ... }`，维度覆盖使用 `dimension[variant] { ... }`。
两者由语法区分。覆盖只替换写出的字段，其他字段使用基础值。

## 4. 结果与错误

| 结果 | 含义 |
| --- | --- |
| 编译或加载诊断 | 语法、类型、必填值、引用或覆盖存在错误，不能完成数据加载 |
| 数据读取结果 | 普通字段值或 fstring 生成的文本 |
| check 报告 | 规则不满足或检查执行出错；不改变 C# 数据加载边界 |
| 求值错误 | 字段读取、文本生成或检查计算失败，保留源码位置 |

## 6. 文法记法

`:=` 表示定义，`|` 表示选择，`[x]` 表示可选，`{x}` 表示重复，
双引号内为固定符号。文法说明结构；类型约束和求值规则以对应章节为准。
