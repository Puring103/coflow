# Coflow 语言总览

> 范围：CFT 与 CFD 的共同语言规则。

## 1. 基本原则

- CFT 定义类型、默认值、常量、维度字段和 check；CFD 提供基础记录与维度覆盖。
- table 和 singleton 声明记录类型，data 声明内联数据类型。记录通过身份引用，data 按内容保存。
- 配置数据只读；数据更新通过重新构建运行时完成。
- 字段、常量与类型别名显式声明类型。
- 普通字符串保存文本，fstring 提供字段路径插值，读取得到普通字符串。
- check 是显式执行的数据校验规则，检查报告不决定 Runtime 是否可用。
- 集合顺序、数值规则和源码位置由语言统一规定。

## 2. 编译与运行

```text
CFT -> 声明检查 -> 只读契约 -> 目标语言代码
                         |
CFD -> 解析、类型检查、默认值补齐、维度覆盖、引用链接
                         |
                       Runtime
                         |
                 数据读取、显式 check
```

基础记录与维度覆盖可以跨文件。记录引用允许成环，加载时按身份链接。
fstring 保存模板与字段所属对象，读取时按字段路径生成文本。

## 3. 字符串与维度

```cft
table Item {
  @localized
  name: string;
  price: int;
  label: fstring = f"价格：{self.price}";
}
```

```cfd
sword: Item {
  name: "Sword",
  price: 100,
}

language[ja] {
  sword: Item {
    name: "剣",
  }
}
```

普通记录使用 `key: Type { ... }`，维度覆盖使用 `dimension[variant] { ... }`。
两者由语法区分。覆盖只替换写出的字段，其他字段使用基础值。

## 4. 结果与错误

| 结果 | 含义 |
| --- | --- |
| 编译或加载诊断 | 语法、类型、必填值、引用或覆盖存在错误，不能正常构建 Runtime |
| 数据读取结果 | 普通字段值或 fstring 生成的文本 |
| check 报告 | 规则不满足或检查执行出错；Runtime 仍可使用 |
| 求值错误 | 字段读取、文本生成或检查计算失败，保留源码位置 |

## 6. 文法记法

`:=` 表示定义，`|` 表示选择，`[x]` 表示可选，`{x}` 表示重复，
双引号内为固定符号。文法说明结构；类型约束和求值规则以对应章节为准。
