# 词法与源码

> 状态：语言设计
>
> 范围：CFT、CFD 与内嵌函数体共享的源码编码、标识符、字面量、注释和源码位置。

## 1. 编码与文件

- 源码使用 UTF-8 编码。
- CFT 文件使用小写扩展名 `.cft`，CFD 文件使用小写扩展名 `.cfd`。
- 换行接受 `\n` 与 `\r\n`；规范输出统一使用 `\n`，并以一个换行结束。
- 空白不参与语义。缩进、续行与空行策略由[源码格式化](./10-源码格式化.md)定义。

```cft
# 这是注释
type Item {
  name: string;
}
```

## 2. 词法记法

```text
identifier     := identifier-start { identifier-continue }
metadata-name  := "$" identifier
int-literal    := digit { digit | "_" }
float-literal  := digit { digit }
                  ( "." digit { digit } [ exponent ]
                  | exponent )
                | "inf"
exponent       := ( "e" | "E" ) [ "+" | "-" ] digit { digit }
bool-literal   := "true" | "false"
string-literal := '"' { string-char | escape } '"'
escape         := "\" ( '"' | "\" | "n" | "r" | "t" | "u{" hex-digit { hex-digit } "}" )
hex-digit      := digit | "a" | "b" | "c" | "d" | "e" | "f" | "A" | "B" | "C" | "D" | "E" | "F"
comment        := "#" { any-char-except-newline }
```

## 3. 标识符

- 首字符为 `_` 或 Unicode XID start。
- 后续字符为 `_` 或 Unicode XID continue。
- 标识符区分大小写。
- 编译期元数据标识符以 `$` 开头，例如 `$type`、`$field`、`$id`。
- `$` 名称只用于编译期元数据，不参与值表达式；记录虚拟字段 `id` 是运行期可读值，二者不同。

```text
name
_variant
变量
$type
```

保留字由语法统一定义，至少覆盖以下类别：

| 类别 | 保留字 |
| --- | --- |
| 声明与结构 | `type`、`enum`、`abstract`、`sealed`、`const`、`check`、`namespace`、`use`、`fn` |
| 函数与控制流 | `var`、`return`、`if`、`else`、`match`、`for`、`while`、`break`、`continue`、`in`、`is` |
| 字面量 | `true`、`false`、`None`、`Some`、`inf` |
| 内建类型名 | `int`、`float`、`bool`、`string` |
| 特殊名称 | `id`、`Host`、`records`、`_` |

## 4. 整数

```text
int-literal := digit { digit | "_" }
```

- 十进制数字序列，语义类型为有符号 32 位整数。
- `_` 只能出现在数字之间，不能位于首尾或连续出现。
- 符号 `-` 是一元运算符，不属于字面量。
- `-2147483648` 由一元负号作用于越界字面量并折叠为 `i32::MIN`；单独的 `2147483648` 越界。

```cfd
count: 0,
limit: 100,
```

## 5. 浮点数

```text
float-literal := digit { digit }
                 ( "." digit { digit } [ exponent ]
                 | exponent )
               | "inf"
exponent      := ( "e" | "E" ) [ "+" | "-" ] digit { digit }
```

- 小数形式 `12.5`；`.` 后必须至少有一位数字。
- 指数形式 `12e-3`、`12E+3`；`e`/`E` 后必须至少有一位数字。
- `inf` 是正无穷字面量，`-inf` 由一元负号得到。
- 语义类型为 IEEE 754 binary32。超出 binary32 范围的字面量得到 `inf`。
- 浮点字面量不支持下划线分隔。

```cfd
ratio: 0.25,
scaled: 1.5e3,
```

## 6. 布尔

```text
bool-literal := "true" | "false"
```

```cfd
enabled: true,
disabled: false,
```

## 7. 字符串

```text
string-literal := '"' { string-char | escape } '"'
escape         := "\" ( '"' | "\" | "n" | "r" | "t" | "u{" hex-digit { hex-digit } "}" )
```

- 字符串使用双引号，支持转义 `\"`、`\\`、`\n`、`\r`、`\t` 和 Unicode 转义 `\u{HEX}`（1 到 6 位十六进制，值不超过 `U+10FFFF`，`hex-digit` 见 §2）。
- 字符串不能跨行。

```cfd
name: "line 1\nline 2",
path: "C:\\games",
```

## 8. 格式化字符串

普通字符串中出现插值花括号时按格式化字符串处理，不存在独立前缀：

```text
formatted-string := '"' { string-char | escape | "{{" | "}}" | "{" field-path "}" } '"'
field-path       := [ qualified-name "::" ] [ record-key "." ] identifier { "." identifier }
```

- `{field-path}` 表示插值，插值目标是记录字段路径。
- `{{` 与 `}}` 分别表示字面量 `{` 与 `}`。
- 不允许未配对的 `}` 或未闭合的插值。

```cfd
label: "{name} x {count}",
remote: "{&sword.name}",
typed: "{&Item::sword.name}",
literal: "{{not interpolation}}",
```

## 9. 注释

```text
comment := "#" { any-char-except-newline }
```

注释从 `#` 延续到行尾，内容不参与语义。

```cft
const MAX_LEVEL: int = 100;  # 等级上限
```

## 10. 标点与运算符

标点按最长匹配扫描，不得拆分：

```text
..=  ->  =>  ::  //  **  <<  >>  <=  >=  ==  !=  &&  ||  ??  +=  -=  *=  /=  %=  //=  **=  <<=  >>=  &=  |=  ^=  ..  ?  @
( ) { } [ ] , : ; . + - * / % ~ ! & | ^ < > = $
```

- `::` 用于命名空间路径、enum 静态成员和带类型的记录引用。
- 字段访问使用 `.`。
- `?` 用于可选类型后缀和可选值传播。
- `??` 是空值合并运算符。
- `//` 是整数除法运算符，不是注释。
- `@` 引入注解。
- `$` 引入编译期元数据标识符。
- 字段访问和方法调用中，`.` 后的成员名可以是保留字（例如 `.for(...)`、`.int()`）。

## 11. 源码位置

- 语言层为每个 token、trivia、声明、字段和表达式保留源码范围。
- 诊断和 fault 绑定最小可定位的源码范围。
