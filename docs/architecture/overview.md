# 系统架构与当前实现

Coflow 使用 CFT 定义结构与业务规则，使用 CFD 保存记录和维度覆盖。CLI、编辑器与 LSP 共享项目运行时；C# 应用通过生成类型和 Coflow.Loader 读取调用方选择的 CFD 文件。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `coflow-language` | 源码跨度、无损词法扫描、CFT 解析与 schema 编译、schema-free CFD 解析、结构限制 |
| `coflow-model` | schema 引导的数据构建、默认值、字段校验、记录身份、引用、维度与模板 |
| `coflow-checker` | 对已编译规则和不可变模型求值，管理执行工作量、迭代预算和检查诊断 |
| `coflow-runtime` | 项目配置、路径与输入发现、schema 编译、固定 CFD 读写、会话、查询、修改、规则规划、索引与产物发布 |
| `coflow-staging` | CFD 写入和生成代码发布共用的文件暂存、提交与失败恢复 |
| `coflow-format` | 基于无损词法流进行 CFT/CFD 规范格式化 |
| `coflow-diagnostics` | 模型构建与规则执行共用的诊断码、阶段与严重性 |
| `coflow-codegen` | 数据类型生成契约；具体生成器只依赖该契约 |
| `coflow-codegen-csharp` | C# 业务类型、描述符、默认值和构造入口生成 |
| `coflow-lsp` | 独立及编辑器内嵌语言服务，处理诊断、补全、导航、语义标记与格式编辑 |
| 根 `coflow` 包 | 二进制 CLI、命令解析和宿主输出 |
| `editors/cfd-editor/core` | 宿主无关会话、编辑器 DTO、视图、写入桥接、监听与事件 |
| `editors/cfd-editor/src-tauri` | 桌面命令与事件适配、窗口、对话框、更新器和插件存储 |
| `editors/cfd-editor/frontend` | 接受后端代次、编辑交互、撤销重做、表格和图谱布局 |

运行时内部固定实现 CFD 读取与写入，宿主通过运行时取得目录和能力。非 CLI 宿主依赖共享 crate；生成器将内存中的文件集合交给运行时发布。

## 项目流水线

1. 读取 `coflow.yaml`，解析 schema、data、维度目录和生成目标路径。
2. 编译全部 CFT 为项目全局 schema，保留声明来源及规则依赖信息。
3. 加载所选 CFD，建立记录身份，补默认值、连接引用并处理覆盖与模板。
4. 按调用方要求执行 CFT 业务规则，汇总数据与规则诊断。
5. 修改在候选项目上验证，通过后检查外部变化并事务写入；生成目标全部准备完成后统一发布。

| CLI 入口 | 校验与生成范围 |
| --- | --- |
| `schema check` | CFT 解析与声明编译 |
| `check` | schema、CFD、默认值、引用和维度 |
| `check --rules` | 数据检查及全部业务规则 |
| `check --rule <id>` | 数据检查及指定业务规则 |
| `codegen` | 数据有效后生成并发布代码 |
| `build` | 数据及全部业务规则通过后生成并发布代码 |

编辑器通过同一运行时规划检查任务，针对变更影响更新诊断。C# 加载器验证数据并构造业务对象，CFT check 的执行由 CLI 和编辑器承担。

## 数据与来源

`table` 与 `singleton` 拥有记录身份，`data` 是内联值。模型索引、业务记录 ID、源码跨度和文件路径分别表示模型定位、业务身份与来源。引用连接身份，允许跨文件与成环；模板按字段依赖求值，模板依赖循环生成诊断。

维度字段同时保存基础值、显式覆盖与覆盖来源，变体从已选择的 CFD 覆盖块发现。维度目录自动参与输入发现。局部写入保留字段来源，读取有效值与查询显式覆盖是两个不同操作。

严格加载和发布要求完整有效的数据；编辑会话能够保留可修复的缺字段或引用诊断。具体保留与拒绝边界见 [容错数据加载](../editor-design/tolerant-loading.md)。

## 宿主与并发

项目会话以不可变代次组织配置、schema、模型、诊断与索引。编辑器前端仅接受匹配会话且更新的后端代次，撤销重做在对应变更提交后推进历史。源码保存和结构化写入使用各自的基线检测外部修改。

CFT 源码需通过声明检查后写盘，错误声明保留在编辑草稿；CFD 源码允许带诊断保存。代码生成与数据写入通过暂存事务保留失败恢复信息。

接口与协作约束见 [项目代次](project-generations.md)、[CLI 设计](../runtime-design/cli.md)、[C# 加载](../language-design/02-api-runtime-design.zh-CN.md) 和 [编辑器视图](../editor-design/views.md)。
