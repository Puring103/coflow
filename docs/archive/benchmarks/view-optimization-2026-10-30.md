# 2026-10-30 视图优化验证

图视图的完整逻辑行与端口继续保存在几何索引中，绘制框架只接收行窗口、可见连线和活动拖线需要的端口。连续平移缩放的三轮帧 P95 为 53.2 / 26.7 / 26.7ms，基线为 80.0 / 53.2 / 40.1ms。1000 次节点快照更新的 P95 为 40.8ms。首屏、稳态帧 P95 和全程无长任务目标仍未全部达到。

## 环境与口径

- 基线提交：`3742bf1e9dc8d3a22a263f1db48be32412b1b3a4`；当前为该提交之上的工作区修改，各次原始 JSON 保存实现文件 SHA-256。
- Windows、Intel Core i5-13600KF、20 个逻辑处理器、约 32GiB 内存；Node.js 22.23.4；无头 Microsoft Edge / Chromium 156.0.4314.50。
- Vite 生产构建，1440×900、DPR=1；标准场景为一万项可编辑引用，实际绘制连线不超过 300。图、引擎和 C# 测量串行执行；未启动或重启桌面 CFD 编辑器。
- 首屏计时从准备好的 GraphData 开始，结束于完整高度测量和夹具初始化定位周围的四次 RAF；不包含后端、传输和 ELK 冷布局。两版本使用相同夹具与稳定判据。
- 正式标准采样各有 30 次首屏、3×30 秒连续平移缩放。当前另含 1000 次更新、8 种容量场景各一次，以及 20 次视图卸载/重建。容量单样本只报告观察值。
- 基线通过 Vite 构建时替换 `GraphView.tsx`、`GraphNode.tsx`、`GraphView.state.ts` 三个已提交源文件获得；其余依赖、行几何模型和夹具相同，工作区文件保持原位。
- 中位数取中间两项平均，P95/P99 使用 nearest rank；首屏不足 100 样本时不报告 P99。浏览器帧等待不代表纯 CPU 时间。

## 瓶颈与实现结果

独立 CPU 采样中，React Flow 的边端点选择、`getEdgePosition` 和 `getHandle` 相关函数合计约占采样时间的 57%；框架按边反复线性扫描一万项端口数组。行高模型的树状数组维持 O(log R) 坐标查找和单行修改，本轮保留该结构。

端口窗口保留穿屏连线的屏外真实起点，并按路径集合和几何版本复用。完整折线坐标按节点位置、几何身份和版本缓存；端口窗口变化复用折线。行高读取复用 ResizeObserver 的 CSS 边框盒高度。几何版本未变且框架实际端口、外框与测量尺寸一致时跳过回写；DOM 尺寸观察丢失屏外端口时重新发布。

异步测量发布检查当前节点的数据身份；框架 replace 事件只合并当前代次的几何字段，保留最新业务数据与拖动位置。该规则修复外部数组删除后旧测量覆盖新快照、旧草稿无法结束的竞态。

维度记录列表按行身份建立展示位置索引，完整列表渲染的定位工作由 O(N²) 降为 O(N)。筛选摘要按快照中的行身份缓存，选中记录按键索引定位。该部分通过功能回归和代码复杂度检查，本报告不提供未经测量的时延倍数。

## 首屏与运行期差异

| 首屏协议 | 基线 P50 / P95（ms） | 当前 P50 / P95（ms） |
| --- | --- | --- |
| 各版本独立整组 30 次 | 558.65 / 628.0 | 847.95 / 897.5 |
| 同一浏览器交替版本，各 20 次 | 555.35 / 617.4 | 561.2 / 734.2 |

成对协议每对交替先运行的版本，各版本使用独立生产预览服务器。20 对中，当前减基线的差值中位数为 5.3ms、P95 为 34.3ms，最大为 134.9ms；最后一对两版本同时变慢至约 888 / 893ms。整组与交替协议存在运行期差异，来源尚未确定。当前没有建立稳定的首屏提速结论，整组首屏回退观察值完整保留。首屏 P95≤200ms及相对改善至少 50% 的目标未达到。

独立诊断构建保留原稳定判据，计数真实几何回写和稳定 effect 的启动/取消。首屏约有 3 次回写、7 次稳定 effect 和 4 次取消；几何版本通知仍保留。相同 5 秒稳态诊断中的重复几何回写从 5 次降至 0 次。这些计数确认消除了重复写入，但不足以解释全部首屏运行期差异。带诊断注入的计时不纳入正式验收。

一千至一万项标准引用的挂载行数不增长，满足 ≤200 行及增长 ≤10% 的目标。密集场景超出标准可见边预算，单独保留其成本。十万项的完整关系和几何构建仍有明显首屏成本。

一万项标量、对象、字典和只读字符串集合展开后，分别挂载 35 / 12 / 35 / 38 行，完整高度为 270399 / 960400 / 270415 / 250372 个逻辑像素。这四个场景的首屏计时对应集合折叠状态；展开后只统计挂载和几何，没有独立记录展开延迟。

1000 次更新前/后强制 GC 的 JS 堆分别约 32.0 / 41.1MB，卸载图后为 23.3MB。100 项图在预热后 20 次卸载/重建的三次 JS 堆检查点为 10.91 / 11.52 / 11.65MB。此处为有限检查点，原生和浏览器分配另计。

$env:PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH='C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe'

node tests/browser/graph-acceptance.mjs
