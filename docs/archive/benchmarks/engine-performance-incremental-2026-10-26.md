## 十万条端到端测量

夹具包含 100,000 条记录、100 个文件、每条 20 个字段，源码共 54,267,780 字节；修改 `name` 字段。下表为同参数串行对照，更新各取 3 次中位数。基线为保存的预算修复版本，包含本轮及此前复制优化的累计差异，不代表仅本轮收益。

| 操作 | 基线 ms | 当前 ms |
| --- | ---: | ---: |
| 单条更新 | 98.408 | 88.124 |
| 同文件 1,000 次更新 | 429.256 | 176.381 |
| 跨 100 文件 1,000 次更新 | 7,382.778 | 6,959.401 |
| 单字段候选验证 | 100.147 | 89.452 |
| 完整数据加载（各单样本） | 11,040.164 | 11,306.489 |

另一轮当前版本测量中，加载 3 次中位数为 8,358.711 ms；单条、同文件批次、跨文件批次各 5 次中位数为 86.907、181.500、7,133.943 ms。样本存在明显波动；完整加载没有显示收益，单次对照不足以判定稳定回退。当前仍未达到完整加载 5 秒、单条更新 50 ms、跨文件批次 3 秒目标，样本数不足以报告稳定 P95。

单条更新验证和物化 1 条记录、复用 99,999 条、重建 2 条引用边、执行 4 个检查根。批次验证 1,000 条、复用 99,000 条、执行 4,000 个检查根。实际修改仍收集 100,000 条草稿引用，并解析命中的完整文件。两轮及基线均通过独立完整重载的全部值与诊断对照。

## 与上一轮的底层对照

使用保存的上一轮二进制串行对照：8,000 条记录的环形引用模型更新中位数由 1.720 降至 1.448 ms，集中引用由 2.034 降至 1.166 ms；十万元素数组的 1,000 次修改由 64.859 降至 56.818 ms。十万条检查环形拓扑为 214.214 → 213.638 ms，集中拓扑为 1,181.126 → 1,081.337 ms，后者波动较大；8,000 条检查拓扑未显示改善。完整原始样本保留，不将局部收益推广为所有场景收益。

## 正确性与增量边界

`cargo check --workspace`、`cargo test --workspace` 均通过，共 729 项测试通过。回归覆盖分页快照隔离、集合缓存身份与失效、递归及多态遍历、借用维度草稿、有限检查预算和发布后外部写入识别。相同内容刷新测试确认零解析、零草稿收集、零模型验证、零检查根执行，并保留原有诊断。

分页共享、schema 遍历计划及成员缓存减少复制和重复计算。实际变化文件仍整份解析，成员与顺序变化继续完整构建，模板依赖仍是记录粒度，身份和来源仍有全量扫描。后续优化重点为变化文件解析与来源更新、结构变化局部维护，以及首次加载的分配和遍历成本；这些不计入已完成成果。
