# C# 稀疏视图测量（2026-11-05）

## 范围

本测量比较完整物化视图和共享数据上的轻量视图。夹具有 500 条记录、每条 128 个 int 字段和 12 个 language 变体；每个变体只覆盖 r0.f0。两版使用相同 CFD 输入，依次选择全部 6,000 个记录视图。计时后读取校验合计值，确保覆盖与基础回退正确。

基线来自提交 `70323a4cad6f29a105e95705cdecd74380c54c73`。基线业务适配器使用填充回调建立 int 数组，新版适配器使用只读 Reader 按序号访问；这是人工宽表夹具，不是实际生成的 128 个属性的业务类。两个适配器均包含在[对照程序](csharp-sparse-2026-11-05-probe.cs)中。

## 环境和方法

Windows、.NET 8、Release，禁用分层编译（DOTNET_TieredCompilation=0）。每版先预热 2 次，再串行采集 7 个样本，先完成基线再运行新版；完整运行时信息与源码 SHA-256 见[元数据](csharp-sparse-2026-11-05-metadata.json)。采样期间没有并行启动仓库构建或测试，未隔离其他桌面进程。

- 加载：已有源文本及描述符到公共加载结果，分配量为当前线程累计分配。
- 视图：为每条记录选择 12 个变体；基线填充字段，新版只建立轻量视图。
- 存活内存：创建全部视图后强制 GC，与本样本加载前强制 GC 的总托管内存作差。源文本和描述符在计量前已存在；此指标不是峰值内存或进程工作集。
- 读取：500 个已选择视图各读 f0 共 2,000 次，总计 100 万次。计时包括循环和整数求和；不代表任意属性、模板或 Unity/IL2CPP 性能。

## 结果

下表为中位数，括号内为最小至最大样本。MB 使用十进制。

| 指标 | 完整物化视图 | 稀疏视图 |
| --- | ---: | ---: |
| 加载 ms | 64.377（56.854–68.168） | 24.924（20.473–30.832） |
| 加载累计分配 MB | 44.685（44.685–44.685） | 24.858（24.858–24.858） |
| 创建全部视图 ms | 58.363（56.601–75.045） | 15.368（9.837–23.529） |
| 全部视图后的存活内存 MB | 44.041（44.040–44.041） | 8.155（8.155–8.155） |
| 100 万次标量读取 ms | 0.839（0.833–0.905） | 14.193（11.308–20.260） |

此夹具体现了减少视图物化与存储的收益，以及逐次属性选择的成本。新版 view 阶段不包含全部属性求值，不能将阶段耗时直接解释为完成同样求值工作的加速倍数。读取场景只覆盖一个 int 字段；需在实际应用中复测热点路径。

原始证据：[基线样本](csharp-sparse-2026-11-05-baseline.ndjson)、[稀疏样本](csharp-sparse-2026-11-05-sparse.ndjson)。

## 复现

将对照程序作为独立 net8.0 控制台项目的 Program.cs，启用 ImplicitUsings 和 Nullable。基线项目引用上述提交中的 Coflow.Loader.csproj，并定义 LEGACY；新版项目引用当前 Coflow.Loader.csproj，不定义 LEGACY。设置 DOTNET_TieredCompilation=0，分别用 dotnet run --configuration Release 串行执行。程序固定记录数、字段数、变体数、预热数与采样数，输出每个正式样本的 JSON。
