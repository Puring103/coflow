# 复杂表格优化验收

日期：2026-10-26。工作区在 `f310934c` 基础上测量，CPU i5-13600KF，内存 32GB，Chromium 156.0.8078.4。全程使用无头浏览器和后端示例，不启动或中断桌面编辑器。

## 滚动

生产构建，3,000 行、20 列，表格 880×480，页面 1280×800。每场景两轮，第二轮倒序；每个方向最多 90 帧或 8 秒，前 4 个间隔剔除。计时与 CPU profile 分开。原始脚本和采样均保留。

同一初始视口的纵向滚动 P95：

| 场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 标量表 | 约 17ms | 16.7–16.8ms |
| 2 列数组，每格 8 项 | 约 50ms | 16.7ms |
| 12 列数组，每格 8 项 | 283–583ms | 16.7–16.8ms |
| 2 列数组，每格 32 项 | 约 317ms | 16.7ms |
| 12 列对象，每格 8 字段 | 约 100ms | 16.7ms |

复杂列位于表格右侧。初始视口内主要是标量；优化后屏外复杂列使用几何占位，纵向采样结束时实际挂载复杂单元格为 0。该表同时体现消除屏外挂载的收益，不能用于声称复杂内容可见时全部稳定 60 帧。

新增先横移到复杂列末端的纵向采样：

| 复杂内容可见场景 | 两轮 P50 | 两轮 P95 | 纵向结束时 DOM 元素 |
| --- | ---: | ---: | ---: |
| 12 列数组，每格 8 项 | 16.7ms | 33.3–33.4ms | 16,188 |
| 2 列数组，每格 32 项 | 16.7ms | 16.7–50ms | 8,215–8,503 |
| 12 列对象，每格 8 字段 | 16.7ms | 33.4ms | 8,915 |

长数组有一轮尾帧达到 50ms；报告保留这次波动。横向 P95 多数为 16.7–16.8ms，长数组可见场景的一轮为 33.3ms。密集复杂内容仍有长帧，不能据此承诺任意数据和插件都稳定 60 帧。

优化包含摘要批量读写、精确计数宽度共享、逻辑缩放单位、按高度限制预览、复杂列横向窗口、单元格 memo 和共享尺寸观察器。展开路径由文件视图持有，活动编辑内容保留挂载；屏外内置字段树保留预览几何及自动行高所需的完整高度。

## 快照

`perf_smoke` release 示例生成一个文件、3,000 条 Entity 和 300 条 Item，实际 3,300 行、22 列。普通快照和共享描述快照来自同一数据。

| 指标 | 普通注解快照 | 共享描述快照 |
| --- | ---: | ---: |
| JSON 字节数 | 27,560,483 | 13,596,270 |
| 快照冷构建 | 136.42ms | 61.49ms |
| 快照热构建 | 131.85ms | 60.18ms |
| JSON 序列化 | 37.43ms | 20.72ms |
| 描述索引整理 | — | 1.03ms |
| Chromium 解析、整数转换和恢复，5 轮 | 105.4–124.0ms | 62.4–69.2ms |

共享表有 23 个描述，恢复后 19 个顶层注解对象被所有记录字段复用；JSON 体积下降约 50.7%。浏览器逐项处理同一输入、交替次序测量；计时不包括工具传入字符串、IPC 传输、首屏挂载或浏览器 GC 总停顿，因此不能直接解释为完整文件打开延迟。

真实快照经 JSON 解析、i64 归一化和共享描述恢复后，内容往返一致。记录坐标、字段值、容器位置、摘要和诊断均保留。此基准比较完整文件快照；单条写入继续返回变化行，未变行沿用前端对象身份。

## 正确性边界

单元测试覆盖共享描述的拓扑顺序、子树复用、不同实例的枚举整数、i64 极值、接收值不可变性和未变分支身份。浏览器回归覆盖缩放与列宽、隐藏预加载、前缀扩展与回收、10,000 项下拉的搜索和键盘循环、复杂列窗口、展开恢复、选中后完整编辑、行高与屏外自动适应，以及已有光标、草稿、诊断、粘贴、剪切和导航路径。

工程必需检查使用根目录 `cargo check --workspace` 和 `cargo test --workspace`。前端单元测试、生产构建、类型绑定导出及无头交互回归用于本次改动验证。
