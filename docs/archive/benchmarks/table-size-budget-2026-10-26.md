# 表格尺寸预算优化验收

日期：2026-10-26。环境和夹具沿用[复杂表优化验收](complex-table-optimized-2026-10-26.md)。

预览现在按所有已展开层级共享的可见行预算停止遍历；折叠子树和预算以外的数组、字典尾部不读取。对象字段首次投影仍包含声明顺序和额外成员排序。省略尾部保留一个溢出标记，选中后恢复完整内容，由浏览器自动扩展单元格表面，整行高度不变。

屏外高度估算达到预览上限后停止。完整展开高度仅在双击适配行高时计算。列窗口分段由所有记录共享，连续屏外区间的宽度通过列宽前缀作差取得；ID 自动列宽达到上限后停止记录扫描。

## 验证

- `cargo check --workspace`、`cargo test --workspace` 通过。
- 363 项前端单元测试、40 项无头浏览器回归和生产构建通过。
- 预算边界使用会抛错的尾部元素与折叠子树，验证预算耗尽后不再读取；完整适配统计另行验证。
- 浏览器验证尾部第 21 项展开后取消选中时回收内容，重新选中后恢复展开状态，横向卸载不改变行高，屏外列仍参与主动适配。

## 滚动复测

生产构建，3,000 行、20 列，每场景两轮。串行运行测量，不与 Rust 检查或浏览器回归同时运行。每方向最多 90 帧或 8 秒，剔除前 4 个间隔。

| 场景 | 纵向 P95 | 横向 P95 |
| --- | ---: | ---: |
| 12 列数组，每格 8 项，复杂内容可见 | 33.3ms | 16.7ms |
| 2 列数组，每格 32 项，复杂内容可见 | 16.8ms | 16.7–16.8ms |
| 2 列嵌套数组，初始标量视口 | 16.8ms | 16.8ms |

常规滚动结果与上一轮处于同一量级。此次改进主要限定展开树和省略尾部的计算量，不能据此声称密集复杂内容已全部达到 60 帧。以上滚动夹具默认折叠，预算耗尽时的展开子树边界由单测和交互回归验证。
