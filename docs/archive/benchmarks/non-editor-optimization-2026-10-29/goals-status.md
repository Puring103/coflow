# G1—G13 实现与验收状态

本表绑定 [优化方案](../../../development/non-editor-performance-plan.md) 中的原始目标，区分已经交付的机制、测量支持的结论和仍需完成的工作。当前并非全部目标完成：G7、G11 仍有明确实现缺口，G12 尚缺 IL2CPP；其余目标也必须按各自夹具、阶段、指标和宿主范围判定。

数值证据来自 Rust / CLI R4 和 managed R6 的既有正式结果。汇总耗时为各独立进程中位数的算术中位数；观察 P95 只用于具备足够样本的操作。绝对预算、相对收益、工作量复杂度、内存和功能等价分别判定，某个端到端时延不能单独证明算法复杂度或完整目标达成。

| G6 模板错误级联消除按轮全量重建 | **机制已实现。**使用实际读取依赖传播剔除，保留原根顺序、预算与最终完整构建；累计工作包含失败轮、探测及最终构建。 | [R4 测量](final-r4/comparison.md) 两千条拒绝由 20,475.416 降至 63.758 ms；优化后一万/十万条分别为 346.078 / 3,794.199 ms，达到对应绝对预算。后两项没有成功基线配对，不能给出提速倍数。独立逐轮全量参照比较完整诊断、顺序及预算，见 [语义复核](verification/final-semantic-review.md)。 | 持续覆盖链、环、扇入、默认模板和节点截断组合；按候选访问、求值及边访问验证增长率。现有端到端数值支持已测收益，不代替完整规模矩阵的工作量证明。 |
| G7 CLI 输入、schema、来源共享及受影响集合 diff | **部分实现。**配置、路径、schema、操作语法树复用，按文件合并安全批次；差异使用类型化字段与稀疏维度表示，最终验证会话复用。 | 当前候选仍复制到临时目录，基线和候选分别建模；基础快照与完整键比较仍遍历全部记录/字段，上述缓存未统一为来源与数据代次。局部提速和缓存命中不能证明整笔事务仅处理受影响集合。 | [剩余方案](remaining-work-rust-cli.md) 的共享不可变输入、候选覆盖、统一来源所有权、字段/成员/上下文差异集合仍需实现；完整输入冲突检测、精确恢复回执及已发布事实必须保留。 |
| G8 描述符查找及每记录字段登记近似 O(F) | **机制已实现。**描述符索引和字段槽位消除逐字段线性查找，名称按加载范围共享。 | [R6 宽度矩阵](managed-r6/comparison.md) 的 .NET 一万条 8/100 字段加载分别为 120.940 / 653.915 ms，基线为 253.298 / 1,505.783 ms；Mono 也单独实测。功能用例覆盖默认值、复杂值、别名及错误顺序。 | 保留 F 单因素的比较次数、耗时及分配曲线；完整加载含解析、构造与其他索引，不能仅用这两点时延证明整个 Loader 为 O(N×F)，也不能据此通过其他宿主或内存预算。 |

| G10 缓存 For 与维度元数据零重复分配 | **机制已实现，.NET 已测路径满足，宿主验收不完整。**选择转换和不可变 Variants/HasVariant 元数据缓存复用。 | [R6 .NET 逐项结果](managed-r6/comparison.json) 中缓存 For、未知变体缓存回退、Variants、HasVariant 的三轮优化原始样本每项 300 个，全部 `AllocatedBytes=0`；缓存 For 每万次 2.163 →0.495 ms。Mono 对应逐操作分配为 `null`，保留内存零增量不能替代零分配。 | Mono 补实际 Player 分配分析，IL2CPP 独立执行。长期组合缓存、真实帧及争用保持单列，不能用本轮短测外推。 |
| G11 稀疏维度新增工作随覆盖与依赖闭包增长 | **部分实现。**共享不可变源、元数据和可证明上下文无关的结果；全部已声明单变体仍在 Load 返回前验证。 | 完整校验仍遍历已声明单变体与记录，尚未全部变为依赖局部工作。[R6 一万条、每维 1 个变体的稀疏加载](managed-r6/comparison.md) 使用两维共 2 个声明变体，.NET 896.898 →389.973 ms、Mono 1,286.138 →535.505 ms，分别降低 56.52% /58.36%，均未达到 60% 目标；.NET 首次全表视图 165.617 →29.646 ms。 | 分开基础必要遍历、覆盖登记、上下文求值和依赖校验；实现可信的局部验证计划并完整覆盖全部单变体，保持组合视图的延迟求值和诊断顺序。 |
| G12 .NET 与 Unity 目标后端分别达标 | **部分验证完成。**.NET 8 与实际 Unity 2022.3.62f3 Windows x64 Mono Player 已完成 R6 正式矩阵；IL2CPP 未实测。 | [R6 审计](verification/managed-r6-audit.json) 为 144/144 个进程、24 个场景、三轮配对；[功能收据](verification/csharp-r6-build-smoke.json) 为 .NET 86/86 及 Mono 主线程/默认新线程共 30 项契约通过。仍有 [七项托管目标未达](remaining-work-csharp.md)，Mono 分配指标缺失。已获授权的 IL2CPP 官方模块下载返回 HTTP 404。 | 解决组件获取后实际构建和运行 IL2CPP，独立验证 AOT、裁剪、线程深度及同夹具耗时/内存；解决已测未达目标。现有结果仅对应已记录的 Mono GC、裁剪和构建配置。 |
| G13 节点预算诊断共享行索引及有界恢复 | **机制已实现。**每来源共享行首索引；行定位使用索引，UTF-16 转换仅扫描目标行；预算耗尽后流式恢复，保留完整诊断与健康记录。 | [R4 两万条预算拒绝](final-r4/comparison.md) 21,805.927 →453.856 ms。逐偏移位置参照含 UTF-8 内部偏移、非 BMP、CRLF 与 EOF；结构边界、保留集合及恢复由专项用例验证，见 [语义复核](verification/final-semantic-review.md)。 | 按 S、D、行长独立记录索引、行内转换和恢复扫描工作量，继续验证 O(S) 索引/恢复、O(D log L) 行查找与 O(D) 输出；超长单行需计入实际行内 UTF-16 扫描，模板级联另按 G6 判定。单个 20k 时延不代替全边界复杂度验收。 |

功能保持以 [Rust / CLI 语义复核](verification/final-semantic-review.md) 和 [C# 语义验收](verification/csharp-semantic-review.md) 列明的参照与宿主为依据。Rust 顶层 811 项及 4 项隔离 worker 成功结果、C# 86 项和 Mono 30 项契约覆盖当前变更的关键边界；这些有限验证不构成所有输入和故障均无回退的证明，也不代替完整版本发布门禁。

后续实现工作分别见 [Rust / CLI 剩余方案](remaining-work-rust-cli.md) 与 [C# 内存及宿主验收](remaining-work-csharp.md)。数值目标保持原阈值，缺测保留为缺测，已有未达结果和原始样本继续保留。
