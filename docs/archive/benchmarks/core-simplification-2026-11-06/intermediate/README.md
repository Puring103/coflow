# 核心精简的中间版本测量

此组固定于第一次核心精简后的源代码快照，使用 HEAD `06a3ac49c73f291b50fa0f87422498e07d5df2bc` 对照。5 轮串行 AB/BA，每个进程 1 次预热和 3 个正式样本；每项每版共 15 个样本，所有功能断言通过。

[完整统计](summary.json)与[结果表](summary-table.md)保留该版本的收益和回退。`after.patch`、`after-source-overlay.zip`、`environment.json`、`artifacts.json` 固定源码、工具链及二进制摘要。原始命令里的输出路径记录采样当时的位置，本目录保存对应文件原名。
