# 最终源码的固定 P 核验证

采用与 [final](../final/README.md) 相同的固定 release 二进制，不重新编译。基线提交和最终 patch、工具链、二进制 SHA-256 见上级报告及 `../final/`。

[run-paired.py](run-paired.py) 用 `GetSystemCpuSetInformation` 读取拓扑，选逻辑 CPU 2（Group=0、CoreIndex=2、EfficiencyClass=1），只对 runner 自身调用 `SetProcessAffinityMask(0x4)`；子进程继承。十次启动均通过 `GetProcessAffinityMask` 检查实际子进程 mask=0x4。完整拓扑和 runner 变更前后 mask 见 [setup.json](setup.json)，逐次子进程 mask 见 `r*-*.meta.json`。

五轮串行 AB/BA，每个进程预热一次、测三次，每项每版十五个样本。十个进程全部退出成功，fixture 摘要相同，全部内容断言和独立完整重载复核通过。所有样本均保留，包括新会话加载的 422ms 慢样本。固定 CPU 不消除系统负载与磁盘延迟；结果按逐轮方向和全部范围解释，不推断显著性或 P95/P99。

[完整统计](summary.json)包含全部样本和逐轮变化；[原始指标表](summary-table.md)可通过 `python summarize.py` 复算。
