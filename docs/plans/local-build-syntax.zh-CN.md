# 局部构造语法

局部构造是表达式，正常结束时消费构造绑定并返回冻结后的不可变值。

本规格细化 [新 VM 实施计划](new-vm-and-csharp-snapshot.zh-CN.md)，冲突时以主计划为准。

```cft
build Type as binding { statements }
build (value) as binding { statements }
```

`Type` 接受已声明的 data 类型、数组类型 `[T]` 或字典类型 `{K: V}`。`value` 必须是这三类的普通不可变值。记录和 singleton 不能作为构造目标。

构造体是语句块，不使用尾表达式指定结果。`binding` 是当前作用域中的独占构造能力，不是普通值；它不能赋值给其他绑定、捕获、返回、传参或存入其他值。

| 操作 | 语法 | 行为 |
| --- | --- | --- |
| data 字段写入 | `b.field = value;` | 设置已声明字段 |
| 数组元素写入 | `b[index] = value;` | 替换已有元素，越界 fault |
| 字典写入 | `b[key] = value;` | 已有 key 保留位置，新 key 追加 |
| 数组追加 | `b.append(value);` | 追加到末尾 |
| 数组删除 | `b.remove(index);` | 删除已有元素，越界 fault |
| 字典删除 | `b.remove(key);` | 删除已有条目，缺失 key 不改变字典 |

构造体内允许读取已初始化且不携带未发布绑定的字段和已有集合元素，读取结果仍为不可变值；未发布绑定规则见下文。嵌套子值修改使用另一个构造表达式，再写回外层字段或元素。

所有到达正常出口的路径必须初始化必填字段。函数和模板可绑定新对象的 `self`，冻结前不能执行或向外暴露该绑定。`return`、`break`、`continue` 和 fault 穿过构造作用域时释放未发布的构造资源。

普通赋值规则继续适用：参数、捕获和 `self` 只读，只有 `var` 可重新赋值；构造能力不能通过赋值转移。构造字段、索引写入使用 `=`，复合赋值需展开为读取和写入。

`build`、`as` 在该表达式中作为语法关键字。字段与方法名称沿用成员标识符规则；`append`、`remove` 仅在构造集合的直接成员调用中表示构造操作。

## 初始化与路径分析

`build Type` 要求具体、可构造的 data 类型，抽象 data 不可直接创建。进入构造体前按声明规则物化默认值；无默认值的可选字段初始化为 None，无默认值的数组和字典字段初始化为空集合，其余必填字段保持未初始化。数组和字典构造目标从空集合开始。默认函数/模板在新对象上下文建立绑定，但不执行；默认值物化计入当前预算，失败清理全部候选资源。

`build (value)` 先在外层作用域对输入求值一次，再复制其实际类型的全部字段或集合元素；不重新应用默认值。静态类型决定可访问字段，实际子类型及不可见的子类型字段完整保留。函数/模板及不可变子值的复制保留身份和原绑定。输入内容始终不被修改。

赋值先按源码求值顺序完成右值，成功后才设置字段已初始化；`b.x = b.x + 1` 要求读取前 x 已初始化。控制流汇合取各可达前驱初始化字段的交集；可能零次执行的循环不能提供循环外的初始化保证。return/break/continue 离开构造作用域的路径只参与清理，不参与冻结点的必填检查。正常出口发布前仍由验证器检查完整性。

## self 的创建位置

| 写入形式 | 新函数/模板字面量的 self |
| --- | --- |
| data builder 的 `b.field = fn ...` 或 `b.field = f"..."` | 正在构造的 data 对象 |
| 上述字段右值中，经括号、可选值、数组/字典字面量及条件结果分支直接提供的字面量 | 同一 data 对象；条件和其他普通计算保持外层作用域 |
| 上述右值中的嵌套 data 字面量或 data build | 最近一层新建 data 对象 |
| 普通局部声明、函数调用实参，或独立数组/字典 builder 写入中的字面量 | 创建位置的外层 self |
| 已有函数/模板值、调用返回值或复制字段 | 保持已有身份与绑定，存储位置不触发重绑 |

创建位置上下文只沿表中的直接值构造形式传播，不进入被调用函数或普通计算。函数体建立 self 后，其内部普通局部闭包按通常捕获规则处理。访问外层 self 时先将其保存为普通局部变量；builder 绑定本身始终不能捕获。

写入的值若包含绑定当前未冻结对象的函数/模板，其字段标记为携带未发布绑定；通过集合或嵌套 data 保存也传播该标记。这些字段在冻结前禁止读取，因此不能间接调用、比较、传给 Host 或赋给外层变量。控制流合并采用“可能携带”的并集；可证明不含未发布绑定的完整覆盖赋值可清除标记。普通已初始化字段仍可读取。编译器和 IR 验证器共同保证该隔离，不将非法程序延后到运行时才拒绝。

冻结在必填字段完整后一次性发布对象及关联绑定；中途退出丢弃整个未发布构造图。已有函数绑定旧对象时可以在构造体内调用，因为旧对象已经发布；修改新对象字段不会改变旧函数的 self。

## 验收示例

以下示例假定具体 data `Sample` 声明 `x: int = 1`、`note: string?`、`read: fn() -> int`。

```cft
var original: Sample = build Sample as b {
  // x 已有默认值，note 已初始化为 None。
  b.read = fn() -> int { self.x };
};
var copied: Sample = build (original) as b {
  b.x = 2;
};
var rebound: Sample = build (original) as b {
  b.x = 3;
  b.read = fn() -> int { self.x };
};
```

`original.read()` 与 `copied.read()` 均为 1，二者的 read 为同一个函数值；`rebound.read()` 为 3，具有新的函数身份。若在 original 的构造体中写入 read 后调用 `b.read()`，或将 `b.read` 保存到外层变量，编译拒绝。

反例还须覆盖：只在单分支或可能零次循环中初始化必填字段、默认值物化失败、从父类型视图复制实际子类型、覆盖带未发布绑定的字段、未发布绑定嵌入集合后外泄，以及提前退出时对象/闭包环回收。
