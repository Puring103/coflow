# 新 VM 实现与验收状态

S0–S10 实现与验收完成，首版布局、编码、预算与 GC 参数已冻结。

目标与完整退出条件见 [新虚拟机与 C# 只读数据快照详细实施计划](new-vm-and-csharp-snapshot.zh-CN.md)。测试入口见 [V01–V20 证据索引](new-vm-validation-evidence.zh-CN.md)，当前测量见 [布局、执行与快照测量](new-vm-compact-storage-measurements.zh-CN.md)。

## 已实现的基础边界

- Contract v5 保存声明和类型化三地址 IR，包含虚拟值类型、捕获、控制流与源码位置。默认函数、模板和 check 在 Contract 创建时分析，未使用的错误函数也会失败。
- CFT/CFD 共用前端直接生成类型化 IR；虚拟值使用 ValueId，已移除先生成字节码再转换 IR 的中转实现。即时编译与 Contract 解码共用语义验证边界，引用和内建操作验证声明、参数及结果类型。
- 映像构建从 Contract IR 降低 CFT 程序；函数来源定位使用 module、owner 和位置，不依赖函数源码文本作为查找键。CFT 源码供工具使用。
- 解码后校验 IR 类型与结构，摘要不作为可信执行证明。
- RuntimeImage 私有持有固定数据、记录索引和程序区，多个实例可共享映像。实例独立持有 Host、动态堆、预算和创建线程身份。
- 执行器、执行绑定及 ValidatedProgram 为 crate 内部类型；外部通过 Runtime 调用。发布前重建活跃集合、检查结构并发布嵌套闭包程序。
- 静态可确定的函数目标链接为 FunctionId，直接访问映像程序表；发布前校验跨程序签名。调用参数整理为连续寄存器窗口，调用时直接复制窗口，Host 接收窗口切片。动态目标保留间接调用。
- 固定区保存共享 UTF-8、对象布局、连续字段/元素引用、字典、维度和函数/模板/Host 描述，持久通用复合 Value 已移除。TypeId、FieldNameId、LayoutId 区分布局元数据，语义 IR 的 FieldId 单独表示声明字段域；固定热读取通过借用视图访问，字符串 key 查询不复制 UTF-8。固定标量节点在发布前移除，发布入口拒绝未紧凑化的标量节点，字段、集合、维度、owner 和外部索引统一重定位；对象字段按共享类型布局压缩为连续载荷。
- 数组的 int/float/bool 使用连续 4/4/1 字节负载，元素读取直接产生标量身份，不分配逐元素节点；GC 不扫描这三种数值缓冲。从已有数组或字典构造直接借用负载，在累计预留预算后复制一次。可选 int/float/bool 使用 5/5/2 字节载荷，全 None 数组仅存长度，固定复合引用数组使用 4 字节索引。
- 寄存器槽为 8 字节，保留完整 i32/f32 位模式，引用使用 48 位编号；固定区发布和动态分配均验证编号上限。
- 动态堆的语言身份与存储槽分离。存储槽复用不复用语言身份，旧句柄失效，早期被保活的值不阻止临时槽复用。
- C ABI 实例及构建器保存在创建线程 TLS；全局注册表保存线程归属。异线程访问返回错误，终结释放排队交回创建线程，创建线程退出会清理剩余资源。
- 局部构造的拼写规格见 [局部构造语法](local-build-syntax.zh-CN.md)。

## 局部构造、优化与 C# 投影

- builder 已贯通语法、IR、解码证明和执行：data 必填字段路径检查、集合更新、追加和删除、自动冻结、提前退出清理、构造中 self 绑定隔离。map/filter 使用同一构造能力；旧 Append 指令已移除。
- IR 解码验证控制流收窄来源，重新签名的无守卫收窄仍被拒绝。控制流与读写集合由共享分析模块提供。
- Release 在寄存器分配前建立 SSA 版本和 phi，执行保守标量常量传播与基本块 CSE。checked 运算复用执行器语义；溢出保留运行时计算，浮点常量合并比较位模式。实际被读取的 phi 才传播逃逸用途。
- 映像调用图通过固定点传播组合 effect。循环、递归和未知调用保持保守；只有可证明无副作用、无 fault 且有限的未使用直接调用可以删除。
- 固定 owner 专化属于各自映像，并受代码量上限约束。固定字段与有效常量索引可折叠，Host 占位值不传播为静态事实。
- 有界直线函数内联、局部标量闭包消除、非逃逸数组标量替换、恒等 map 阶段消除和纯标量 map/filter 两阶段融合已接入 Release。捕获重写、闭包身份、模板读取、越界索引和未知用途保留原计算。
- 区间证明只将保证成功的标量不变量移出单入口循环；无法证明不溢出的算术保持原位置。尾调用只在返回链和 builder 清理条件已证明时复用帧。
- Format/Concat 计划合并静态片段、直接写入输出；全静态文本识别后缓存，直接读取不进入 VM 或分配动态文本。
- 维度独立保留显式覆盖存在性，显式 None 不回退。
- C ABI 逐节点编码批量投影，不保存整张通用值副本；C# 在发布前建立全部对象包装和类型化集合缓存；C# 普通字段、表、数组、字典和维度读取无需逐值 FFI，释放实例后普通数据仍可读。表与字典具有本地查询索引。
- C# 生成函数方法、一等函数入口及显式 Render，提供不可变 data/集合构造与类型化导入。原模板与静态文本均可作为 fstring 参数和返回值。
- 动态返回图通过内部 lease 保活；显式释放实例统一使执行能力失效。终结释放通过原生创建线程回收队列处理。托管 Runtime 强持有 Host、native 使用弱上下文，跨语言 Host 反向引用环可回收。
- 执行寄存器、帧、GC 工作栈、根、临时集合、Host 导出文本、格式化输出、正则缓存和实参窗口共享累计预算；小预算失败后立即释放预留。固定集合、对象和字符串的参数判型直接借用负载，不复制整份值。
- 外部聚合导入、字符串复制、连接和集合缓冲在分配前检查预算，并使用可失败的容量预留。递归导入和集合转换的临时向量共享累计预留，发布时转交内存占用。
- Host 直接读取、函数调用和同步重入共享深度/工作量预算；已有参数先保活再导入后续参数。安全点替换临时分配根，不能仅因寄存器根未变化就跳过发布。
- C# 9 生成静态字段解码器，普通热读取零 FFI、零托管分配；标量节点共享只读空元数据。Host getter 对一次回调结果完成可选值和类型转换。
- CFT/CFD builder 成员补全使用正式类型解析，区分 data 字段、数组 append/remove、字典 remove，并处理作用域和局部遮蔽。

## 优化适用范围与成本

| 优化 | 证明边界及回退 | 成本约束 |
| --- | --- | --- |
| 常量传播/CSE | checked 溢出保留原运算；浮点按位区分常量；Host 和未知调用保持保守 | CFG/SSA 分析在构建期执行，Debug 关闭可选优化 |
| 固定 owner 专化 | 多快照独立，Host 占位不折叠；未知动态参数继续执行通用路径 | 每映像额外指令预算 65,536 |
| 标量内联 | 有限直线标量函数，不内联递归、Host 和复杂控制流 | 每映像额外指令预算 65,536，寄存器不超过 65,536 |
| 闭包/数组消除 | 只处理使用已证明局部且身份不外泄的值；返回、捕获、模板或未知用途保留 | 超出分析界限停止优化，语义验证照常执行 |
| 循环外提 | 单入口循环、范围证明不溢出；不能提前执行可能 fault 的表达式 | 不能证明时保留原位置和派发 |
| 集合融合 | 恒等 map、纯标量且有限无计算 fault 的相邻 map/filter；Host、模板、checked fault 与短路不能任意重排 | 两阶段有界改写；不宣称消除所有 map/fold 中间集合 |
| 文本计划 | 静态片段合并；固定文本直接借用；动态片段写单一输出 | 未证明独占的循环字符串连接保留不可变复制成本 |
| 尾调用 | 返回链及 builder 清理条件均已证明 | 证明扫描最多 1,024 个节点；Debug 保留逻辑帧 |
| 映射压缩 | 连续相同源码位置区间编码，不改变精确位置 | 不能节省空间时保留稠密数组；诊断时二分查询 |

实际分配、派发与程序区域成本以测量报告为准。Debug/Release 对照包含整套优化的组合效果，不能归因到单一 pass；安全回退是首版证明边界，不是兼容旧执行器。

## 当前验证结果

2026-09-20，最新工作区 `cargo check --workspace` 与 `cargo test --workspace` 均通过：572 项测试通过，3 项独立测量探针按设计忽略。C# 19 项专项测试以及 Unity 2022.3.62f3 Mono/IL2CPP 独立播放器验证覆盖 Host 重入、闭包保活、跨线程纯读取、释放后数据和执行能力检查。原始性能、分配/GC、布局候选及快照测量随报告保存。

新增专项覆盖可选数值完整位模式、None/Host 混合字段共享布局、枚举描述共享但记录身份独立、IR FieldId 类型区分、正则累计缓存与失败释放，以及压缩源码位置逐 PC 往返。

新增回归覆盖契约 IR 篡改拒绝、原始源码不可解析时仍从 IR 执行、多线程共享映像与实例隔离、早期值保活时动态槽复用、过期句柄拒绝、C ABI 异线程访问、终结释放队列和创建线程退出清理。

直接调用回归覆盖递归和分支重新赋值的函数值；参数窗口回归覆盖换序、重复参数及循环跳转重定位。固定读取回归在持有动态堆写借用时执行字段、数组和字典读取。重新签名的非法引用及内建操作 IR 在解码时被拒绝。

固定种子的受限程序生成器对 32 组程序、11 个边界输入和 Debug/Release 两个 profile 使用独立 checked i32 oracle。新增覆盖固定字符串共享与记录环、浮点位模式、固定区越界引用拒绝、流式投影中重入 GC、空循环中的潜在溢出、C# 显式 None 维度覆盖，以及 Host 引用环回收。

## Unity 专项复现

`tests/unity-runtime-smoke/` 保存独立播放器场景的检查代码。`scripts/test-unity-runtime.ps1` 将当前 runtime、生成绑定和 Release 原生库复制到 `target` 内的隔离项目，构建并运行播放器，以退出码和成功标记共同判断结果。

```powershell
pwsh scripts/test-unity-runtime.ps1 -UnityEditor "<Unity 2022.3 安装目录>/Editor/Unity.exe" -Backend Mono
pwsh scripts/test-unity-runtime.ps1 -UnityEditor "<含 Windows IL2CPP 支持的 Unity 2022.3 安装目录>/Editor/Unity.exe" -Backend IL2CPP
```

测试不属于普通开发门禁；发布仍按 AGENTS.md 执行对应门禁。
