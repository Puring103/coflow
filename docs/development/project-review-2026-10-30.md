日期：2026-10-30。项目基线为 0.14.0、提交 `3742bf1e9dc8d3a22a263f1db48be32412b1b3a4`；验收版本为 0.15.0。Loader 的字段索引阶段与内部表示优化分别保留独立性能对照，使用各自报告中的同轮样本。验证使用 CLI、共享后端、C# 应用与无头浏览器，不启动或操作 CFD 桌面编辑器。

## C# 与编号性能

完整测量及原始数据见 [C# Loader 报告](../archive/benchmarks/csharp-loader-2026-10-30.md)。每组使用 500 条记录，5 次正式样本，计时使用与生成代码一致的字段数组。

| 完整加载场景 | 基线中位数 | 优化后中位数 | 时间减少 |
| --- | ---: | ---: | ---: |
| 32 字段，无变体 | 16.89 ms | 13.35 ms | 20.9% |
| 128 字段，3 个变体 | 693.58 ms | 112.46 ms | 83.8% |
| 512 字段，无变体 | 2297.30 ms | 517.81 ms | 77.5% |
| 512 字段，3 个变体 | 7715.56 ms | 965.04 ms | 87.5% |

512 字段、3 变体场景的线程分配量中位数由 799.48 MB 降至 406.99 MB。字段索引消除了逐字段线性扫描形成的二次工作；源节点共享减少了维度视图的重复分配。该结果不代表进程峰值内存或桌面整体提速。

`@idAsEnum` 的 10 万新编号回归执行 10 万次候选检查；整体生成仍包含模型遍历、有序映射和文本输出，未将候选扫描复杂度当作完整生成耗时。

## 0.15.0 Loader 内部表示与加载基准

完整数据见 [0.15.0 Loader 报告](../archive/benchmarks/csharp-loader-0.15.0.md)。基线 `7854472451e57ff8c4b805fef0cd525ba9c2e393` 已包含字段索引和共享输入优化；新旧两版使用同一基准程序与输入，各预热 2 次、正式采样 7 次。48 项结果全部通过输入哈希、操作数与业务结果核对，中位耗时和累计分配均下降，其中 3 项样本范围重叠，不能据此宣称稳定显著差异。

| 场景 | 优化前中位数 | 0.15.0 中位数 | 累计分配：优化前 → 0.15.0 |
| --- | ---: | ---: | ---: |
| 500 条、512 字段、3 变体完整加载 | 477.01 ms | 171.61 ms | 406.99 → 98.13 MB |
| 500 条、128 字段、12 个密集变体完整加载 | 1031.97 ms | 533.68 ms | 954.77 → 302.91 MB |
| 500 条现实夹具、3 个稀疏变体完整加载 | 16.47 ms | 5.54 ms | 17.17 → 7.88 MB |
| 已缓存维度视图访问 50,000 次 | 15.32 ms | 5.07 ms | 25.60 → 0 MB |

两版均使用共有的字符串字段读取 API，未将生成代码的字段序号读取额外收益计入。结果是 .NET 8 的时间与当前线程累计分配，不代表峰值或常驻内存，也不代表 Unity/IL2CPP 表现。全部已声明单维度仍在加载期校验；依赖增量校验、并行构造和业务视图淘汰不属于当前实现。

## 视图成本与性能边界

完整协议、CPU 采样与原始结果见 [视图优化报告](../archive/benchmarks/view-optimization-2026-10-30.md)。原有行高几何已采用树状数组；本轮主要消除 React Flow 逐边扫描全量端口的成本，缓存完整连线坐标与 DOM 测量，并减少重复状态发布。维度列表的逐行 `indexOf` 改为一次索引，消除列表渲染的二次查找。

同一生产夹具为 1 万条引用、1440×900 视口、不超过 300 条绘制边，连续平移缩放每轮 30 秒：

| 轮次 | 基线帧 P95 | 优化后帧 P95 | 超过 50ms 的长任务：基线 → 优化后 |
| --- | ---: | ---: | ---: |
| 1 | 80.0 ms | 53.2 ms | 124 → 24 |
| 2 | 53.2 ms | 26.7 ms | 49 → 0 |
| 3 | 40.1 ms | 26.7 ms | 27 → 0 |

1,000 次连续更新的 P95 为 40.8ms，逐次核对 React Flow 节点接收的数据，未丢更新。计时包含 React 与两次动画帧等待，排除后端提交；切换缩略模式时并不验证隐藏字段的 DOM 文字，显示行为由独立浏览器回归验证。

首屏 20 对交替采样中位数为基线 555.35ms、优化后 561.2ms，没有可证实的改善。整组 30 次优化后首屏 P95 为 897.5ms；交替采样尾部也出现两版同时变慢的样本，运行期漂移原因未确定，不能将整组差异直接解释为代码回退或提速。

图首屏 P95 ≤200ms、稳态帧 P95 ≤20ms 和零长任务的目标仍未全部达到。首次完整关系与几何投影、React 挂载和测量通知仍需进一步分析；本轮没有修改夹具、视口、可见边上限或静稳判据来宣称达标。Rust 十万记录热编辑未在本轮重新计时，历史结果不作为当前性能结论。

## 网站产物

[原始体积数据](../archive/benchmarks/website-bundle-2026-10-30.json)统计首页 HTML 的预加载模块与应用入口，按资源去重。动态导入、HTML、CSS 和图片不计入该指标。

| 指标 | 基线 | 优化后 |
| --- | ---: | ---: |
| 模块预加载数 | 45 | 4 |
| 初始 JavaScript 原始字节 | 2,379,409 | 217,614 |

体积变化来自移除当前网站未使用的 Mermaid 集成，以及将首页 CSS 从运行时脚本转为静态样式。没有使用产物体积推算网络延迟、FCP 或 CLS。

网站的专项命令为 `npm --prefix website run test:browser`，先执行生产构建再运行 4 项浏览器回归；需要 Playwright Chromium 或通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定可执行文件。该专项测试不改变 AGENTS.md 的常规门禁。
