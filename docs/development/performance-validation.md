# 性能验证与优化候选

## 当前契约

模型增量、维度与检查复用见[增量代次](../runtime-design/incremental-generations.md)。表格、图节点几何、活动编辑器与查询缓存见[编辑器性能约束](../editor-design/performance.md)，快照共享与失效规则见[表格投影与传输](../editor-design/table-projection.md)。

性能优化保持业务结果、诊断顺序与来源、旧快照独立性、执行预算、写入冲突检测和失败恢复。工作量减少与端到端延迟分别验收，功能通过和性能达标分别记录。

## 测量协议

记录 commit、构建模式、工具链、主机、夹具、样本量与基线程序摘要。引擎基准与浏览器基准串行运行，报告冷加载、首次查询、热编辑、批量修改、错误恢复、峰值内存与长尾延迟。十万条单文件与跨百文件、高扇入与稀疏引用、内存宿主与真实磁盘发布分别统计。

小样本报告中位数和范围；稳定 P95/P99 使用足够的独立样本。浏览器动画帧等待不解释为纯 CPU 时间，局部算法微基准不换算为桌面整体提速倍数。源码位置随文件文本变化真实移动，来源访问与业务值求值分别计数。

## 性能目标

以下为验收目标，实际状态以对应测量报告为准。

| 场景 | 目标 |
| --- | --- |
| 相同内容刷新 | 零解析、零模型求值、零检查执行 |
| 十万条、百文件、20 字段的健康单字段修改 | 端到端 P50 ≤50ms、P95 ≤100ms，P50 相对报告基线降低至少 25% |
| 固定变化文件，工程从一万增至十万条 | 身份与来源访问不随无关记录增长；模型增量阶段 P50 增长 ≤25%，目录复制单独统计 |
| 同文件一千项独立修改 | 一次候选构建和完整语法验证，既有夹具 P50 ≤150ms |
| 冷加载与失败恢复 | 冷加载时间和峰值内存相对对应基线稳定增幅 ≤5% |
| 万项简单引用图节点 | 标准视口挂载行 ≤200；一千至一万项时挂载行数增幅 ≤10% |
| 标准图稳态平移缩放 | 帧间隔 P95 ≤20ms、P99 ≤33ms，无超过 50ms 主线程长任务 |
| 保存布局的图首次呈现 | 首个可交互画面 P95 ≤200ms，相对对应基线改善至少 50% |
| 图单节点修改 | 输入至局部稳定显示 P95 ≤100ms，真实后端提交另计 |

图标准视口为 1440×900，实际可见连线不超过 300；密集连线和十万元素单列压力结果。相对目标绑定归档报告中的具体基线。目标未达时保留测量结论与成本，不修改口径宣称达标。

## 优化候选

以下方向保留为评估事项，实施前复测当前代码并确认瓶颈：

- 变化文件整份解析、候选文本生成和发布成本；成员变化的完整构建、页目录复制与名称字段布局。
- 模板维度上下文合并造成的保守失效、受影响记录完整重建和同值结果传播。
- 选区清理的重复查找、共享值比较、选中复杂字段的完整挂载与首轮全文文本投影。
- 注解缓存命中前的形状遍历、维度宽表列挂载和展开路径生命周期。
- LSP 文件发现与文本读取、锁内转换、引用候选缓存范围，以及跨代次完整值快照传输。
- 集合比较索引与语言依赖计划；任何变化均需验证相等语义、执行顺序和预算计费。

## 证据与工具

近期测量保存在[性能测量索引](../archive/README.md)，绑定当时的版本和夹具。核心验收见[增量与图测量](../archive/benchmarks/incremental-graph-acceptance-2026-10-26.md)，其中相对热编辑时延、图首屏和稳态帧间隔等目标存在未达项。

引擎使用 `crates/coflow-runtime/examples/engine_perf.rs`，编辑器后端使用 `editors/cfd-editor/core/examples/perf_smoke.rs`；浏览器使用 `frontend/tests/browser/performance.mjs` 与 `graph-acceptance.mjs`。原始结果复算使用 `scripts/summarize-incremental-graph.mjs`。测量输出写入独立文件，保留基线和采样协议。

开发和发布检查遵循 [AGENTS.md](../../AGENTS.md)。性能改动按影响范围补充增量等价、预算边界或无头浏览器验证。
