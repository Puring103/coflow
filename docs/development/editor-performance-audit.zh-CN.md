# 编辑器性能与功能复核

日期：2026-10-26。范围为复杂表优化涉及的预览窗口、展开状态、共享注解、引用与搜索缓存。

## 功能与结构

共享注解描述按子节点在前的顺序恢复。结构键保留枚举整数、Option 包装、对象实际类型、成员形状与字典键；业务字符串和普通数字不影响注解。编码期间保留 Arc，避免地址复用造成描述误合并。传输恢复保留记录、字段与源位置，整数归一化遵守不可变输入及 i64 精度约束。

对象字段、引用候选和全文搜索投影按不可变对象身份失效。WeakMap 不单独保留旧快照；引用 ID 查找为平均 O(1)，对象投影首次构造包含额外字段排序，后续相同值与注解直接复用。查询上下文内的 Rust 注解缓存不跨项目代际。

展开状态独立于窗口 DOM，活动编辑列保持挂载。普通预览和屏外高度推导受可见高度预算约束，省略尾部不计算完整高度。选中后恢复完整内容；双击适配行高时才遍历完整展开树。回归覆盖第 21 项展开后的取消选中、窗口卸载、选中恢复与自动行高。

验证范围内未发现其余功能回退；无头验证不代替桌面宿主、任意第三方插件或所有数据规模的验收。

## 后续优化候选

| 顺序 | 位置与当前成本 | 可评估的改进 | 验收要求 |
| --- | --- | --- | --- |
| 1 | `DataCard.tsx`：未选中预览已按所有展开层级共享预算；选中后恢复完整内容。既有复杂内容可见基准有约 8,200–16,200 个 DOM 元素，P95 为 17–50ms | 评估选中后超长内容表面的行窗口化 | 保留单元格自动扩展、编辑器身份、焦点、草稿、键盘路径、诊断、插件与自动行高；独立测选中场景 |
| 2 | `convert.rs`：每次字段转换均构造并哈希完整 `AnnotationShape`；命中缓存仍需 O(子树节点数) 遍历，字典还创建键文本 | 评估不可变模型节点的形状摘要复用，或 schema 描述与实例例外分离 | 枚举实例值、多态、缺失字段、嵌套 Option 与字典键必须保持一致；测大集合及深层树的构建、分配和内存 |
| 3 | `fieldValue.ts`：首次全文筛选为每条记录生成完整小写文本，时间与总文本长度线性相关；旧记录仍被视图或历史持有时投影也保留 | 对重复子值共享文本投影；查询规范化移到筛选入口；超大文件评估已有后端搜索边界 | 保持现有子串与字段边界语义，测首次查询、后续输入、单条修改和堆内存 |
| 4 | `tableExpansion.ts`：展开路径按文件视图保存，删除记录及结构变化后旧路径仍保留；屏外高度已改为有界推导 | 按记录代际清理无效路径；按值、注解与展开集合身份评估预算投影复用 | 排序、删除、同 ID 新建、类型切换与撤销重做行为保持可解释，内存随存活记录和展开路径增长 |

上述候选尚未实施。当前数据结构适合不可变代际和单行增量更新；下一轮重点是减少可见复杂树的实际挂载与重复遍历。共享注解减少传输，但完整刷新仍传输全部值；跨代际增量协议需要单独定义版本、原子应用和失效契约。

仓库根目录的 `cargo check --workspace`、`cargo test --workspace` 通过。前端 361 项单元测试、生产构建通过；表格无头回归检查编辑、选择、光标、草稿、维度、引用、多选、缩放、长下拉、预览窗口及行高。测量数据与适用边界见[优化验收](../archive/benchmarks/complex-table-optimized-2026-10-26.md)。
