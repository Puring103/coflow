# 实现验收

> 状态：架构设计
>
> 范围：已确定语言与架构规则的验收场景。

## 1. 验收方式

语言案例分别给出 CFT、CFD、调用输入及期望结果。编译失败、加载失败、普通返回值、
执行错误和检查报告分别断言。涉及错误时检查错误类别与必要源码位置。

共享核心案例直接使用内存输入。宿主集成案例使用同一组契约和 CFD，比较 Rust、
C# 及编辑器预览的语言结果。性能测量记录数据规模、程序数量、运行环境及执行限制。

本文件定义功能与性能验收内容。仓库开发和发布命令以根目录 AGENTS.md 为准，
当前交付能力及对应回归入口见[当前实现范围](./00-当前实现范围.md)。

## 2. 契约与加载

| 场景 | 期望结果 |
| --- | --- |
| 一份契约加载两组不同 CFD | 两个 Runtime 分别读取各自数据，契约保持只读 |
| 两个 Runtime 为同一默认函数提供不同 CFD 覆盖 | 调用分别使用各自最终实现，默认程序保持共享 |
| 默认值含记录引用 | 每个 Runtime 链接到自己的记录，不写回契约 |
| 普通字段省略、显式 None 和必填缺失 | 分别应用默认值、保留可选空值或返回加载诊断 |
| 将 data 声明为 CFD 顶层记录 | 返回类型用途诊断 |
| table 继承 table、data 继承 data、singleton 继承非 sealed table | 按各自类型类别检查，合法字段与父类规则正常继承 |
| table 继承 data、data 继承 table，或任何类型继承 singleton | 返回继承诊断 |
| 普通 singleton 提供非类型短名 key，或没有唯一记录 | 返回单例记录诊断 |
| 用 table 或单例名称构造内联对象 | 返回类型用途诊断 |
| 将记录传入 data 参数位置 | 返回类型诊断，不隐式转换对象内容 |
| 字段或参数声明为 table Item 类型并传入 `&Item::key` | 保留记录身份，允许通过该值访问 id |
| 字段或参数的类型写为 `&Item` | 返回类型语法诊断 |
| 两条记录相互引用 | 成功建立记录身份及循环引用，访问不复制整条记录 |
| 引用目标不存在 | 返回链接诊断，本次构建不产生成功 Runtime |
| 父子类型或兄弟类型的记录使用相同 key，分布在不同文件 | 返回重复 key 诊断 |
| 无共同父类型的独立类型使用相同 key | 允许，显式指定类型可分别定位 |
| 指定某个子类型引用同一继承树中兄弟类型的记录 | 兄弟类型不在该查询范围内，引用链接失败 |
| 父类型默认函数中的裸引用在子类型对象上执行，目标记录属于兄弟类型 | 按父类型的静态查询范围成功链接，不改用实际子类型范围 |
| CFD 函数签名或返回类型错误 | 返回编译诊断，契约及旧 Runtime 不变 |
| 契约版本不支持或输入截断 | 返回对应读取错误 |
| 仅加载契约的业务构建 | 可编译 CFD 函数并执行，无需 CFT 声明编译能力 |
| 声明 Host 服务但不提供绑定 | 构建成功，保留服务声明身份与成员签名 |
| 为 @Host 函数字段声明 CFT 默认实现或提供 CFD 服务记录 | 返回声明或数据来源诊断 |
| 同一服务对象用于两个 Runtime | 使用各自 Runtime 的服务与函数身份 |
| 创建新 Runtime 时变更 Host 绑定 | 新实例使用新绑定，旧实例保持原绑定状态 |

## 3. 值、函数与文本

| 场景 | 期望结果 |
| --- | --- |
| 将 item 的函数字段保存后调用 | self 仍绑定 item |
| var 局部变量省略类型声明，即使初始化为数字字面量 | 返回缺少类型声明诊断 |
| `for item in records(Item)` | item 直接获得 Item 类型，无需标注 |
| 遍历 `[int]` 使用 index、value 两个绑定 | index 和 value 均为 int |
| 遍历 `[fstring]` | 元素绑定为普通读取结果 string |
| 对 int? 使用 `is Some(number)` | number 是只读 int 绑定，无需标注 |
| 显式声明 float 局部变量，if 两分支分别为 int 与 float | 两分支按 float 检查，整数分支提升为 float |
| 显式声明 int 局部变量，if 的一个可到达分支为 float | 返回类型诊断，不自动改为 float |
| 复制同一个函数值 | 保留函数身份及绑定 |
| 连续两次读取同一函数字段 | 函数身份相等 |
| 同一闭包表达式执行两次，代码和捕获值相同 | 两个函数身份不相等 |
| is 检查稳定的只读字段路径后进入成功分支 | 保留对应收窄；根局部变量重新赋值后撤销 |
| 对函数调用结果做 is 检查后再次调用 | 第二次调用不继承前次结果的收窄 |
| Item 函数构造 Other，直接声明 Other 的函数字段和 fstring | 新字面量的 self 绑定 Other |
| Other 的数组、字典或可选字段中直接声明函数和 fstring | self 仍绑定 Other |
| Other 再包含一个内联对象，其字段直接声明函数或 fstring | self 绑定该内联对象 |
| 创建 Other 前将 Item 的 self 保存到 owner，并在新模板中使用 self 和 owner | 分别读取 Other 和原 Item；类型检查按各自类型进行 |
| 在 Item 函数体中创建局部闭包，然后存入 Other 的字段 | 保持原 Item 绑定 |
| 闭包捕获局部值，随后外层变量重新赋值 | 闭包使用创建时捕获的值 |
| 函数返回闭包，外层调用结束 | 宿主持有期间仍能调用闭包并读取捕获值 |
| 动态 fstring 字段读取两次 | 发生两次文本函数执行，可用执行器计数观测 |
| 将一次 fstring 读取保存为普通局部字符串，再读取局部变量 | 文本函数只执行一次 |
| 获取含 fstring 的集合，但不读取元素 | 不执行元素文本函数 |
| 将 fstring 字段赋给显式 fstring 局部变量，或传给 fstring 参数 | 保留模板及绑定，不执行模板 |
| 普通读取返回 fstring 的函数调用结果 | 普通函数执行后，再执行返回的模板 |
| 在 fstring 期望类型位置调用返回 fstring 的函数 | 普通函数执行，返回的模板保留且未求值 |
| 将已绑定模板存入另一个对象 | 保持原 self 及捕获环境 |
| 定义 fstring 常量并用另一 fstring 常量复用 | 保存同一模板定义，不转换为普通文本 |
| 将普通 string 赋给 fstring 位置 | 返回类型诊断 |
| 对含 fstring 的字典调用 values() | 返回原顺序的 `[fstring]`，不执行模板 |
| 对 `[fstring]` 调用 filter | 回调接收 string，每个判定元素读取一次；结果保存入选原模板 |
| 普通读取 filter 的入选元素 | 重新执行原模板，保持原绑定 |
| 对 `[fstring]` 调用 map，回调分别声明返回 string 和 fstring | 分别得到 `[string]` 与 `[fstring]`，保存结果时不额外执行返回模板 |
| 数组与字典分别执行 map、filter | 回调分别接收 value 与 key、value；map 返回有序数组，filter 保留原容器类型、入选原值及顺序 |
| 数组与字典执行 fold | 累计值为首个参数，按保存顺序累计 |
| 空集合执行 map、filter、fold、any、all | 分别返回对应空容器、初值、false、true，不调用回调 |
| any 已得到 true 或 all 已得到 false，后续模板或回调会报错 | 短路返回，不执行后续模板或回调 |
| 空数值数组执行 min、max、sum | 前两者执行错误，sum 为对应数值类型的 0 |
| float 数组含 NaN | min、max、sum 为 NaN，两种排序检查均为 false |
| 数字解析输入含首尾空格或尾随非数字内容 | 返回 None，不自动清理输入 |
| 输出 binary32 数值及负零，再按相同数值类型解析 | 最短文本还原原值，负零保留，插值与 string() 一致 |
| matches 使用合法子串模式或反向引用、环视 | 合法模式按 Rust regex 匹配子串；不支持的模式在编译时诊断 |
| 按索引读取一个 fstring 元素 | 执行该元素，返回普通 string |
| 读取 None 状态的 fstring? | 返回 None |
| 非空 fstring? 在执行中出错 | 返回执行错误 |
| 插值中途发生除零或越界 | 整次读取失败，不返回半截文本 |
| 两个动态模板循环读取 | 由调用深度或执行预算终止，返回执行错误 |
| CFT 默认字典和 CFD 字典均按 z、a 顺序声明 | 加载、遍历和 keys() 保持 z、a 顺序 |
| 两个普通字典键值相同，声明顺序不同 | 内容相等 |
| 两个 data 对象的引用字段指向同一记录 | 引用字段按身份比较，不递归展开记录 |
| 同一 data 对象包含动态 fstring，参与内容比较 | 仍按语言读取规则执行文本，不用对象地址相同跳过读取 |
| 两个记录参与相等比较 | 只比较 Runtime 和记录身份，不执行记录字段中的模板 |
| `"😀".len()` 与 `"😀"[0]` | 分别得到 1 和完整的 `"😀"` |
| `"e\u{301}".len()` 与索引 1 | 分别得到 2 和单个 U+0301 组成的 string |
| 比较 `"é"` 与 `"e\u{301}"` | 不相等，不自动进行 Unicode 规范化 |
| 比较 U+E000 与 U+10000 组成的两个字符串 | 前者小于后者，按 Unicode 码点数值排序 |
| 对单码点字符串使用索引 1 或负索引 | 返回无效索引执行错误 |

## 4. 维度与检查

| 场景 | 期望结果 |
| --- | --- |
| 业务记录具有维度字段，但没有覆盖 CFD | 仍建立生成记录，所有覆盖为 None，读取回退基础值 |
| 某变体有覆盖，另一变体未提供或为 None | 分别读取覆盖值和基础值 |
| 基础字段类型为 T? 且值为 None | 覆盖仍为 T?，回退结果为 None |
| 使用未知变体名称读取 | 按基础值回退 |
| 按 zh、en 定义维度，基础值 Sword，zh 覆盖为剑，en 无覆盖 | variants() 返回按 zh、en 顺序保存的 `{ "zh": "剑", "en": "Sword" }` |
| 对 fstring 维度调用 variants() 后反复读取结果字符串 | 调用时逐项计算，读取已保存文本不再执行原模板 |
| 两个变体均回退到同一动态基础 fstring | 每个变体分别执行基础模板，共执行两次 |
| 对 fstring? 维度调用 variants()，某变体回退到 None | 返回字典对应 value 为 None |
| 对 [fstring] 维度调用 variants() | 保存集合值，不递归执行元素模板 |
| variants() 中途某变体读取失败 | 整次调用返回执行错误，不返回部分字典 |
| 再次调用 variants() | 重新执行各变体的普通读取，不复用上次字典 |
| 基础类型声明维度字段，子类型记录继承字段 | 使用声明字段对应的生成类型，并关联实际业务记录 |
| 维度基础值及覆盖值直接声明函数或 fstring 并读取 self.code | 均读取原业务对象的 code |
| 维度字段集合中直接声明函数或 fstring | self 绑定原业务对象 |
| 维度覆盖值中的用户内联对象自身字段声明函数或 fstring | self 绑定该内联对象 |
| 维度变体从 None 回退到基础模板 | 执行基础模板，保持原业务对象绑定 |
| Runtime 构建成功后尚未请求 check | 数据可读取，普通函数可调用，未产生检查报告 |
| 在 data 中声明 check | 返回声明诊断 |
| 在记录 check 中访问 self.id | 取得当前记录 key 对应的 string |
| 检查目标记录具有 data、集合、记录引用及维度字段 | 不因字段结构自动增加检查目标或递归执行检查 |
| 检查请求选择多条记录 | 对所选记录执行规则，不递归检查各记录字段中的类型 |
| 记录 check 显式循环读取 data 字段或关联记录 | 只执行源码中表达的业务校验 |
| require 条件为 true，消息表达式会出错 | 消息立即求值并产生执行错误，本次 Host 调用不发生 |
| require 条件为 false，消息产生普通文本 | 两个参数依次求值后调用 Host，由绑定记录问题 |
| 将 require 保存到局部函数值或传给普通函数 | 使用普通函数签名及 Host 绑定调用 |
| 未绑定的 Host 函数保存在闭包中，但闭包未执行 | 不因保存函数目标产生未绑定错误 |
| 实际调用未绑定的 Host 函数或读取其宿主数据 | 返回未绑定执行错误 |
| 普通入口或逃逸闭包调用 require | 按其 Host 绑定执行，不产生专用调用权限错误 |
| require 条件为 false | 记录问题并继续当前 check 后续语句 |
| check 条件、消息或被调用函数发生执行错误 | 结束当前 check，报告真实错误，其他 check 继续 |
| 本次检查总预算耗尽 | 停止检查并报告未完成 |
| 检查失败后调用普通函数 | Runtime 仍可正常调用 |
| 连续请求两次相同检查 | 两次均实际执行所选 check |
| 父类型与子类型均声明 check | 对子类型执行时保留两者，并按父到子执行 |
| 通过 records(T) 查询 | 返回 `[T]`，包含 T 及子类型记录，不包含 data，按实际类型限定名和 key 排序 |
| 临时 data 对象在普通函数中构造 | 应用类型、默认值和引用规则，data 不提供 check |

## 5. 生命周期与执行清理

| 场景 | 期望结果 |
| --- | --- |
| 宿主持有返回对象、集合或闭包后触发回收 | 活跃返回值保持可访问 |
| 循环引用失去全部活跃根 | 动态图可被回收 |
| 动态槽回收后被新对象复用 | 旧句柄报失效，不访问新对象 |
| Runtime 释放后访问对象、集合或函数包装 | 返回失效错误 |
| Runtime 释放前复制普通标量和字符串到宿主 | 已复制结果继续可用 |
| Runtime 执行中另一线程调用，随后在空闲时换线程调用 | 前者立即报忙，后者正常执行 |
| 将记录或函数句柄传给另一个 Runtime | 报所属 Runtime 不符 |
| 一次调用发生除零、越界或预算耗尽，随后重新调用 | 本次栈、寄存器窗口及临时保活状态已经清理 |
| 调用深度或整条执行链寄存器内存达到限制 | 返回执行错误并清理退出的调用状态 |

Host 验收包含同步重入、外层活跃值保活、内层失败清理、异常映射，
以及同一调用链预算的连续累计，与 Host 声明和绑定共同纳入当前实现。

## 6. 编辑与宿主集成

| 场景 | 期望结果 |
| --- | --- |
| 输入未完成函数、缺字段或悬空引用 | 返回可用源码树与诊断，继续显示和编辑 |
| 修改单个字段 | 保留未涉及文本、注释和字典声明顺序 |
| 编辑 fstring 后保存并重新解析 | 保留原始模板，预览文本不进入源码 |
| 新源码构建失败，保留旧预览 | 旧 Runtime 继续可用，界面标明预览对应旧数据 |
| 新源码构建成功并切换预览 | 预览对应新 Runtime，旧实例由宿主管理释放 |
| 格式化同一源码两次 | 输出相同，非空白 token 和注释内容保持不变 |
| C# 读取普通字段、fstring 和调用函数 | 与 Rust 核心得到相同值或执行错误 |
| C# 包装复制及释放 | 与核心句柄保活和 Runtime 生命周期规则一致 |
| C# Runtime 主动 Dispose 或进入 SafeHandle 终结释放 | 统一释放原生实例，值包装不单独释放，已复制标量和字符串不受影响 |
| C# 读取 fstring 属性或显式取得模板句柄 | 前者产生 string，后者保留模板并能传入 fstring 参数 |
| Unity 2022 及以上版本的 IL2CPP 构建产物加载原生核心并读取数据、调用函数和 Host | 使用相同核心语义，AOT 环境下包装、回调和句柄释放正常，不依赖 Unity 之外的专属特性 |

## 7. 性能记录

加载测量包含契约体积、全部程序及附表体积、编译时间、加载时间和峰值内存。
执行测量覆盖字段访问、短循环、不同函数切换、闭包、文本和集合分配，记录耗时、
动态指令数、分配次数和分配量。C# 场景额外记录跨语言调用次数和数据复制成本。

持续分配测试分别覆盖宿主持有结果及主动释放结果两种使用方式。
失去活跃根的动态值经回收后不随调用次数持续积累；记录回收耗时、较慢请求和最长停顿。
编辑场景记录修改到成功预览的延迟及被丢弃构建的工作量。

字节码编码对比使用相同语义、相同数据和相同执行限制，计入扩展编码与全部附表开销。
测量结果用于确定编码参数、布局及性能目标。
