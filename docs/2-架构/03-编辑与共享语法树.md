# 编辑与共享语法树

> 状态：架构设计
>
> 范围：共享解析、CFD 修改、编辑预览和宿主交付。

## 1. 共用实现，分别持有实例

编辑器和业务程序共用契约加载、CFD 编译、数据访问、引用、函数、fstring、维度和 check 的实现。
各自按需要创建 Runtime，不要求共用同一个实例。

编辑器修改源码，构建新的只读 Runtime 用于预览。业务程序加载发布后的配置。
两者使用相同的语言语义；Host 可以绑定业务实现或明确的预览实现。
缺失 Host 绑定允许构建预览 Runtime，实际调用其函数或读取其宿主数据时才报错。

## 2. 一套解析器和源码树

CFD 解析由共享语言层负责，编辑器不另写解析器或 AST。
共享源码树保留 token、分隔符、空白、注释、声明顺序、原始文本和源码位置。
未完成或错误的内容也保留在树中，使编辑不依赖编译成功。

编译器可以从源码树生成便于类型检查和执行的内部表示，这些表示由同一次解析派生。
编辑器长期持有源码树；业务程序加载成功后可以释放源码树，只保留运行和错误定位所需的信息。

```text
CFD 源码 -> 共享解析器 -> 无损源码树
                          ├─ 分析结果 -> 定位、补全、生成局部修改
                          └─ 类型检查与编译 -> 只读 Runtime
```

## 3. CFD 编辑放在项目工具层

| 层 | 职责 |
| --- | --- |
| 共享语言与分析 | 解析、源码树、类型规则、诊断，以及字段与源码的对应关系 |
| 项目工具 | 新增和删除记录、修改字段、重命名及更新引用、生成局部源码修改、文件写回 |
| 编辑器 | 编辑会话、表格和表单、命令、撤销重做、文件监听、预览展示 |
| Runtime | 执行成功编译的数据和程序，提供读取、调用和可选检查 |

项目工具的修改能力供编辑器、CLI 和 LSP 复用。编辑器将用户操作转换为工具命令。
工具根据源码和类型生成修改，不通过修改 Runtime 再反向序列化整张表。

现有仓库中，共享语法由 `coflow-language` 承担，格式化由 `coflow-format` 承担，
项目修改和写回由 `coflow-project` 承担，原子文件暂存由 `coflow-staging` 承担。
`coflow-project` 是项目服务边界，不等同于本文的执行实例 Runtime。
编辑会话和命令桥接位于 `studio/editors/cfd-editor/core`，撤销重做由前端历史控制器串行处理。

## 4. 从编辑到预览

一次字段修改按以下流程处理：

1. 编辑器提交记录、字段和用户输入。
2. 项目工具根据类型和源码位置生成局部修改，更新编辑缓冲区；保存时写入文件。
3. 共享解析和分析更新源码树及诊断。
4. 后台构建新 Runtime，成功后切换预览。

修改保留未涉及的文本和注释，以及字典原始声明顺序。
fstring 编辑保存原始 `f"..."` 模板，预览字符串单独展示。
分析结果标明字段来自 CFD 显式赋值还是 CFT 默认值、维度覆盖还是基础值，供工具确定修改位置。
这些编辑信息由工具持有，不要求每个运行时记录携带完整源码信息。

连续输入可以合并处理，过时构建可以取消或丢弃结果，未变化的解析和编译结果可以复用。
这不包含增量 check；检查仍按请求实际执行。
源码暂时无效时继续提供编辑和诊断；保留旧预览时明确显示它对应旧数据。
涉及 Host 的预览由用户显式触发。

## 5. 按宿主交付能力

业务程序只依赖运行所需的核心与语言包装。
仅加载契约时无需携带 CFT 声明编译器，也无需携带补全、重构、文件监听、源码写回、
撤销重做、编辑界面、代码生成和发布工具。

共享实现不要求所有宿主加载所有组件，也不要求业务程序常驻完整 AST 和编辑索引。
