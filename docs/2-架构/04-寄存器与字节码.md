# 寄存器与字节码

> 状态：Rust 运行时架构
>
> 范围：寄存器布局、调用、内存回收和字节码编码。

## 1. 执行方式

虚拟机采用寄存器式架构，始终解释执行字节码，不引入 JIT。
编译时尽量常量化，不能常量化的逻辑保留为字节码。
普通函数、闭包、fstring 和 check 共用执行核心。
本文描述完整目标方案，不按首版划分执行能力。

## 2. 寄存器是调用中的值槽

每次函数调用拥有独立的寄存器窗口。寄存器编号相对于当前窗口，不是 CPU 寄存器。
函数编译结果记录所需槽数，调用时只分配实际需要的空间。

寄存器使用统一的 Value 表示，保存种类标记和数值或句柄：

| 内容 | 表示 |
| --- | --- |
| 数字、布尔 | 值本身 |
| enum、flag | 带静态类型身份的值句柄 |
| None | 独立标记 |
| 字符串、对象、集合、记录引用 | 对应存储或记录身份的句柄 |
| 函数、fstring | 代码与绑定的句柄 |

未初始化槽使用内部空槽状态，与语言中的 None 分开。
类型由编译器检查，运行时标记供回收、可选值和通用接口使用。
Value 的字节大小由载荷和句柄布局决定。

参数使用约定的起始槽位，局部变量和临时值使用其余槽位。
编译器根据分支、循环和返回路径分析存活范围，不同时使用的值可以复用槽位。
self 和捕获值保存在函数绑定中，按需读取。
闭包按值捕获，不保存外层寄存器地址；复制对象句柄不复制对象内容。

## 3. 调用窗口与资源限制

执行链使用连续的寄存器存储，每个调用帧记录函数、绑定、指令位置、窗口起点和长度，以及返回目标。
调用附表记录按求值顺序排列的参数寄存器，调用时复制到被调用者窗口的起始参数槽。
返回值交给调用者后释放被调用者窗口，两个窗口不重叠。

寄存器限制分为三个层面：

- 单个函数的槽数上限，与寄存器编号的编码范围一致；槽位复用后仍超限时报编译诊断。
- 调用深度上限，限制递归和嵌套调用。
- 整条执行链的寄存器内存预算，包含等待内层调用或 Host 返回的窗口。

运行时达到深度或内存预算时返回执行错误。
编码允许的槽数不等于每次调用的分配量，也不替代执行链总预算。
寄存器编号为 u16，编译程序最多包含 65,536 个虚拟寄存器；槽位复用缩小实际窗口。

## 4. 回收、重入与错误

编译器为可能触发回收和 Host 调用的位置生成寄存器存活信息。
回收器只把仍需使用的寄存器值作为根，已经不用的临时值不会因旧句柄残留而继续保活。
暂停的外层调用按暂停位置保留活跃值，函数绑定、Host 参数和宿主句柄也参与保活。

调用帧使用索引定位寄存器。寄存器存储扩容或 Host 同步重入后，重新按索引访问。
跨 Host 调用使用稳定句柄，不保留指向可扩容寄存器存储内部的裸指针。
同步重入沿用执行链预算。错误只清理需要退出的调用帧，保留仍在等待的外层状态。

## 5. 指令职责

指令直接表达编译器已确定的操作，字段使用槽编号，算术指令区分数值类型。
执行器处理越界、除零和预算耗尽等错误，不重复推导语言类型。

| 类别 | 内容 |
| --- | --- |
| 值与绑定 | 加载常量、移动值、读取 self 和捕获值 |
| 数据 | 读取字段和集合元素、创建对象和集合 |
| 运算 | 类型明确的算术、比较、可选值判断 |
| 控制流 | 跳转、条件跳转、返回 |
| 调用 | 直接调用、函数值调用、Host 调用、创建闭包 |
| 特殊读取 | 执行 fstring |

require 编译为普通 Host 调用，参数按普通求值顺序生成。
报告记录由其 Host 实现完成；VM 使用相同的函数值调用、Host 调用和错误清理机制。

取出保存的 fstring 与执行它使用不同操作。普通读取生成执行操作；
明确要求 fstring 的参数、返回、赋值及其他模板位置生成原模板传递。
复制值、扫描内存和编辑模板不执行 fstring。每次普通读取的执行次数遵循语言语义。

常量、调用信息、闭包捕获说明、源码映射和寄存器存活信息由函数的只读附表保存。
调用目标与参数列表保存在调用附表中，由 Call 的 u32 索引定位。
CFT 与 CFD 分别持有自己的编译产物，CFD 不修改契约中的代码或附表。

## 6. 字节码编码与性能

Rust VM 与契约使用 64 位定长逻辑指令，布局为 opcode:8、A:16、B:16、C:16、flags:8。
BC 可作为 u32 常量/附表索引或绝对指令序号。序列化使用小端，不保存 Rust 结构体内存。
寄存器值使用 `Slot`，空槽、unit、None 与标量/句柄分别表示。

32 位常用指令加完整字扩展作为同语义存储编码对照。完整程序测量包括附表与来源信息，
测量数据、复现命令和解释边界见[Rust 运行时实现与测试](08-Rust运行时实现与测试.md#5-编码确定与测量)。
两种存储候选均解码为相同逻辑程序，指令数和附表查询相同。解码测试不代表业务执行吞吐量。

字节码随契约格式管理版本；读取校验操作码、标志、索引、捕获布局、参数槽与存活信息。
