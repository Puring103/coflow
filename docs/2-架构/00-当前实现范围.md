# 当前实现范围

当前版本迁移声明、契约、数据构建、宿主数据访问及项目工具。语言完整语义按
`docs/1-语言` 定义，当前交付边界如下。

| 部分 | 当前行为 |
| --- | --- |
| CFT 声明 | 编译 table、singleton、data、类型别名、常量、继承、维度及 Host 成员签名 |
| CFD 数据 | 按契约加载记录和 data，校验显式类型、引用、key 唯一域及静态值 |
| 契约 | 序列化声明及源码，检查版本、长度与完整性；读取不重新编译 CFT |
| 函数与模板 | 保留签名、源码、创建身份与对象绑定；函数编译和虚拟机执行接口返回未实现错误 |
| check | 保留规则源码和检查入口；执行返回未实现错误，不报告校验通过 |
| Host | 按 singleton 服务整对象固定绑定，缺失绑定在访问时报告；宿主函数调用随虚拟机执行一起保留空接口 |
| 内部函数 | 集合方法、解析、格式化和正则等语言内部函数暂不执行 |
| C# | Unity 2022+、.NET Standard 2.1、IL2CPP，使用 C ABI 和生成的静态类型包装 |

`coflow-language` 提供共享词法、CFT/CFD 语法和源码位置；`coflow-core` 提供契约、
声明类型检查、数据模型、内存加载、运行时值和执行接口。CFT 声明编译由
`cft-compiler` feature 控制。`coflow-runtime` 提供项目配置、文件发现、编辑、诊断和
命令组织；`coflow-ffi` 适配 C ABI，默认不包含 CFT 声明编译器。

函数体不在数据构建时执行。fstring 通过显式模板接口保留，普通文本读取在需要模板求值时
报告未实现。模板和函数不使用旧解释器作为替代执行路径。

宿主数据的标量按值传递；对象、集合、enum、函数与模板可返回同一 Runtime 的现有值句柄。
返回异属 Runtime 的句柄报告归属错误。Host 回调异常转换为执行错误；同一 Runtime 的
并发执行报告忙错误，同线程同步重入沿用当前执行链。

Unity 原生库部署与 Player 验收见 [Unity 原生集成](07-Unity原生集成.md)。
