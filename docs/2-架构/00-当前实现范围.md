# 数据工具与加载边界

Coflow 使用 CFT 定义数据契约，通过 CFD 提供基础记录与维度覆盖。编辑器负责声明检查、数据编辑和 check 校验；C# 使用生成的业务类型与共享加载器。

| 部分 | 职责 |
| --- | --- |
| 项目层 | 组织项目配置、CFT 编译、所选 CFD 加载与写入会话 |
| 数据模型 | 构建记录、默认值、引用、基础插值与维度覆盖 |
| 维度 | 从所选 CFD 覆盖块发现变体，保留覆盖字段的原始来源 |
| 校验 | 编辑器执行声明式 check，输出独立检查报告 |
| C# | Coflow.Loader 读取 CFD，通过类型描述构造生成的业务类与结构体 |
| 编辑器 | 提供图谱编辑、Git Diff、自动保存、冲突处理、维度导航与项目设置 |

C# 加载器在加载时链接记录引用、合成维度字段并完成基础插值。加载结果是一份业务数据对象图，生成代码包含业务类型、类型描述与构造入口。维度字段通过 `.Default`、`.For(variant)`、`.Variants` 读取。

CFT 源码需要通过声明校验才写入磁盘；错误声明保留在编辑草稿中。CFD 源码可带诊断保存。自动保存比较磁盘内容与编辑基线，发现外部修改时暂停并显示冲突。

语言规格见 `docs/1-语言`，生成类型和共享加载实现契约见 `docs/language-design`。
