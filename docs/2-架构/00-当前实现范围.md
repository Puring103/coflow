# 当前实现范围

当前代码以 v0.11.0 的语言与运行时为基础，编辑器使用该版本的核心接口。
`docs/1-语言` 定义语言设计规格；实现接口见 `docs/language-design`。

| 部分 | 当前行为 |
| --- | --- |
| 项目与声明 | 使用 `coflow-runtime` 组织项目配置、CFT 编译、数据加载和写入会话 |
| 数据模型 | 使用 `coflow-model` 构建记录、引用和格式化字符串的解析结果 |
| 维度 | 按项目维度配置管理辅助 CFD 文件，编辑器提供按业务类型和字段组织的维度导航 |
| 函数与校验 | 保留 v0.11.0 已实现的函数与显式 check 接口 |
| C# | 保留 v0.11.0 的生成代码和托管运行时 |
| 编辑器 | 提供图谱编辑、Git Diff、自动保存、冲突处理、维度导航、项目共享设置和本机设置 |

CFT 源码需要通过声明校验才写入磁盘；错误声明保留在编辑草稿中。
CFD 源码可带诊断保存。自动保存比较磁盘内容与编辑基线，发现外部修改时暂停并显示冲突。
