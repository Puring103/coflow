# 当前实现范围

> 新 VM 的设计与验收以 [新 VM 实施计划](../plans/new-vm-and-csharp-snapshot.zh-CN.md) 及其配套规格为准；本文冲突内容在同一次交付中同步。

当前版本提供共享声明编译、契约、数据构建、Rust 字节码执行及项目工具。语言语义按
`docs/1-语言` 定义，当前交付边界如下。

| 部分 | 当前行为 |
| --- | --- |
| CFT 声明 | 编译 table、singleton、data、类型别名、常量、继承、维度及 Host 成员签名 |
| CFD 数据 | 按契约加载记录和 data，校验显式类型、引用、key 唯一域及静态值 |
| 契约 | 序列化声明、源码与类型化 IR，检查版本、长度、完整性及 IR 类型/结构边界；读取不重新编译 CFT |
| 函数与模板 | 静态编译普通函数、闭包、对象构造和 fstring，寄存器 VM 实际执行并保留来源和调用栈 |
| check | 按显式请求执行所选记录规则及顶层规则，继承按父到子执行，每次产生新报告 |
| Host | 按 singleton 服务整对象固定绑定，执行数据读取和函数调用，校验参数与返回值，支持同步重入 |
| 内部函数 | 执行集合方法、解析、格式化、正则和维度方法，以及整数区间循环 |
| C# | Unity 2022+、.NET Standard 2.1、IL2CPP；批量建立托管只读快照，提供本地属性/集合访问、函数与模板执行、Host 调用和显式 check |

`coflow-language` 提供共享词法、CFT/CFD 语法和源码位置；`coflow-core` 提供契约、
声明类型检查、数据模型、内存加载、运行时值和执行接口。CFT 声明编译由
`cft-compiler` feature 控制。`coflow-project` 提供项目配置、文件发现、编辑、诊断和
命令组织；`coflow-ffi` 适配 C ABI，默认不包含 CFT 声明编译器。

函数体在构建阶段静态编译，不调用 Host、不执行 check 或模板。
fstring 在模板类型位置保留程序与绑定，在普通文本读取时执行并返回独立字符串。
实现、编码测量和测试入口见 [Rust 运行时实现与测试](08-Rust运行时实现与测试.md)。

宿主数据的标量按值传递；对象、集合、enum、函数与模板可返回同一 Runtime 的现有值句柄。
返回异属 Runtime 的句柄报告归属错误。Host 回调异常转换为执行错误；同一 Runtime 的
并发执行报告忙错误，同线程同步重入沿用当前执行链。

Unity 原生库部署与 Player 验收见 [Unity 原生集成](07-Unity原生集成.md)。
