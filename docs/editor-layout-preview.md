# 编辑器真实组件布局预览

## 入口

在 editors/cfd-editor/frontend 下启动：

    npm run dev -- --host 127.0.0.1 --port 1430

访问 http://127.0.0.1:1430/layout-preview.html。

独立构建：

    npm run build -- --config vite.layout-preview.config.ts

产物位于 dist-layout-preview/，使用 HTTP 服务加载。

## 布局与组件

预览直接挂载正式 App。文件树、活动栏、文档标签、表格、记录、图谱、维度、源码、Git 变更、诊断、复杂值编辑及插件宿主沿用现有组件和操作链路。

layoutPreview 启用紧凑布局、顶部项目搜索、自定义视图类型标记及显式视图设置入口。检查器与诊断列表初始收起，诊断定位和详情操作仍沿用原状态管理。自定义视图使用真实的字段选择、字段排序、关系选择和分组过滤配置。

独立入口提供布局对比和字号调整。切换布局保留当前编辑状态与面板展开状态。布局样式仅由预览入口导入并限定在预览根节点；正式入口保持原有默认行为。

## 示例与运行范围

预览沿用浏览器 Mock 数据，并以真实 EditorProjectSettings 格式增加“基础属性”“药水分组”“掉落与奖励”视图。示例配置只在预览入口传入。

浏览器交互受现有 Mock 能力约束。真实文件读写、源码语言服务、构建、Git 查询和外部插件后端操作需要桌面后端；预览不代表这些操作已完成桌面端验证。
