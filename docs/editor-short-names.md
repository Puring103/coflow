# 编辑器缩略名

每个记录实际类型可指定一个顶层 `string` 字段作为缩略名，同类型的记录在所有文件中共用该设置。设置保存在 `editor-setting/editor.json` 的 `short_name_fields` 中，键为类型名，值为字段名。

在记录面板、Inspector 属性右键菜单或表格列头右键菜单中选择“设置为缩略名”。指定新字段会替换该类型原有设置；当前字段的菜单提供“取消缩略名”。后端依据 Schema 验证字段存在且类型为 `string`。

引用下拉选项显示 `缩略名(ID)`，选中后的引用文字和图缩略节点显示缩略名。记录面板和 Inspector 顶部显示 `缩略名(ID)`，类型名称保留原始大小写。未设置、字段缺失或字符串为空时显示 ID；格式化字符串使用渲染结果。

缩略名只影响展示。记录坐标、引用值、跳转目标和 ID 重命名仍使用真实 ID。引用查询返回目标记录的缩略名；设置修改成功及数据变更后刷新引用缓存。类型继承场景按引用目标记录的实际类型选择设置。
