## 2. Host 接口

Host 声明与绑定属于当前实现范围，语言规则见[Host 函数](../1-语言/12-Host函数.md)。
Host 使用 @Host singleton 类型，由宿主整对象绑定，允许缺失绑定并在实际访问时返回执行错误。
跨语言绑定接口的编码与资源释放协议需要细化；require 作为普通 Host 函数使用同一机制。

## 3. 字节码编码参数

寄存器式虚拟机始终解释执行，不引入 JIT。
优先评估 32 位常用指令加扩展编码，与 64 位定长指令比较总体积、执行指令数和耗时。
寄存器编号宽度与上限、Value 大小、指令位布局及调用信息编码尚未定稿。
评估范围见[寄存器与字节码](../2-架构/04-寄存器与字节码.md)。
