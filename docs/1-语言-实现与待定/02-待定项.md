> 范围：不改变已确定语言方向，但仍需命名、细化或性能验证的接口与实现参数。

## 1. find

查找方法暂缓实现，返回结构需要区分未找到与找到值为 None 的元素，见[暂缓项](04-暂缓项.md)。
其他通用内建方法按[函数与表达式](../1-语言/06-函数与表达式.md)执行。

## 2. Host 接口

Host 声明与绑定属于当前实现范围，语言规则见[Host 函数](../1-语言/12-Host函数.md)。
Host 使用 @Host singleton 类型，由宿主整对象绑定，允许缺失绑定并在实际访问时返回执行错误。
跨语言绑定接口的编码与资源释放协议需要细化；require 作为普通 Host 函数使用同一机制。

## 3. 性能目标

Rust VM 使用 64 位定长指令和 16 位寄存器编号。实际布局、限制及可复现的编码测量见
[Rust 运行时实现与测试](../2-架构/08-Rust运行时实现与测试.md)。
项目级吞吐量与延迟目标根据实际数据规模和 Host 工作负载确定。

## 4. Unity 交付参数

C# 首批交付必须支持 Unity 2022 及以上版本、IL2CPP，不引入 Unity 之外的专属特性。
Mono 是否纳入验收、目标操作系统及 CPU、移动端和 WebGL 范围需要确定。
托管目标框架与原生库产物矩阵据此确定。
