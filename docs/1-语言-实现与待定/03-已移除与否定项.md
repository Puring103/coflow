# 不提供的语法与机制

> 状态：设计边界
>
> 范围：当前语言不提供的能力。

| 项目 | 当前规则 |
| --- | --- |
| 浮点 f/F 后缀 | float 本身为 binary32；f"..." 专用于格式化字符串 |
| @expand | 展开布局由编辑器处理 |
| localized bucket | @localized 只绑定 language 维度 |
| CFD group 简写 | 每条记录写 key: Type { ... } |
| 无类型名内联对象 | { ... } 是字典，对象写 TypeName { ... } |
| 多行字符串 | 单行源码，换行使用转义 |
| 普通字符串隐式插值 | 只有 f"..." 解释插值，普通字符串花括号是文本 |
| 继承成员覆盖 | 类型及继承链内禁止同名字段和命名 check |
| check 作为普通值 | check 是专用入口，不作为参数、返回值或普通调用目标 |
| check 专用表达式引擎 | check 复用普通函数编译和执行 |
| Runtime 内多版本快照 | 更新创建并切换独立 Runtime |
| 维度独立数据副本 | 使用普通生成记录和引用 |
| CFD 再优化 CFT | 契约编译完成后保持只读 |

check 可以调用普通函数、CFD 实现和 Host 函数。
函数值在集合、可选值、对象和默认值中的位置不受额外限制。
