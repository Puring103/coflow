# 已移除与否定项

> 状态：记录
>
> 范围：已从语言设计中移除或明确否定的特性。未经重新评审，不得在后续设计中重新引入。

## 1. 浮点字面量 `f` / `F` 后缀

浮点字面量不再接受 `f` / `F` 后缀。`float` 本身已是 IEEE 754 binary32，无需后缀区分。

## 2. `@expand` 注解

移除 `@expand`。字段展开不再由语言注解控制。

## 3. 维度 bucket

移除 `@localized("bucket")` 的可选参数。`@localized` 只等价于绑定 `language` 维度。

## 4. CFD group 语法

移除 `TypeName { key { ... } }` 形式的 group 简写。每条记录必须写 `key: Type { ... }`。

## 5. 无类型名的内联对象

移除裸 `{ ... }` 作为内联对象的能力。`{ ... }` 只作字典字面量；内联对象必须写类型名
`TypeName { ... }`。

## 6. 多行字符串

字符串不支持跨行，也不提供三引号形式。需要换行时使用 `\n` 转义。

## 7. check 作为可调用函数

check 不接受参数、不返回值，check 之间不能相互调用。check 只能使用 `require`、`records` 和内建
控制流。
