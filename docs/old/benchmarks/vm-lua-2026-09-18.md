# VM 与 Lua 性能基准（2026-09-18）

## 环境与命令

- Coflow `0.11.0`，Rust release/bench profile，Criterion 10 samples。
- Lua `5.5.0`，LuaJIT `2.1.1779665312`。
- Windows，同一台机器、同一电源与进程环境。

```powershell
cargo bench -p coflow-core --bench vm -- --sample-size 10 --warm-up-time 1 --measurement-time 1
lua tests/perf/lua_bench.lua
luajit tests/perf/lua_bench.lua
```

Criterion 列使用估计区间中值。Lua 脚本自动增加重复次数，表中为单次平均时间。Lua 5.5 是解释器
主对照；LuaJIT 用于展示 JIT 上界，不作为寄存器解释器的同类目标。

不表示相同抽象成本。其余行保持相同数据规模和循环边界。

## 结论

Coflow VM 的字符串拼接、字符串索引和闭包创建处于 Lua 5.5 的约 1.7x 至 3.4x；普通循环、调用、集合、
字典和模板处于约 4.1x 至 11.9x。Runtime 链接、固定字段折叠和立即整数融合把记录引用字段负载从
7.861 ms 降至 3.107 ms，约提升 2.53x；对应 Debug 映像为 5.457 ms。整数循环同步从 22.342 ms
降至 17.224 ms。剩余差距主要来自解释器派发、动态调用与闭包分配、集合物化、哈希读取和诊断边界。

VM 性能回归以 Criterion 基准为准。`vm_perf_probe` 保留为快速诊断入口，不用于发布性能数字。
