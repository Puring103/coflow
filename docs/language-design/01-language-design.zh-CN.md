# 语言语义与工具边界

CFT 提供数据声明、默认值、字段维度及编辑器检查规则。CFD 提供基础记录和维度覆盖。
声明编译产生可供编辑器、模型构建器及代码生成器使用的 schema。

语言规格按主题维护于 [语言总览](../1-语言/01-总览.md)。
数据构建与字段校验由 coflow-model 负责；check 求值由 coflow-checker 负责。
共享源码扫描由 coflow-language 提供，规范格式化由 coflow-format 提供。

普通字符串保存文本。fstring 使用显式前缀，只支持字段路径、基础值转文本和花括号转义。
加载时解析模板依赖并求值；语法、路径及循环依赖错误保留来源。

check 使用条件语句、when 和 all/any/none 量词，在编辑器中按规则执行并生成诊断。
C# 加载直接构造生成类型，相关协议见 [生成类型与加载器](02-api-runtime-design.zh-CN.md)。
