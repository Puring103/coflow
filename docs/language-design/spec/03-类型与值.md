# 类型与值

## 类型文法

```text
type := "int" | "float" | "bool" | "string"
      | identifier | "&" identifier | "Option<" type ">"
      | "[" type "]" | "{" type ":" type "}" | "(" type ")"
```

| 声明 | 语义 |
| --- | --- |
| int / float | 有符号 64 位整数 / 有限 binary64 浮点数 |
| bool / string | 布尔 / 文本；string 支持普通字面量与显式插值模板 |
| data 名称 | 内联对象，使用字段内容表示 |
| `&TableName` | 按记录身份连接的引用 |
| Option<T> | 独立的一层 None 或 Some(T)，可以嵌套 |
| [T] / {K: V} | 数组 / 字典 |
| EnumName | 独立的命名枚举类型 |

table 用于有身份的顶层记录，data 用于内联值，singleton 用于唯一配置。记录的源码名称称为 id，在检查表达式和生成业务类型中通过 string 类型的 `id` 读取；data 按字段内容表示。字段使用 `&TableName` 连接记录，使用 data 名称构造内联值。显式 `&` 的目标必须是 table，引用类型可嵌套在 Option、数组和字典值中。类型别名可以直接表示完整引用类型，例如 `type ItemRef = &Item;`。

int 可以提升为 float；子类型可用于父类型位置。集合参数保持声明类型，字典 key 使用 int、string 或 enum。

```cft
data Stats { hp: int; }
table Item {
  stats: Stats;
  next: Option<&Item> = None;
}
```

## 可选值

`None` 表示当前层没有值，`Some(value)` 表示当前层存在值。裸值在已知的 `Option<T>` 位置物化为一层 Some。嵌套可选值保留各层状态，例如 `None`、`Some(None)` 和 `Some(Some(3))` 相互不同。

```cft
table Entry {
  nested: Option<Option<int>> = Some(None);
}
```

字段只有显式声明默认值时才允许省略。`Option<T>` 仅定义值可以为空，没有默认值时仍必须填写；显式 `= None` 允许省略并物化为空态。所有没有默认值的缺失字段都产生必填诊断。显式 None 只能用于可选位置，不能代替数值、对象或必填引用。

```cft
data Note {
  required: Option<string>;
  optional: Option<string> = None;
}
```

检查通过 `is Some(value)` 解包一层，通过 `is None` 判断当前层的空态。

## 递归与默认值

必填内联对象字段组成的直接或间接循环无合法有限构造，声明检查拒绝该循环。Option、数组、字典允许有限的递归数据；记录引用连接预先分配的记录身份，允许成环。

默认值必须能够有限展开。`None`、空集合以及显式提供的终止字段可结束递归；循环读取其他字段默认值会生成默认值物化诊断。常量可以推断无歧义类型；None、空集合等需要明确声明类型。常量依赖必须无环，常量不包含需要所属对象的插值模板。

## 字符串与插值模板

`string` 是唯一字符串类型，同时接收普通字符串和 `f"..."` 模板。普通字面量中的花括号及 `f` 字符均保持为文本，只有显式模板语法触发插值。字段及集合中的模板按所属对象绑定 self，嵌套内联对象的模板使用该内联对象作为 self。维度覆盖的文件位置不改变绑定对象；覆盖模板的读取范围见[维度](09-维度.md)。

```cft
table Item {
  name: string;
  price: int;
  label: string = f"名称：{self.name}，价格：{self.price}";
  note: Option<string> = None;
}
```

```cfd
sword: Item { name: "Sword", price: 100 }
shield: Item {
  name: "Shield",
  price: 80,
  label: f"同类物品：{&Item::sword.name}",
}
```

模板只读取字段路径，末端为 string、int、float、bool、enum 或其他 string 模板的求值文本。检查消息也可以读取作用域绑定。对象、集合和 Option 层不是可直接转换的文本末端。

模板从左到右生成文本，基础值转换不受区域设置影响。路径错误、读取错误和循环依赖返回来源诊断。源码保留模板，加载后的业务对象保存求值文本。

## 集合与相等

数组保持元素顺序，字典 key 唯一。源码语法树保存声明顺序，模型和查询按照各自约定组织字段、记录与索引。数组逐项比较，字典按 key 和对应 value 比较。内联对象按实际类型与字段内容比较，记录引用按所属模型及记录身份比较，并不展开被引用记录。Option 按每层状态与内容比较。

字符串按 Unicode 内容比较；浮点按数值规则比较。插值模板在需要文本值时使用求值结果，错误保留来源。
