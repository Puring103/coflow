# 校验表达式

## 读取与作用域

类型规则直接读取当前记录或内联 data 对象字段，字段路径使用 `stats.hp` 等形式。顶层规则使用 `records(Type)` 获取记录，通过量词绑定读取 `item.price`、`item.id`。记录的虚拟 `id` 是字符串；data 可声明自己的普通 `id` 字段，该字段按声明类型读取。

表达式可以读取字面量、常量、字段、引用目标、集合索引及量词绑定。`records(Type)` 用于顶层规则，Type 可以是 table、singleton 或指向 table 的引用类型别名，结果包含可赋给该类型的全部记录。

## 条件、类型与运算

条件必须为 bool。`is TypeName` 判断对象或记录的实际类型，并在成立范围内提供子类型字段。`is Some(value)` 解包一层 Option，绑定可用于同一条件后续的 `&&` 和成立时的 when 主体；`is None` 检查空态。

检查支持逻辑、相等及顺序比较、算术、位运算、类型判断和括号。普通操作数从左到右求值；`&&`、`||` 短路求值。链式比较要求方向一致。缺失字典键、数组越界、整数溢出、除零和无效移位产生计算诊断，并定位到相应表达式。

数值计算及比较按 `int → long → float → double` 提升到共同类型，整数运算与 sum 检查该位宽的溢出，float 运算按 binary32 舍入。Option 解包、集合访问和字典键保留声明数值类型。数组索引和枚举数值构造只接受 int 或 long。

## 固定内建操作

| 接收值 | 操作 |
| --- | --- |
| 字符串 | `len`、`contains`、`startsWith`、`endsWith`、`isBlank`、`matches` |
| 数组 | `len`、`contains`、`isUnique`、`min`、`max`、`sum`、`isSorted`、`isStrictlySorted` |
| 字典 | `len`、`contains`、`containsKey`、`containsValue`、`keys`、`values` |
| 支持标量元素的集合 | `intersects`、`isDisjoint`、`isSubsetOf`、`isSupersetOf` |
| int / long / float / double | `abs` |
| float / double | `isFinite`、`approxEqual` |
| 维度字段 | `for`、`hasVariant`、`variants` |

内建操作通过 `CftCheckBuiltin` 注册名称、参数个数与说明，编译器校验接收值和参数类型。`matches` 使用静态正则表达式；集合排序、聚合与唯一性检查要求支持的元素类型。

```cft
check ItemNames {
  all item in records(Item) {
    !item.name.isBlank(): "名称不能为空";
    item.tags.isUnique(): "标签不能重复";
    item.name.matches("^[A-Za-z]+$"): "名称只能包含英文字母";
  }
}
```

数组双绑定为 `item, index`，字典双绑定为 `key, value`；字典单绑定可读取条目的 `.key` 与 `.value`。

## 维度和模板

维度字段在普通表达式中直接读取基础值，保留其声明类型。仅维度方法的接收者保留字段及维度坐标：`name.for("ja")` 选择有效变体，`name.hasVariant("ja")` 查询显式覆盖，`name.variants()` 获取全部已发现变体及有效值。

普通字符串中的花括号是字面内容；`f"..."` 显式插值，使用 `{{`、`}}` 表示花括号。检查消息和检查字符串表达式中的插值读取字段或绑定路径对应的标量值，运算和方法调用放在检查表达式中。

```cft
check Prices {
  all item in records(Item) {
    item.price >= 0: f"物品 {item.id} 的价格 {item.price} 无效";
  }
}
```

维度选择后的 CFD 模板由模型按照维度与变体上下文求值。检查引擎读取模型的有效结果，缺失覆盖仍使用当前上下文重新求值基础模板。

命名块、消息作用域、执行状态和诊断见 [Check 校验](07-Check校验.md)。
