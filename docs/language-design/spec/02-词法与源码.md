# 词法与源码

## 标识符与源码

CFT 和 CFD 使用 UTF-8 文本。标识符采用 Unicode XID：首字符为 `_` 或 XID_Start，后续字符为 `_` 或 XID_Continue，区分大小写，不进行 Unicode 规范化。记录 id 使用同样的标识符规则，并排除语言保留字。

空白分隔 token；`#` 开始行注释。源码位置保存字节跨度，LSP 输出位置时转换为 UTF-16 行列。格式化保留注释和字符串内容。

声明关键字包括 `table`、`data`、`singleton`、`type`、`enum`、`abstract`、`sealed`、`const` 和 `check`。检查结构使用 `when`、`all`、`any`、`none`、`in`、`is`；规则、字段和记录名称按所在语法位置解析。

全局保留标识符限定为以下集合：

| 类别 | 保留标识符 |
| --- | --- |
| 占位 | `_` |
| 声明与规则结构 | `const`、`enum`、`type`、`table`、`data`、`singleton`、`abstract`、`sealed`、`check`、`when`、`all`、`any`、`none`、`in`、`is` |
| 字面值与构造 | `true`、`false`、`None`、`Some` |

`int`、`long`、`float`、`double`、`bool`、`string`、`Option` 在类型位置有固定含义；方法名称和目标语言关键字采用上下文解析。`for`、`records`、`len`、`min`、`max`、`keys`、`values` 可以用作普通业务名称。`id` 是 table 和 singleton 的虚拟身份字段，禁止在这两类字段声明中覆盖；data 可以声明普通 `id` 字段，`Id`、`ID` 按大小写分别识别。生成器处理目标语言关键字转义。

## 数字

- `int` 为有符号 32 位整数，范围为 `-2147483648` 至 `2147483647`；`long` 为有符号 64 位整数，范围为 `-9223372036854775808` 至 `9223372036854775807`。
- `float` 为有限 IEEE 754 binary32 值，`double` 为有限 binary64 值。支持小数和指数，例如 `1.5`、`-2.5e-3`；`1e100` 需要 double。
- 数字的范围和精度由声明类型决定；超出范围或产生非有限值时返回诊断。
- enum 默认使用有符号 32 位整数，`@int64` 指定有符号 64 位整数。`@flag` 的用户定义非零成员使用正的二次幂，内建 `None = 0` 和按所有标志位求或得到的 `Everything`。
- CFD parser 保存数字源码，schema-guided loader 再按字段类型验证；单独解析 CFD 不等于完成数值校验。

## 字符串

字符串使用双引号，支持 `\n`、`\r`、`\t`、`\"`、`\\` 转义。普通字符串按字面保存花括号。

Unicode 文本直接以 UTF-8 写入源码；转义集合由上面五种简单转义组成。

`f"..."` 为显式插值模板，使用字段路径读取当前求值上下文中的值；`{{` 和 `}}` 表示文本花括号。完整插值契约见[类型与值](03-类型与值.md)。

```cft
table Item {
  name: string;
  price: int;
  label: string = f"{self.name}: {self.price}";
}
```

## 结构限制

类型、值、检查规则及依赖分析使用结构深度、节点数和分析工作预算。数组、对象、`Some(...)` 和括号表达式的递归进入共享深度计数，超限返回带来源跨度的诊断。源码工具使用共享无损 token 流，保证扫描与格式化的词法边界一致。
