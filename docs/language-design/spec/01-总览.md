# Coflow 语言总览

> 范围：当前实现的 CFT 与 CFD 语言规则。

本目录描述已实现的语法、数据语义与执行边界。实现边界见
[语言核心实现](../01-language-design.zh-CN.md)。

## 1. 基本原则

- CFT 定义类型、默认值、常量、维度字段和 check；CFD 提供基础记录与维度覆盖。
- table 声明可引用记录，data 声明内联值，singleton 声明唯一记录；`&TableName` 表示引用，data 名称表示内联值。
- 加载后的数据模型供只读查询和规则执行；项目变更经源码写入和重新加载产生新模型。
- 字段与类型别名显式声明类型；常量可以推断无歧义的值类型。
- string 同时承载普通文本和显式 `f"..."` 字段路径插值，读取得到字符串值。
- check 是 CLI、编辑器与共享运行时执行的声明式业务校验规则。
- 集合顺序、数值规则和源码位置由语言统一规定。

## 2. 生成与加载

```text
CFT -> 声明编译 -> schema -> Rust 数据模型构建 -> check 报告
                         |          ^
                         |          |
                         |         CFD
                         v          |
                   C# 类型与描述    |
                         |          v
                         +----> C# Loader -> 业务对象
```

基础记录与维度覆盖可以跨文件。记录引用允许成环，加载时按身份链接。
默认值、类型约束、引用和插值模板在数据加载时处理。Rust 项目流程另外按请求执行业务规则；
`coflow build` 要求全部规则通过后生成代码，`coflow check --rules` 显式请求完整规则检查。
C# Loader 按生成描述构造业务对象，规则不进入生成代码。命令边界见
[CLI 设计](../../runtime-design/cli.md)。

## 3. 字符串与维度

```cft
table Item {
  @localized
  name: string;
  price: int;
  label: string = f"价格：{self.price}";
}
```

```cfd
sword: Item {
  name: "Sword",
  price: 100,
}

language[ja] {
  sword: Item {
    name: "剣",
  }
}
```

普通记录使用 `id: Type { ... }`，维度覆盖使用 `dimension[variant] { ... }`。
两者由语法区分。覆盖只替换写出的字段；未覆盖字段选择基础表达式，并在当前维度、变体上下文中求值。

## 4. 结果与错误

| 结果 | 含义 |
| --- | --- |
| 编译或加载诊断 | 语法、类型、必填值、引用或覆盖存在错误；严格消费者拒绝错误数据 |
| 数据读取结果 | 普通字段值或插值模板生成的文本 |
| check 报告 | 规则不满足或检查执行出错；不改变 C# 数据加载边界 |
| 求值错误 | 字段读取、文本生成或检查计算失败，保留源码位置 |

编辑会话可以保留可修复的数据问题和来源，供用户继续编辑；这一边界见
[编辑器容错数据加载](../../editor-design/tolerant-loading.md)。

## 6. 文法记法

`:=` 表示定义，`|` 表示选择，`[x]` 表示可选，`{x}` 表示重复，
双引号内为固定符号。文法说明结构；类型约束和求值规则以对应章节为准。
