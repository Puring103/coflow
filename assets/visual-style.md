# Coflow 整体视觉规范

本文件是官网、文档、CFD Editor、编辑器插件和应用图标的共同视觉依据。

## 品牌定位

- 产品名：Coflow。
- Slogan：AI 原生的数据配置工作流。
- 宣传语：人与AI共同配置。
- 多视图表达：同一份数据，多种视图，自由切换。
- 核心特性：类型与规则约束、human in loop、多视图编辑。

程序定义数据和规则，策划通过多视图维护内容，AI 通过 Skills 与 CLI 获取上下文、预览修改并验证结果。人的查看、调整与审查贯穿配置工作流。

## Logo

唯一源文件为 [coflow-logo.svg](./coflow-logo.svg)。标记使用 C 的斜切转折与 F 的连笔结构，F 对应 Flow；图形保持单色、原始比例及开口间距。

- 浅色背景使用 Indigo `#3E63DD`，深色背景使用 `#9EB1FF`。
- 单色印刷使用墨色或反白版本。
- 标记周围至少保留半个主笔画宽度的空白。
- 网站、编辑器与扩展共享同一图形，平台 PNG、ICO、ICNS 为派生资源。

安装图标工具后，在仓库根目录执行 `pwsh scripts/sync-brand-assets.ps1`，同步网站明暗 Logo 和各平台图标。工具安装命令为 `npm --prefix editors/cfd-editor ci`；资源同步不启动编辑器。

## 色彩系统

采用 [Radix Colors 3](https://www.radix-ui.com/colors) 的 Indigo / Slate 色阶。公共实现位于 [brand-theme.css](./brand-theme.css)，官网、文档与编辑器通过语义变量引用，不各自复制主题色值。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底层 | `#FCFCFD` | `#111113` |
| 内容表面 | `#FFFFFF` | `#18191B` |
| 次级面板 | `#F9F9FB` | `#212225` |
| 浮起 / 悬停层 | `#F0F0F3` | `#272A2D` |
| 选中背景 | `#EDF2FE` | `#182449` |
| 主文字 | `#1C2024` | `#EDEEF0` |
| 次级文字 | `#60646C` | `#B0B4BA` |
| 品牌与链接 | `#3E63DD` | `#9EB1FF` |
| 实心主按钮 | `#3E63DD` | `#3E63DD` |
| 主按钮悬停 | `#3358D4` | `#3358D4` |
| 主按钮文字 | `#FFFFFF` | `#FFFFFF` |

低彩度中性色承载主要内容，以明度差组织层级；同一靛蓝色族表达品牌和交互。深浅主题分别选择适合背景的色阶。错误、警告、成功与代码语法具有独立语义，并结合图标和文字表达。角色通过名称与工作入口区分。

## 排版与界面

- 界面使用 Inter、Segoe UI、中文系统无衬线字体；代码与字段使用 Cascadia Code 等等宽字体。
- 常规圆角为 5 至 8 px，浮层通过边界与适量阴影表达层级。
- 编辑器保持紧凑；表格、记录、图、源码、检查器共用中性色与选中状态。
- 主操作按钮使用固定靛蓝底与白字，链接和轮廓操作使用当前主题强调色。
- 功能图标使用单色线条，并提供悬停提示和可访问名称。
- 动效尊重 `prefers-reduced-motion`；主题和状态变化保持布局稳定。

## 官网展示

首屏呈现定位、宣传语与主要入口。AI 参与高速迭代与 human in loop 优先展示；同一示例在表格、记录、图和源码中使用相同数据。展示卡片跟随当前主题，使用与编辑器一致的色阶。

CLI 示例体现上下文、候选预览、差异审查、校验写入与代码生成。示例使用当前语法和命令，不承诺产品未提供的强制审批流程。桌面和移动布局保持内容完整、无横向页面溢出。
